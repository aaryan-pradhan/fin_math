Itô's Formula

Chain rule for Itô processes: Taylor to second order, because $(dW)^2 = dt$ does not vanish.

Step 1: Itô process

On a filtered probability space $(\Omega,\mathcal{F},\mathbb{F},P)$ with BM $W$, an Itô process is $$X_t = X_0 + \int_0^t a_s\,ds + \int_0^t b_s\,dW_s,\quad t\in[0,T]$$
  • $X_0$ is $\mathcal{F}_0$-measurable.
  • $a$ (drift), $b$ (noise coefficient) are $\mathbb{F}$-adapted: may be random, but depend only on the path up to time $t$.
  • $\int_0^T |a_s|\,ds < \infty$ and $\int_0^T \mathbb{E}[b_s^2]\,ds < \infty$ (technical: integrals exist).
Shorthand (stochastic differential): $dX_t = a_t\,dt + b_t\,dW_t$. It means only the integral equation.
$X=W$: $a=0$, $b=1$.   $X_t=\int_0^t s\,dW_s$: $a=0$, $b_s=s$.
From $\int_0^t W\,dW = \tfrac12W_t^2 - \tfrac12t$: $W_t^2 = \int_0^t 1\,ds + \int_0^t 2W_s\,dW_s$, i.e. $d(W_t^2) = dt + 2W_t\,dW_t$ ($a=1$, $b=2W_t$).

Step 2: Multiplication table

$$dt\cdot dt = 0,\qquad dt\cdot dW = 0,\qquad dW\cdot dW = dt$$ Each is shorthand for a limit of sums over a uniform partition ($\Delta t = t/n$):
RuleSumLimit
$dt\cdot dt=0$$\sum(\Delta t)^2 = t^2/n$$0$
$dt\cdot dW=0$$\sum \Delta t\,\Delta W_k = \tfrac tn W_t$$0$
$dW\cdot dW=dt$$\sum(\Delta W_k)^2$$t$ (LLN)
Reason: $\Delta W$ has size $\sqrt{\Delta t}$, so $(\Delta W)^2 \sim \Delta t$ survives; $\Delta t^2$, $\Delta t^{3/2}$ vanish.
$$(dX_t)^2 = (a\,dt + b\,dW)^2 = a^2(dt)^2 + 2ab\,dt\,dW + b^2(dW)^2 = b_t^2\,dt$$

Step 3: Itô's formula

$f$ twice continuously differentiable, $Y_t = f(X_t)$. Taylor: $f(x) \approx f(a) + f'(a)(x-a) + \tfrac12 f''(a)(x-a)^2$. With $x-a = dX_t$: $$dY_t = f'(X_t)\,dX_t + \tfrac12 f''(X_t)\,(dX_t)^2 = f'(X_t)\,dX_t + \tfrac12 f''(X_t)\,b_t^2\,dt$$
Ordinary calculus drops the second-order term since $(dx)^2=0$. Here $(dX)^2 = b^2\,dt \ne 0$, so it stays. Third order and up vanish ($dW^3 = dt\,dW = 0$).
$f(x)=x^2$, $X=W$: $d(W_t^2) = 2W_t\,dW_t + \tfrac12\cdot 2\,dt = dt + 2W_t\,dW_t$. Matches Step 1.
$f(x)=x^3$, $X=W$: $d(W_t^3) = 3W_t^2\,dW_t + 3W_t\,dt$, i.e. $$W_t^3 = 3\int_0^t W_s\,ds + 3\int_0^t W_s^2\,dW_s$$

Step 4: Time-dependent $f(t, X_t)$

Two-variable Taylor, then the table: $(dt)^2 = 0$, $dt\,dX = a(dt)^2 + b\,dt\,dW = 0$, $(dX)^2 = b^2\,dt$. Only three terms survive: $$dY_t = \partial_t f(t,X_t)\,dt + \partial_x f(t,X_t)\,dX_t + \tfrac12\,\partial_{xx} f(t,X_t)\,b_t^2\,dt$$ Second derivative only in $x$: only $x$ carries $dW$.
$Y_t = W_t^2 - t$, $f = x^2 - t$: $dY = -dt + 2W_t\,dW_t + dt = 2W_t\,dW_t$. No drift, consistent with $W_t^2 - t$ being a martingale.
$f = tx$: $\partial_t f = x$, $\partial_x f = t$, $\partial_{xx} f = 0$, so $d(tW_t) = W_t\,dt + t\,dW_t$. No Itô correction when $\partial_{xx} f = 0$: ordinary product rule.

Step 5: Geometric Brownian motion

$Z_t = e^{\mu t + \sigma W_t}$, $f(t,x) = e^{\mu t + \sigma x}$: $\partial_t f = \mu f$, $\partial_x f = \sigma f$, $\partial_{xx} f = \sigma^2 f$. $$dZ_t = \mu Z_t\,dt + \sigma Z_t\,dW_t + \tfrac12\sigma^2 Z_t\,dt = \left(\mu + \tfrac{\sigma^2}{2}\right)Z_t\,dt + \sigma Z_t\,dW_t$$
Do not drop the $\tfrac12$: the term is $\tfrac12\partial_{xx}f\,(dW)^2$. It is the source of $\mu + \tfrac{\sigma^2}{2}$ in $\mathbb{E}[Z_t]$.
Zero drift iff $\mu = -\tfrac{\sigma^2}{2}$: the exponential martingale $e^{-\sigma^2 t/2 + \sigma W_t}$. (Strictly, zero drift gives a local martingale; true martingale needs integrability, which holds here.)

Step 6: Product rule

$X, Y$ Itô processes on a common filtered space, $dX = a_1\,dt + b_1\,dW$, $dY = a_2\,dt + b_2\,dW$. Itô on $f(x,y) = xy$ ($\partial_{xy} f = 1$, $\partial_{xx} f = \partial_{yy} f = 0$): $$d(X_tY_t) = X_t\,dY_t + Y_t\,dX_t + dX_t\,dY_t,\qquad dX\,dY = b_1 b_2\,dt$$
$X=Y=W$: $d(W^2) = 2W\,dW + dt$. Matches Step 1.
$Z_t = W_t e^{W_t}$, $X = W$, $Y = e^{W_t}$, $dY = \tfrac12 e^{W_t}\,dt + e^{W_t}\,dW_t$: $$dZ_t = \left(1 + \tfrac12 W_t\right)e^{W_t}\,dt + (1 + W_t)\,e^{W_t}\,dW_t$$ Check via $f(x) = xe^x$, $f' = (1+x)e^x$, $f'' = (2+x)e^x$: same result.

Step 7: Quotient rule

Itô on $f(x,y) = x/y$: $\partial_x f = \tfrac1y$, $\partial_y f = -\tfrac{x}{y^2}$, $\partial_{xx} f = 0$, $\partial_{yy} f = \tfrac{2x}{y^3}$, $\partial_{xy} f = -\tfrac1{y^2}$. $$d\left(\frac{X_t}{Y_t}\right) = \frac{dX_t}{Y_t} - \frac{X_t}{Y_t^2}\,dY_t + \frac{X_t}{Y_t^3}(dY_t)^2 - \frac{1}{Y_t^2}\,dX_t\,dY_t$$
$X = 1$, $Y = e^{W_t}$: $d(e^{-W_t}) = \tfrac12 e^{-W_t}\,dt - e^{-W_t}\,dW_t$. Check: GBM with $\mu = 0$, $\sigma = -1$.

Summary: three forms

  • $f(x)$: $df(X) = f'\,dX + \tfrac12 f''\,b^2\,dt$
  • $f(t,x)$: $df = \partial_t f\,dt + \partial_x f\,dX + \tfrac12\partial_{xx} f\,b^2\,dt$
  • $f(x,y)$: $df = \partial_x f\,dX + \partial_y f\,dY + \tfrac12\left[\partial_{xx} f\,(dX)^2 + 2\partial_{xy} f\,dX\,dY + \partial_{yy} f\,(dY)^2\right]$
Recipe: Taylor to second order, then $dt\cdot dt = 0$, $dt\cdot dW = 0$, $dW\cdot dW = dt$.
