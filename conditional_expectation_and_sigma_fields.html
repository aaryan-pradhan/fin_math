Conditional Expectation & σ-Fields

Rigorously connecting independence, sub-σ-fields, the Law of Iterated Expectations, and operational rules.

Step 1: Independence of Random Variables & σ-Fields

Independent σ-Fields: Two sub-σ-fields $\mathcal{G}, \mathcal{H} \subseteq \mathcal{F}$ are independent if for all $A \in \mathcal{G}$ and all $B \in \mathcal{H}$: $$P(A \cap B) = P(A)P(B)$$ Independent Random Variables: $\xi$ and $\eta$ are independent $\iff$ their generated σ-fields $\sigma(\xi)$ and $\sigma(\eta)$ are independent, where: $$\sigma(\xi) = \{\xi^{-1}(B) \subseteq \Omega : B \in \mathcal{B}(\mathbb{R})\}$$
Two tosses. $\xi = \mathbb{1}\{\text{toss 1 H}\}$, $\eta = \mathbb{1}\{\text{toss 2 H}\}$.
  • $\sigma(\xi) = \{\varnothing, \{HH,HT\}, \{TH,TT\}, \Omega\}$ and $\sigma(\eta) = \{\varnothing, \{HH,TH\}, \{HT,TT\}, \Omega\}$.
  • Check one pair: $P(\{HH,HT\} \cap \{HH,TH\}) = P(\{HH\}) = \tfrac14 = \tfrac12\cdot\tfrac12$ ✅. The other pairs work the same way (pairs involving $\varnothing$ or $\Omega$ are automatic). So they are independent.
Dependent: $\xi$ and $S = \xi + \eta$. $P(\xi = 1, S = 0) = 0$, but $P(\xi = 1)P(S = 0) = \tfrac12\cdot\tfrac14 \ne 0$.

Step 2: What is $E(X \mid \mathcal{G})$?

$E(X \mid \mathcal{G})$ is a RANDOM VARIABLE, not a single number.
  • $E(X \mid Y = y)$ is a single real number (the estimate when $Y(\omega) = y$).
  • $E(X \mid Y) = E(X \mid \sigma(Y))$ is a random variable that assigns $E(X \mid Y = y)$ whenever $Y(\omega) = y$.
  • $E(X \mid \mathcal{G})$ is the general random variable for any sub-σ-field $\mathcal{G} \subseteq \mathcal{F}$.
Two dice, $X$ = sum, $Y$ = first die.
  • Number: $E(X \mid Y = 4) = 4 + E(\text{second}) = 4 + 3.5 = 7.5$.
  • Random variable: $E(X \mid Y) = Y + 3.5$. If $\omega = (4, 1)$, its value is $7.5$. If $\omega = (2, 6)$, its value is $5.5$.
Formal Definition: $Y = E(X \mid \mathcal{G})$ is the unique (a.s.) random variable satisfying:
  1. $Y$ is $\mathcal{G}$-measurable: $\sigma(Y) \subseteq \mathcal{G}$. $Y$ cannot see finer details than $\mathcal{G}$ allows and is forced to be constant on every information block $G \in \mathcal{G}$.
  2. Integral Matching (for all $G \in \mathcal{G}$): $\int_G Y\, dP = \int_G X\, dP$. Since $Y$ is constant ($c_G$) on block $G$, this reduces to $c_G \cdot P(G) = \int_G X\, dP \implies c_G = \int_G X\, dP \,/\, P(G)$. Condition 2 forces $Y$ to equal the exact average of $X$ over each block $G$.
  3. Unique (a.s.): Any two random variables $Y_1, Y_2$ satisfying (1) & (2) must be equal everywhere except on a set of probability zero ($P(Y_1 \neq Y_2) = 0$).
Die, $X = \omega$, $\mathcal{G} = \sigma(\text{odd}, \text{even})$.
  1. Measurability: $Y$ is constant on odd $\{1,3,5\}$ and on even $\{2,4,6\}$.
  2. Matching on $G$ = odd: $\int_G X\,dP = \tfrac16(1 + 3 + 5) = 1.5$. So $c_{\text{odd}}\cdot\tfrac12 = 1.5$, giving $c_{\text{odd}} = 3$.
  3. On even: $\tfrac16(2 + 4 + 6) = 2 = c_{\text{even}}\cdot\tfrac12$, giving $c_{\text{even}} = 4$.
$E(X \mid \mathcal{G}) = 3$ on odd outcomes and $4$ on even ones. Uniqueness: changing $Y$ on a probability-0 set changes nothing, but a die has no such sets, so here $Y$ is fully unique.

Step 3: Law of Iterated Expectations (Tower Property)

Theorem: $E(E(X \mid Y)) = E(X)$ and generally $E(E(X \mid \mathcal{G})) = E(X)$.

Proof via Joint Densities: $$\begin{aligned} E(E(X \mid Y)) &= \int_{-\infty}^{\infty} \left[\int_{-\infty}^{\infty} x\, f_{X|Y=y}(x)\, dx\right] f_Y(y)\, dy \\ &= \iint_{\mathbb{R}^2} x\, f_{X|Y=y}(x)\, f_Y(y)\, dx\, dy \\ &= \iint_{\mathbb{R}^2} x\, f(x, y)\, dx\, dy \\ &= \int_{-\infty}^{\infty} x \left[\int_{-\infty}^{\infty} f(x, y)\, dy\right] dx = \int_{-\infty}^{\infty} x\, f_X(x)\, dx = E(X) \end{aligned}$$
Tail Probability Application: Setting $X = \mathbb{1}_{\{X > t\}}$ gives $P(X > t) = E(P(X > t \mid Y))$.
  • Dice: $E(E(X \mid Y)) = E(Y + 3.5) = 3.5 + 3.5 = 7 = E(X)$ ✅
  • Die, odd/even: $\tfrac12(3) + \tfrac12(4) = 3.5 = E(X)$ ✅
  • Random coin: bias $p \sim U[0,1]$, $X$ = heads in 10 tosses. $E(X \mid p) = 10p$, so $E(X) = E(10p) = 5$.
  • Tail: lifetime $X \sim \text{Exp}(Y)$ with rate $Y = 1$ or $2$, each with probability $\tfrac12$. $P(X > 1) = \tfrac12e^{-1} + \tfrac12e^{-2} \approx 0.184 + 0.068 = 0.252$.

Step 4: Operational Rules

1. Linearity: For constants $a, b \in \mathbb{R}$: $$E(aX + bY \mid \mathcal{G}) = a\,E(X \mid \mathcal{G}) + b\,E(Y \mid \mathcal{G})$$ 2. Taking Out What Is Known: If $Z$ is $\mathcal{G}$-measurable: $$E(Z \cdot X \mid \mathcal{G}) = Z \cdot E(X \mid \mathcal{G})$$ 3. Independence Rule: If $X$ is independent of $\mathcal{G}$: $$E(X \mid \mathcal{G}) = E(X)$$
Two dice $X_1, X_2$, $\mathcal{G} = \sigma(X_1)$:
  • Linearity + known + independence: $E(X_1 + X_2 \mid X_1) = X_1 + E(X_2) = X_1 + 3.5$.
  • Take out what is known: $E(X_1X_2 \mid X_1) = X_1E(X_2 \mid X_1) = 3.5X_1$. If $X_1 = 2$, this is $7$.
  • Squares: $E((X_1 + X_2)^2 \mid X_1) = X_1^2 + 2X_1E(X_2) + E(X_2^2) = X_1^2 + 7X_1 + \tfrac{91}{6}$.
Two extremes: if $X$ is $\mathcal{G}$-measurable, $E(X \mid \mathcal{G}) = X$ (full information). If $\mathcal{G} = \{\varnothing, \Omega\}$, $E(X \mid \mathcal{G}) = E(X)$ (no information).

Practice Questions

Q1. Die, $\mathcal{G} = \sigma(\{1,2,3\}, \{4,5,6\})$. Find $E(X^2 \mid \mathcal{G})$ and check the tower property.
AnswerLow: $\tfrac{1 + 4 + 9}{3} = \tfrac{14}{3}$. High: $\tfrac{16 + 25 + 36}{3} = \tfrac{77}{3}$. Tower: $\tfrac12\left(\tfrac{14}3 + \tfrac{77}3\right) = \tfrac{91}{6} = E(X^2)$ ✅
Q2. Two dice. Find $E(X_1 \mid X_1 + X_2 = 4)$. Guess the general formula for $E(X_1 \mid S)$.
AnswerThe pairs with sum 4 are $(1,3), (2,2), (3,1)$, equally likely, so the average of $X_1$ is $2$. By symmetry $E(X_1 \mid S) = E(X_2 \mid S)$, and the two add up to $E(S \mid S) = S$. So $E(X_1 \mid S) = S/2$.
Q3. Two dice. Find $E(\max(X_1, X_2) \mid X_1 = 5)$.
AnswerIf $X_2 \le 5$ (probability $\tfrac56$), the max is 5. If $X_2 = 6$, it's 6. $E = \tfrac{5\cdot 5 + 6}{6} = \tfrac{31}{6} \approx 5.17$.
Q4. Symmetric random walk. Find $E(S_5 \mid \mathcal{F}_3)$ and $E(S_5^2 \mid \mathcal{F}_3)$.
Answer$S_5 = S_3 + D$ with $D = \xi_4 + \xi_5$ independent of $\mathcal{F}_3$, $E(D) = 0$, $E(D^2) = 2$. So $E(S_5 \mid \mathcal{F}_3) = S_3$ and $E(S_5^2 \mid \mathcal{F}_3) = S_3^2 + 2S_3\cdot 0 + 2 = S_3^2 + 2$.
Q5. The number of insurance claims is $N \sim \text{Poisson}(3)$. Each claim has mean Rs 100, independent of $N$. Find the expected total.
Answer$E(\text{total} \mid N) = 100N$ (linearity + independence). Tower: $E(\text{total}) = E(100N) = 300$.
Q6. Two dice. Are $X_1$ and $\mathbb{1}\{X_1 + X_2 = 7\}$ independent?
AnswerYes, surprisingly. For every $k$, $P(\text{sum} = 7 \mid X_1 = k) = P(X_2 = 7 - k) = \tfrac16 = P(\text{sum} = 7)$. (For sum $= 8$ it fails: $X_1 = 1$ makes 8 impossible.)
Q7. $X$ is $\mathcal{G}$-measurable and $Z$ is independent of $\mathcal{G}$ with $E(Z) = 2$. Simplify $E(3X + XZ + 5 \mid \mathcal{G})$.
Answer$3X + X\,E(Z \mid \mathcal{G}) + 5 = 3X + 2X + 5 = 5X + 5$.
