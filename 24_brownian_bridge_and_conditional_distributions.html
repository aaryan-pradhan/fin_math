24 — Brownian Bridge & Conditional Distributions

Master Reference Rules & Derivation of $[Y(s) \mid Y(t) = C]$.

1. Reference Rules & Definitions

  • Rule 1 (Density Notation): $f_t(x)$ is shorthand for $f_{W(t)}(x)$, the density of $W(t) \sim \mathcal{N}(0, t)$.
  • Rule 2 (Bayes' Rule for Densities): $f_{X \mid Y}(x \mid y) = \frac{f_{X, Y}(x, y)}{f_Y(y)}$.
  • Rule 3 (Independent Increments): For $s < t$, $f_{W(s), W(t)}(x, B) = f_{W(s)}(x) \cdot f_{W(t)-W(s)}(B - x)$.
  • Rule 4 (Stationary Increments): $W(t) - W(s) \sim \mathcal{N}(0, t-s) \implies f_{W(t)-W(s)}(B - x) = f_{t-s}(B - x)$.
  • Rule 5 (Gaussian Density): $f_v(z) = \frac{1}{\sqrt{2\pi v}} \exp\left( -\frac{z^2}{2v} \right)$.
  • Rule 6 (Completing the Square): $f(x) = K \exp\left(-\frac{(x - \mu)^2}{2\sigma^2}\right) \implies \mathcal{N}(\mu, \sigma^2)$.

2. Derivation of Standard Brownian Bridge $[W(s) \mid W(t) = B]$

Using Rules 2, 3, 4, 5: $$f_{W(s) \mid W(t)}(x \mid B) = \frac{f_s(x) f_{t-s}(B - x)}{f_t(B)} = K_1 \exp\left( -\frac{x^2}{2s} - \frac{(B-x)^2}{2(t-s)} \right)$$ Completing the square for $x$: $$-\frac{x^2}{2s} - \frac{(B-x)^2}{2(t-s)} = -\frac{\left( x - \frac{s}{t}B \right)^2}{2 \left[ \frac{s(t-s)}{t} \right]} + \text{const}$$ $$[W(s) \mid W(t) = B] \sim \mathcal{N}\left( \frac{s}{t}B, \;\; \frac{s(t-s)}{t} \right)$$

3. General Brownian Motion $Y(t) = \sigma W(t)$

For general Brownian motion $Y(t) = \sigma W(t) \sim \mathcal{N}(0, \sigma^2 t)$:
  • Condition $Y(t) = C \implies W(t) = \frac{C}{\sigma}$.
  • $[Y(s) \mid Y(t) = C] = \sigma \left[ W(s) \;\middle|\; W(t) = \frac{C}{\sigma} \right]$.
$$\text{Mean: } \mu_Y = \sigma \left( \frac{s}{t} \frac{C}{\sigma} \right) = \frac{s}{t} C \quad \text{($\sigma$ cancels out)}$$ $$\text{Variance: } \text{Var}_Y = \sigma^2 \left( \frac{s(t-s)}{t} \right) = \sigma^2 \frac{s(t-s)}{t} \quad \text{($\sigma^2$ scales variance)}$$ $$[Y(s) \mid Y(t) = C] \sim \mathcal{N}\left( \frac{s}{t}C, \;\; \sigma^2 \frac{s(t-s)}{t} \right)$$

4. Application: Bicycle Race Model

Let $Y(t) = \sigma W(t)$ be the lead margin at $100t\%$ completion ($0 \le t \le 1$).

(i) Given midpoint lead $Y(1/2) = \sigma$, probability of winning ($Y(1) > 0$): $$P\left( Y(1) - Y(1/2) > -\sigma \right) = P\left( Z > \frac{-\sigma}{\sigma/\sqrt{2}} \right) = P(Z > -\sqrt{2}) = \Phi(\sqrt{2}) \approx 0.9213$$ (ii) Given winning margin $Y(1) = \sigma$, probability of leading at midpoint ($Y(1/2) > 0$): $$\left[ Y(1/2) \;\middle|\; Y(1) = \sigma \right] \sim \mathcal{N}\left( \frac{\sigma}{2}, \; \frac{\sigma^2}{4} \right) \implies P(Z > -1) = \Phi(1) \approx 0.8413$$
