Starting Pieces — Probability Theory

My understanding, built from scratch.

1. The Outcome

The experiment runs. One outcome is produced. Call it ω.
Ω = the set of all possible outcomes (sample space).
ω ∈ Ω always.

2. Events

An event is just a subset A ⊆ Ω.

A happened iff ω ∈ A. (Did the actual outcome land inside the set?)
A did not happen iff ω ∉ A.

Examples (coin toss forever):
  • AH = {ω : first toss is H}
  • AHH = {ω : first two tosses are HH}
  • Ω = always happens. ∅ = never happens.

3. σ-field (Sigma-Algebra)

A σ-field ℱ is a collection of subsets of Ω that we are allowed to assign probabilities to.

Must satisfy:
  1. ∅ ∈ ℱ
  2. A ∈ ℱ ⟹ Aᶜ ∈ ℱ (if you can ask "did A?", you can ask "did NOT A?")
  3. A₁, A₂, … ∈ ℱ ⟹ ∪Aᵢ ∈ ℱ
Just accept these axioms. They exist so probability arithmetic never breaks.

4. Special Events & Filtration

At time k, you have seen ω₁, ω₂, …, ωₖ.

A is a special event at time k if:
  Knowing ω₁,…,ωₖ is enough to say definitively — ω ∈ A or ω ∉ A.

A is NOT special at time k if:
  You need more tosses. You cannot decide yet.

EventSpecial at k=1?Reason
AH✅ YesSaw ω₁, enough to decide
AHH❌ NoNeed ω₂
Ω✅ YesAlways yes, needs 0 tosses
ℱₖ = the set of ALL special events at time k.

As k grows, you see more → more events become special:
  ℱ₀ ⊂ ℱ₁ ⊂ ℱ₂ ⊂ …

This chain is the filtration. It tracks your growing information over time.
ℱₖ represents all information available by time k.

5. Probability Measure

P is a function: P : ℱ → [0,1]
Input: an event. Output: a number.

Two rules:
  1. P(Ω) = 1
  2. If A₁, A₂, … are pairwise disjoint: P(∪Aᵢ) = ΣP(Aᵢ)

6. Probability Space

(Ω, ℱ, P) — the three pieces:
  • Ω — all possible outcomes
  • ℱ — the events we are allowed to assign probabilities to
  • P — the function that assigns those numbers

7. Almost Surely (a.s.)

P(A) = 1 → A occurs almost surely. NOT "surely."

Surely = A = Ω, impossible to be outside A.
Almost surely = P(A) = 1, but exceptions of probability 0 may exist.
