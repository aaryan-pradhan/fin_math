14 — Standard Brownian Motion & Canonical Martingales

Rigorously defining the Wiener process (Standard Brownian Motion) and deriving its three fundamental canonical martingales.

Step 1: Definition of Standard Brownian Motion (SBM / Wiener Process)

A continuous-time stochastic process (Wₜ)t ≥ 0 is a Wiener process or Standard Brownian Motion if:

1. Initial State: W₀ = 0 (P-a.s.).
2. Continuous Paths: The map t ↦ Wₜ(ω) is continuous P-a.s.
3. Independent Increments: For 0 ≤ t₁ < t₂ < … < tₙ, increments (Wt₂ - Wt₁), (Wt₃ - Wt₂), … are mutually independent.
4. Gaussian Increments: For 0 ≤ s < t:

  (Wₜ - Wₛ) ~ N(0, t - s)

Step 2: Martingale 1 — The Linear Process Wₜ

Theorem: (Wₜ)t ≥ 0 is a martingale relative to its natural filtration ℱₜ = σ(Wᵣ : 0 ≤ r ≤ t).

Proof:
1. Integrability: E[|Wₜ|] ≤ √(E[Wₜ²]) = √t < ∞.
2. For 0 ≤ s < t, decompose Wₜ = (Wₜ - Wₛ) + Wₛ:

  E[ Wₜ | ℱₛ ] = E[ Wₜ - Wₛ | ℱₛ ] + E[ Wₛ | ℱₛ ] = E[ Wₜ - Wₛ ] + Wₛ = 0 + Wₛ = Wₛ   ■

Step 3: Martingale 2 — The Quadratic Process Wₜ² - t

Theorem: Yₜ = Wₜ² - t is a martingale relative to ℱₜ.

Proof:
1. Integrability: E[|Yₜ|] ≤ E[Wₜ²] + t = 2t < ∞.
2. Decompose Wₜ² = (Wₜ - Wₛ)² + 2 Wₛ(Wₜ - Wₛ) + Wₛ²:

  E[ Wₜ² | ℱₛ ] = E[ (Wₜ - Wₛ)² | ℱₛ ] + 2 Wₛ E[ Wₜ - Wₛ | ℱₛ ] + Wₛ²
                  = (t - s) + 0 + Wₛ² = Wₛ² + t - s.

Subtract t on both sides: E[ Wₜ² - t | ℱₛ ] = Wₛ² - s   ⟹   E[ Yₜ | ℱₛ ] = Yₛ   ■

Note: The un-centered process (Wₜ²)t ≥ 0 is a submartingale since E[Wₜ² | ℱₛ] = Wₛ² + (t-s) ≥ Wₛ².

Step 4: Martingale 3 — The Exponential Process eu Wₜ - ½ u² t

Theorem: For any parameter u ∈ ℝ, Zₜ = eu Wₜ - ½ u² t is a martingale relative to ℱₜ with E[Zₜ] = 1.

Proof:
1. Integrability: E[Zₜ] = e-½ u² t E[eu Wₜ] = e-½ u² t e½ u² t = 1 < ∞.
2. Multiplicative increment splitting for 0 ≤ s < t:

  Zₜ = Zₛ · eu(Wₜ - Wₛ) - ½ u²(t-s)

3. Taking conditional expectation E[ · | ℱₛ ]:

  E[ Zₜ | ℱₛ ] = Zₛ · e-½ u²(t-s) E[ eu(Wₜ - Wₛ) ]

Since (Wₜ - Wₛ) ~ N(0, t - s), its MGF is E[eu(Wₜ - Wₛ)] = e½ u²(t-s).
Substituting this in yields E[ Zₜ | ℱₛ ] = Zₛ · 1 = Zₛ.   ■
