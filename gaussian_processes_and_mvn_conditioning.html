Gaussian Processes, Standard Brownian Motion & MVN Conditioning

1. Multivariate Normal (MVN) Distribution Properties

Definition: A random vector $\mathbf{X} \in \mathbb{R}^n$ follows an $n$-dimensional MVN distribution, $\mathbf{X} \sim \mathcal{N}_n(\boldsymbol{\mu}, \boldsymbol{\Sigma})$, if every linear combination $\mathbf{a}^T \mathbf{X}$ is a univariate Gaussian random variable for any non-zero $\mathbf{a} \in \mathbb{R}^n$.

Linear Transformation Property

If $\mathbf{X} \sim \mathcal{N}_n(\boldsymbol{\mu}, \boldsymbol{\Sigma})$, then for any matrix $\mathbf{A} \in \mathbb{R}^{m \times n}$ and vector $\mathbf{c} \in \mathbb{R}^m$: $$\mathbf{Y} = \mathbf{A}\mathbf{X} + \mathbf{c} \implies \mathbf{Y} \sim \mathcal{N}_m(\mathbf{A}\boldsymbol{\mu} + \mathbf{c}, \, \mathbf{A}\boldsymbol{\Sigma}\mathbf{A}^T)$$

Conditional Distribution of Partitioned MVN

Partition a joint MVN vector into two sub-vectors:

$$\mathbf{X} = \begin{pmatrix} \mathbf{X}_1 \\ \mathbf{X}_2 \end{pmatrix} \sim \mathcal{N}\left( \begin{pmatrix} \boldsymbol{\mu}_1 \\ \boldsymbol{\mu}_2 \end{pmatrix}, \, \begin{pmatrix} \boldsymbol{\Sigma}_{11} & \boldsymbol{\Sigma}_{12} \\ \boldsymbol{\Sigma}_{21} & \boldsymbol{\Sigma}_{22} \end{pmatrix} \right)$$
Theorem: The conditional distribution $\mathbf{X}_1 \mid \mathbf{X}_2 = \mathbf{x}_2$ is Multivariate Normal: $$\mathbf{X}_1 \mid \mathbf{X}_2 = \mathbf{x}_2 \sim \mathcal{N}(\boldsymbol{\mu}_{1|2}, \boldsymbol{\Sigma}_{1|2})$$
  • Conditional Expectation: $\mathbb{E}[\mathbf{X}_1 \mid \mathbf{X}_2 = \mathbf{x}_2] = \boldsymbol{\mu}_1 + \boldsymbol{\Sigma}_{12}\boldsymbol{\Sigma}_{22}^{-1}(\mathbf{x}_2 - \boldsymbol{\mu}_2)$
  • Conditional Variance: $\text{Var}(\mathbf{X}_1 \mid \mathbf{X}_2 = \mathbf{x}_2) = \boldsymbol{\Sigma}_{11} - \boldsymbol{\Sigma}_{12}\boldsymbol{\Sigma}_{22}^{-1}\boldsymbol{\Sigma}_{21}$

2. Gaussian Process & Brownian Motion

A stochastic process $\{W(t), t \ge 0\}$ is a Gaussian Process if every finite sub-collection $(W(t_1), \dots, W(t_n))^T$ is Multivariate Normal. Standard Brownian Motion is fully defined by:

  • Mean function: $m(t) = \mathbb{E}[W(t)] = 0$
  • Covariance function: $K(s, t) = \text{Cov}(W(s), W(t)) = \min(s, t) = s \wedge t$

3. Conditional Expectations of Brownian Motion

Case 1: Forward Expectation ($s < t$) — Martingale Property

Using independent increments $W(t) = W(s) + [W(t) - W(s)]$, where the increment $W(t) - W(s)$ is independent of $W(s)$:

$$\mathbb{E}[W(t) \mid W(s)] = W(s) + \mathbb{E}[W(t) - W(s)] = W(s)$$

Case 2: Backward Expectation & Interpolation ($s < t$)

For $s < t$, the joint distribution of $(W(s), W(t))^T$ is:

$$\begin{pmatrix} W(s) \\ W(t) \end{pmatrix} \sim \mathcal{N}_2\left( \begin{pmatrix} 0 \\ 0 \end{pmatrix}, \, \begin{pmatrix} s & s \\ s & t \end{pmatrix} \right)$$

Applying the MVN conditional parameters for scalars ($\mu_1=0, \mu_2=0, \Sigma_{11}=s, \Sigma_{12}=s, \Sigma_{22}=t$):

  • Conditional Mean: $$\mathbb{E}[W(s) \mid W(t)] = 0 + s \cdot t^{-1} (W(t) - 0) = \frac{s}{t} W(t)$$
  • Conditional Variance: $$\text{Var}(W(s) \mid W(t)) = s - s \cdot t^{-1} \cdot s = s - \frac{s^2}{t} = \frac{s(t - s)}{t}$$
Insight (Brownian Bridge): Given $W(t)$, the value at an earlier time $s < t$ is non-terminally uncertain with variance $\frac{s(t-s)}{t}$, which shrinks to $0$ as $s \to 0$ or $s \to t$.
