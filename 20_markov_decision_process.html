20 — Markov Decision Processes (MDP)

My understanding, built from scratch.

1. The Structure (Decision Tree)

An MDP models decision-making in a stochastic environment.
  • State Node: System is in state $X_t = i$.
  • Action Node: Decision-maker chooses action $a \in A$ based only on the history up to $t$ (no future peeking).
  • Reward: Receive immediate payoff $R(i, a)$.
  • Chance Node: Environment randomly transitions to $X_{t+1}$ based on the state $i$ and action $a$.

2. Policies and Stationarity

A policy $\{a_t\}$ is a rulebook prescribing which action to take at each time $t$.
Stationary Policy: A policy where the action depends only on the current state $X_t$, not on time $t$ or past history. $$a_t = f(X_t)$$ Intuition: If I am in State A, I take Action 1. Doesn't matter if it's minute 5 or minute 50. The rule doesn't change.

3. The Markov Property and State Augmentation

Question: Doesn't the real-world environment sometimes respond based on history, not just the current state?

Answer: Yes. But the word "Markov" imposes a mathematical rule: The environment's response depends only on the current state and action. It has amnesia.
State Augmentation trick: If the environment does care about history (e.g., whether you visited Room B), you redefine the state to include that memory.
$X_t = (\text{Current Location}, \text{ Boolean Flag: Have I visited Room B?})$
Now the environment only needs to look at the current state vector. The Markov property is restored.

4. The MDP Collapse

If you pair an environment that has amnesia (Markov Property) with a policy that has amnesia (Stationary Policy), the whole system becomes memoryless.

The sequence of states $(X_t)$ collapses into a time-homogeneous Markov Chain.
The transition probabilities are constant over time and depend only on the policy: $$P_{ij}\big(f(i)\big)$$ This controlled Markov Chain is called a Markov Decision Process.
