Binomial Market Model & Martingale Properties

Rigorously building the discrete binomial tree, natural filtrations, sub/super-martingales, multi-step expectations, and the constant mean property.

Step 1: Binomial Market Model & Natural Filtration

Binomial Asset Price: $S_0 > 0$ fixed, with movement factors $0 < d < u$. At each time step $t \in \{1, 2, \ldots, T\}$: $$S_t = v_t S_{t-1} \quad \text{where } v_t \in \{u, d\}$$ Sample Space $\Omega$: Path vectors of length $T$: $$\Omega = \{v = (v_1, v_2, \ldots, v_T) : v_j \in \{u, d\}\}$$ Natural Filtration $\mathbb{F} = (\mathcal{F}_t)_{t \geq 0}$: Generated by price history $\mathcal{F}_t = \sigma(S_0, S_1, \ldots, S_t)$.
  • $\mathcal{F}_0 = \{\varnothing, \Omega\}$
  • $\mathcal{F}_1 = \sigma(A_u, A_d) = \{\varnothing, \Omega, A_u, A_d\}$ where $A_u = \{v_1 = u\}$
  • $\mathcal{F}_t \subset \mathcal{F}_{t+1}$ (nested information structure)
Non-Adapted Increment: $Y_t := S_{t+1} - S_t$ is not $\mathcal{F}_t$-measurable because determining $\{Y_t = c\}$ requires future move $v_{t+1} \notin \mathcal{F}_t$.

Step 2: Martingale, Submartingale & Supermartingale

Let $(X_t)_{t \geq 0}$ be an adapted, integrable process ($E[|X_t|] < \infty$).
  1. Martingale (MG): $E[X_{t+1} \mid \mathcal{F}_t] = X_t$ ($P$-a.s.) — fair game
  2. Submartingale (sub-MG): $E[X_{t+1} \mid \mathcal{F}_t] \geq X_t$ ($P$-a.s.) — expected value grows or stays equal
  3. Supermartingale (super-MG): $E[X_{t+1} \mid \mathcal{F}_t] \leq X_t$ ($P$-a.s.) — expected value shrinks or stays equal
Binomial Stock Condition: $E[S_{t+1} \mid \mathcal{F}_t] = S_t \cdot E[v_{t+1}]$.
If $P(v_{t+1} = u) = p$, then $E[v_{t+1}] = pu + (1-p)d$.
$S_t$ is a martingale $\iff pu + (1-p)d = 1$.

Step 3: Multi-Step Expectation Theorem

Theorem: If $(X_t)$ is a martingale, then for any $s \geq 1$: $$E[X_{t+s} \mid \mathcal{F}_t] = X_t \quad (P\text{-a.s.})$$ Proof via Tower Property: Since $\mathcal{F}_t \subseteq \mathcal{F}_{t+s-1}$: $$E[X_{t+s} \mid \mathcal{F}_t] = E\big[E[X_{t+s} \mid \mathcal{F}_{t+s-1}] \mid \mathcal{F}_t\big]$$ By martingale property, $E[X_{t+s} \mid \mathcal{F}_{t+s-1}] = X_{t+s-1}$, so $$= E[X_{t+s-1} \mid \mathcal{F}_t] = \cdots = E[X_{t+1} \mid \mathcal{F}_t] = X_t. \quad ■$$

Step 4: Corollary — Constant Unconditional Mean

Theorem: For a martingale $(X_t)$, $E[X_t] = E[X_0]$ for all $t \geq 0$.

Proof:
  1. Since $\Omega \in \mathcal{F}_t$ (as $\varnothing \in \mathcal{F}_t$ and $\Omega = \varnothing^c$), total expectation gives $E[E[Z \mid \mathcal{F}_t]] = E[Z]$.
  2. Taking $E[\cdot]$ on both sides of $E[X_{t+s} \mid \mathcal{F}_t] = X_t$ yields $E[X_{t+s}] = E[X_t]$.
  3. Setting $t = 0$: $E[X_s] = E[X_0]$ $\forall s \geq 0$. ■
For Submartingales: $E[Y_{t+s} \mid \mathcal{F}_t] \geq Y_t \implies E[Y_{t+s}] \geq E[Y_t] \geq E[Y_0]$.
