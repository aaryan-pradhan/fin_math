# p.105–109: Finite single-period market and the no-arbitrage theorem

## Notation check

Same symbols as p.88: $\Delta$ is the number of shares, $b$ the number of bonds, and time is $t = 0, 1$. The one change: now there can be $n$ stocks, so $\Delta = (\Delta_1, \dots, \Delta_n)$ and $S_t = (S_{t,1}, \dots, S_{t,n})$ are vectors. The notes mark vectors with a small $\sim$ underneath.

Tables keep the same layout: rows are time or outcome, columns are securities (bond first), plus a sum column. Each cell is holding $\times$ price.

## Recap: the binomial case (p.105)

Let's start from what we already know. In the single-period binomial market, the NA (no-arbitrage) condition has the form

$$S_0 \in \left(\frac{S_1(d)}{1+r}, \frac{S_1(u)}{1+r}\right)$$

and this is the same as saying there exists an EMM (equivalent martingale measure) $p^*$ on $\Omega = \{u, d\}$ such that

$$S_0 = p^* \frac{S_1(u)}{1+r} + (1 - p^*) \frac{S_1(d)}{1+r} = E^*\left(\frac{S_1}{1+r}\right)$$

(The notes write $S_1(d)$ in both terms. The first one should be $S_1(u)$, as on p.91.)

Numbers, from p.91: $0.6 \times 1.4 + 0.4 \times 0.4 = 0.84 + 0.16 = 1 = S_0$.

Now we want the same result for a market with more outcomes and more stocks.

## The finite market (p.105)

There are two times, $t = 0$ and $t = 1$. At $t = 1$ the possible outcomes are

$$\Omega = \{\omega_1, \dots, \omega_N\}, \quad N < \infty$$

There are $n + 1$ traded assets in the market: $n$ stocks,

$$S_t = (S_{t,1}, \dots, S_{t,n})$$

and $1$ bond (bank account),

$$B_t = (1+r)^t, \quad t = 0, 1$$

Numbers. Let's build a running example with $n = 2$ stocks, $N = 3$ outcomes and $r = 0.25$. Each row is a time, and at $t = 1$ an outcome (4 rows). Each column is a security (3 columns):

| | bond | stock 1 | stock 2 |
|---|---|---|---|
| $t = 0$ | $1$ | $1$ | $1$ |
| $t = 1$, $\omega_1$ | $1.25$ | $2$ | $1$ |
| $t = 1$, $\omega_2$ | $1.25$ | $0.5$ | $2$ |
| $t = 1$, $\omega_3$ | $1.25$ | $0.5$ | $1$ |

We'll often need the discounted stock prices $y_k = \frac{S_1(\omega_k)}{1+r}$. Divide each stock price by $1.25$. Rows are outcomes (3), columns are the stocks (2):

| | stock 1 | stock 2 |
|---|---|---|
| $\omega_1$ | $1.6$ | $0.8$ |
| $\omega_2$ | $0.4$ | $1.6$ |
| $\omega_3$ | $0.4$ | $0.8$ |

Each $y_k$ is a point in the plane. These three points will be the corners of a triangle.

## Convex set (p.105)

A set $D \subset \mathbb{R}^m$ is called convex if, for any $\underset{\sim}{x}_1, \underset{\sim}{x}_2 \in D$, all the points on the straight line segment connecting them also lie in $D$:

$$\beta \underset{\sim}{x}_1 + (1 - \beta) \underset{\sim}{x}_2 \in D, \quad \beta \in (0, 1)$$

As $\beta$ goes from $1$ to $0$, the point slides along the segment from $x_1$ to $x_2$.

Numbers. Take $x_1 = y_1 = (1.6, 0.8)$ and $x_2 = y_2 = (0.4, 1.6)$. With $\beta = 0.5$, I get $0.5 \times (1.6, 0.8) + 0.5 \times (0.4, 1.6) = (1.0, 1.2)$, the midpoint. A triangle is convex: every such point stays inside it.

## Convex hull (p.105–106)

The convex hull of a set $B \subset \mathbb{R}^m$, written $\text{conv}(B)$, is the smallest convex set $D$ such that $B \subset D$.

For a finite set $B := \{y_1, \dots, y_N\} \subset \mathbb{R}^m$ one has

$$D := \text{conv}(B) = \left\{x \in \mathbb{R}^m : x = \sum_{j=1}^N \alpha_j y_j, \ \alpha_j \ge 0, \ \sum_{j=1}^N \alpha_j = 1\right\}$$

So the convex hull is all the weighted averages of the points, with weights that are $\ge 0$ and add up to $1$.

Numbers. For our three points, $\text{conv}\{y_1, y_2, y_3\}$ is the filled triangle with corners $(1.6, 0.8)$, $(0.4, 1.6)$, $(0.4, 0.8)$. Weights $(1, 0, 0)$ give the corner $y_1$ itself.

## Relative interior (p.106)

Denote by $D_0$ the relative interior of the convex hull $D$. It is the same formula, but every weight must be strictly positive:

$$D_0 = \left\{x \in \mathbb{R}^m : x = \sum_{j=1}^N \alpha_j y_j, \ \alpha_j > 0, \ \sum_{j=1}^N \alpha_j = 1\right\}$$

If some weight is $0$, the point sits on an edge or a corner. So $D_0$ is the triangle without its edges.

Numbers.

- $(1, 1) = 0.5 y_1 + 0.25 y_2 + 0.25 y_3$. Check the first coordinate: $0.8 + 0.1 + 0.1 = 1$. The second: $0.4 + 0.4 + 0.2 = 1$. All weights are $> 0$, so $(1, 1) \in D_0$.
- $(0.4, 1.2) = 0 \cdot y_1 + 0.5 y_2 + 0.5 y_3$. One weight is $0$, so this point is in $D$ (on the left edge) but not in $D_0$.

## Hyperplane (p.106)

By a hyperplane in $\mathbb{R}^m$ one means a flat set (linear manifold) of dimension $m - 1$. In $\mathbb{R}^2$ that's a line. Analytically, a hyperplane can be given by one linear equation:

$$L := \{\underset{\sim}{x} = (x_1, \dots, x_m) \in \mathbb{R}^m : \underset{\sim}{a} \cdot \underset{\sim}{x} = c\}$$

where $\underset{\sim}{a} \cdot \underset{\sim}{x} = \sum_{j=1}^m x_j a_j$, $c \in \mathbb{R}$, and $\underset{\sim}{a} = (a_1, \dots, a_m) \ne 0$ is fixed.

Numbers. With $a = (1, 1)$ and $c = 2$, the hyperplane is the line $x_1 + x_2 = 2$. The point $(1, 1)$ is on it, since $1 + 1 = 2$.

## The normal vector (p.106)

The vector $\underset{\sim}{a}$ is orthogonal to $L$. Let's see why. Take any $x_1, x_2 \in L$. Then $a \cdot x_1 = c$ and $a \cdot x_2 = c$. Subtract the two:

$$\underset{\sim}{a} \cdot (\underset{\sim}{x}_1 - \underset{\sim}{x}_2) = 0$$

So $a$ is perpendicular to every direction that lies inside $L$.

Now fix one point $x_0 \in L$, so $c = a \cdot x_0$. Substitute this $c$ into $a \cdot x = c$ and move it to the left. The equation for $L$ can be written as

$$\underset{\sim}{a} \cdot (\underset{\sim}{x} - \underset{\sim}{x}_0) = 0$$

The three pictures in the notes show $c < 0$, $c = 0$ and $c > 0$. The value of $c$ only decides where $L$ sits relative to the origin $0$. In every picture, the arrow $a$ is perpendicular to $L$.

Numbers. $x_1 = (2, 0)$ and $x_2 = (0, 2)$ both lie on $x_1 + x_2 = 2$. Their difference is $(2, -2)$, and $(1, 1) \cdot (2, -2) = 2 - 2 = 0$. Perpendicular, as promised.

## The half-space (p.106)

The open half-space on the side of $L$ where $\underset{\sim}{a}$ is pointing can be given as

$$H_L(\underset{\sim}{a}) := \{x \in \mathbb{R}^m : \underset{\sim}{a} \cdot (\underset{\sim}{x} - \underset{\sim}{x}_0) > 0\}$$

On $L$ the dot product is $0$. On the side the arrow points to, it is positive. On the other side, negative.

Numbers. $a = (1, 1)$, $x_0 = (1, 1)$. Take the point $(1.6, 0.8)$: $(1, 1) \cdot (0.6, -0.2) = 0.6 - 0.2 = 0.4 > 0$. So $(1.6, 0.8)$ is in $H_L(a)$.

## Thm 1: the separation theorem (p.107)

**Theorem 1 (separation theorem).** Assume that $D \subset \mathbb{R}^m$ is a convex set, and $D_0$ its relative interior. Then for any point $x_0 \notin D_0$, there exists a hyperplane $L$ with a normal vector $a$ such that $x_0 \in L$ and $D_0 \subset H_L(a)$.

In other words, there exists a vector $a \in \mathbb{R}^m$ such that

$$\underset{\sim}{a} \cdot (\underset{\sim}{x} - \underset{\sim}{x}_0) > 0, \quad \forall \, x \in D_0$$

In words: if a point is not inside the convex set, I can draw a line through that point with the whole inside of the set strictly on one side.

Numbers. Take $x_0 = (2, 2)$, which is outside our triangle. Try $a = (-1, -1)$. Then $a \cdot (y - x_0) = -(y_1 + y_2) + 4$ for a point $y$ with coordinates $(y_1, y_2)$. At the three corners:

- $(1.6, 0.8)$: $-2.4 + 4 = 1.6 > 0$
- $(0.4, 1.6)$: $-2.0 + 4 = 2.0 > 0$
- $(0.4, 0.8)$: $-1.2 + 4 = 2.8 > 0$

Every point of the triangle is a weighted average of the corners. The dot product is linear, so it's the same weighted average of $1.6$, $2.0$, $2.8$, which is positive. So the whole triangle is on the positive side.

## Thm 2: NA if and only if an EMM exists (p.107)

**Theorem 2.** A finite single-period financial market is arbitrage-free if and only if there exists a probability $P^*$ on $(\Omega, 2^\Omega)$ such that $P^*(\{\omega\}) > 0$ for every $\omega \in \Omega$, and

$$E^*\left(\frac{\underset{\sim}{S}_1}{1+r}\right) = \underset{\sim}{S}_0$$

That is, the process $\{\underset{\sim}{S}_t (1+r)^{-t}\}_{t=0,1}$ is a (vector-valued) martingale (MG) under $P^*$.

Let's read the martingale part. At $t = 0$ the discounted price is $S_0 (1+r)^0 = S_0$. At $t = 1$ it is $\frac{S_1}{1+r}$. "Martingale" says: the expected value tomorrow equals the value today.

Numbers. Take $p^* = (0.5, 0.25, 0.25)$ on $(\omega_1, \omega_2, \omega_3)$. Rows are outcomes (3), plus a last row for $E^*$. Columns are the stocks (2). Each cell is $p_k^* \times y_k$, and the last row adds down the column:

| | stock 1 | stock 2 |
|---|---|---|
| $\omega_1$ | $0.5 \times 1.6 = 0.8$ | $0.5 \times 0.8 = 0.4$ |
| $\omega_2$ | $0.25 \times 0.4 = 0.1$ | $0.25 \times 1.6 = 0.4$ |
| $\omega_3$ | $0.25 \times 0.4 = 0.1$ | $0.25 \times 0.8 = 0.2$ |
| $E^*$ (sum) | $1$ | $1$ |

So $E^*\left(\frac{S_1}{1+r}\right) = (1, 1) = S_0$, and every $p_k^* > 0$. This $P^*$ is an EMM, so by Thm 2 our market is arbitrage-free.

## The plan of the proof (p.107)

Let's prove it for $n = 2$: $S_t = (S_{t,1}, S_{t,2})$, $t = 0, 1$, two risky assets. Set

$$D := \text{conv}\left\{\frac{S_1(\omega_1)}{1+r}, \dots, \frac{S_1(\omega_N)}{1+r}\right\}$$

In our example, $D$ is the triangle. There are two possibilities: either

(I) $S_0 \in D_0$, or (II) $S_0 \notin D_0$.

We will prove NA $\iff$ $\exists$ EMM in three steps:

- Step 1 shows $\exists$ EMM $\iff$ (I).
- Step 2 proves $\exists$ EMM $\Rightarrow$ NA.
- Step 3 proves NA $\Rightarrow$ (I).

Why is that enough? Chain them: NA $\Rightarrow$ (I) by Step 3, (I) $\Rightarrow$ EMM by Step 1, and EMM $\Rightarrow$ NA by Step 2. So NA and EMM imply each other.

## Step 1: an EMM is the same as (I) (p.108)

From the definition of $D_0$, the statement $S_0 \in D_0$ says there are weights $p_k^* > 0$ adding up to $1$ with

$$S_0 = \sum_{k=1}^N p_k^* \frac{S_1(\omega_k)}{1+r} =: E^*\left(\frac{S_1}{1+r}\right)$$

But positive weights adding to $1$ are just a probability on $\Omega$ with $P^*(\{\omega_k\}) = p_k^* > 0$. And the equation says the discounted stocks are fair under it. That is an EMM. Thus $\exists$ EMM $\iff$ (I).

Numbers. The one equation $(1, 1) = 0.5 y_1 + 0.25 y_2 + 0.25 y_3$ says both things: $S_0 \in D_0$, and $p^* = (0.5, 0.25, 0.25)$ is an EMM.

## Step 2: an EMM rules out arbitrage (p.108)

Proof by contradiction. Suppose that an EMM exists, but NA does not.

So there is an arbitrage opportunity $(\underset{\sim}{\Delta}, b)$, with value

$$V_t = \underset{\sim}{\Delta} \cdot \underset{\sim}{S}_t + b B_t$$

An arbitrage starts from nothing:

$$V_0 = \underset{\sim}{\Delta} \cdot \underset{\sim}{S}_0 + b = 0$$

so that

$$b = -\underset{\sim}{\Delta} \cdot \underset{\sim}{S}_0$$

Now substitute this $b$ into $V_1$, using $B_1 = 1 + r$:

$$V_1(\omega) = \underset{\sim}{\Delta} \cdot \underset{\sim}{S}_1(\omega) + b(1+r) = \underset{\sim}{\Delta} \cdot \underset{\sim}{S}_1(\omega) - \underset{\sim}{\Delta} \cdot \underset{\sim}{S}_0 (1+r)$$

Being an arbitrage means

$$V_1(\omega) \ge 0 \ \forall \omega, \quad V_1(\omega) > 0 \text{ for at least one } \omega \qquad (\circledast)$$

However, this means the following. Start from $\Delta \cdot S_0$ and use Step 1, $S_0 = E^*\left(\frac{S_1}{1+r}\right)$:

$$\underset{\sim}{\Delta} \cdot \underset{\sim}{S}_0 = \underset{\sim}{\Delta} \cdot E^*\left(\frac{\underset{\sim}{S}_1}{1+r}\right)$$

$\Delta$ is a fixed vector, so I can move it inside the expectation:

$$\underset{\sim}{\Delta} \cdot \underset{\sim}{S}_0 = E^*\left(\frac{\underset{\sim}{\Delta} \cdot \underset{\sim}{S}_1}{1+r}\right) = \sum_{k=1}^N p_k^* \frac{\underset{\sim}{\Delta} \cdot \underset{\sim}{S}_1(\omega_k)}{1+r}$$

Now look at $(\circledast)$. Dividing it by $1 + r$ says $\frac{\Delta \cdot S_1(\omega_k)}{1+r} \ge \Delta \cdot S_0$ for every $k$, with $>$ for at least one $k$. Every $p_k^* > 0$, so that strict part survives in the sum:

$$\sum_{k=1}^N p_k^* \frac{\underset{\sim}{\Delta} \cdot \underset{\sim}{S}_1(\omega_k)}{1+r} > \sum_{k=1}^N p_k^* \, \underset{\sim}{\Delta} \cdot \underset{\sim}{S}_0 = \underset{\sim}{\Delta} \cdot \underset{\sim}{S}_0$$

The last step used $\sum_k p_k^* = 1$. Putting the two lines together: $\Delta \cdot S_0 > \Delta \cdot S_0$. That is a contradiction. $\therefore$ $\exists$ EMM $\Rightarrow$ NA.

Numbers. Let's try to build an arbitrage in our market and watch it fail. Take $\Delta = (1, -1)$: buy stock 1, short stock 2. Then $b = -\Delta \cdot S_0 = -(1 - 1) = 0$. Rows are time and outcome (4), columns are the securities plus the sum (4):

| | bond | stock 1 | stock 2 | sum |
|---|---|---|---|---|
| $t = 0$ | $0 \times 1 = 0$ | $1 \times 1 = 1$ | $-1 \times 1 = -1$ | $0$ |
| $t = 1$, $\omega_1$ | $0 \times 1.25 = 0$ | $1 \times 2 = 2$ | $-1 \times 1 = -1$ | $1$ |
| $t = 1$, $\omega_2$ | $0 \times 1.25 = 0$ | $1 \times 0.5 = 0.5$ | $-1 \times 2 = -2$ | $-1.5$ |
| $t = 1$, $\omega_3$ | $0 \times 1.25 = 0$ | $1 \times 0.5 = 0.5$ | $-1 \times 1 = -1$ | $-0.5$ |

It wins in $\omega_1$ but loses in $\omega_2$ and $\omega_3$. Check the average: $E^*\left(\frac{V_1}{1.25}\right) = 0.5 \times 0.8 + 0.25 \times (-1.2) + 0.25 \times (-0.4) = 0.4 - 0.3 - 0.1 = 0$. An average of $0$ with positive weights can't come from numbers that are all $\ge 0$ with one $> 0$. That's the whole proof, in one example.

## Step 3: no-arbitrage forces (I) (p.108–109)

This also we will prove by contradiction. Suppose NA holds, but (I) does not.

The latter means that (II) holds: $S_0 \notin D_0$. Then by the separation theorem there is a straight line $L$ through $S_0$ separating $S_0$ from $D_0$. Denote by

$$\underset{\sim}{\Delta} := (\Delta_1, \Delta_2)$$

a normal vector to $L$, "pointing" in the direction of $D_0$. Then we have

$$\underset{\sim}{\Delta} \cdot (\underset{\sim}{x} - \underset{\sim}{S}_0) > 0, \quad x \in D_0$$

The notes jump from points of $D_0$ to the corners $\frac{S_1(\omega)}{1+r}$, so let's fill it in. The corners sit at the edge of $D_0$: points of $D_0$ come as close to them as I like. So at each corner the dot product can't be negative, though it might be $0$. And it can't be $0$ at every corner, since then every weighted average, including every point of $D_0$, would give $0$ too. So

$$\underset{\sim}{\Delta} \cdot \left(\frac{\underset{\sim}{S}_1(\omega)}{1+r} - \underset{\sim}{S}_0\right) \begin{cases} \ge 0, & \forall \omega \\ > 0, & \text{for at least one } \omega \end{cases}$$

Now multiply by $1 + r$. This becomes $\Delta \cdot S_1(\omega) - \Delta \cdot S_0 (1+r)$, which is exactly $V_1(\omega)$ from Step 2 with $b = -\Delta \cdot S_0$. So it is $(\circledast)$ again.

But this is an arbitrage opportunity. That contradicts NA. $\therefore$ NA $\Rightarrow$ (I).

Numbers. Keep the same $S_1$, but now let $S_0 = (2, 2)$, outside the triangle. From Thm 1, $\Delta = (-1, -1)$ points towards the triangle: short one of each stock. Then $b = -\Delta \cdot S_0 = -(-2 - 2) = 4$, so I put $4$ in the bond. Rows are time and outcome (4), columns are the securities plus the sum (4):

| | bond | stock 1 | stock 2 | sum |
|---|---|---|---|---|
| $t = 0$ | $4 \times 1 = 4$ | $-1 \times 2 = -2$ | $-1 \times 2 = -2$ | $0$ |
| $t = 1$, $\omega_1$ | $4 \times 1.25 = 5$ | $-1 \times 2 = -2$ | $-1 \times 1 = -1$ | $2$ |
| $t = 1$, $\omega_2$ | $4 \times 1.25 = 5$ | $-1 \times 0.5 = -0.5$ | $-1 \times 2 = -2$ | $2.5$ |
| $t = 1$, $\omega_3$ | $4 \times 1.25 = 5$ | $-1 \times 0.5 = -0.5$ | $-1 \times 1 = -1$ | $3.5$ |

$V_0 = 0$, and $V_1 > 0$ in every outcome: an arbitrage. Check against Thm 1: there the dot products were $1.6$, $2.0$, $2.8$. Times $1.25$ that's $2$, $2.5$, $3.5$. Same.

## Doubts

**Q:** In the binomial case, why does no-arbitrage mean $S_0 \in \left(\frac{S_1(d)}{1+r}, \frac{S_1(u)}{1+r}\right)$? And why is that the same as having an EMM $p^*$ with $S_0 = E^*\left(\frac{S_1}{1+r}\right)$?

**A:** Let's take the two parts one at a time.

First, rewrite the interval. Substitute $S_1(d) = dS_0$ and $S_1(u) = uS_0$, then multiply through by $\frac{1+r}{S_0}$:

$$\frac{dS_0}{1+r} < S_0 < \frac{uS_0}{1+r} \iff d < 1 + r < u$$

So the condition just says the bond's growth $1 + r$ must sit strictly between the stock's down factor and up factor. Let's see what goes wrong if it doesn't. I use $S_0 = 1$ and $u = 1.75$ throughout.

Case 1: $1 + r \ge u$. The bond does at least as well as the stock even in the stock's best case. So I short the stock and put the money in the bond. Take $r = 0.8$, $d = 0.5$: short 1 share, buy 1 bond. Rows are time and outcome (3); columns are bond, stock and the sum (3):

| | bond | stock | sum |
|---|---|---|---|
| $t = 0$ | $1 \times 1 = 1$ | $-1 \times 1 = -1$ | $0$ |
| $t = 1$, up | $1 \times 1.8 = 1.8$ | $-1 \times 1.75 = -1.75$ | $0.05$ |
| $t = 1$, down | $1 \times 1.8 = 1.8$ | $-1 \times 0.5 = -0.5$ | $1.3$ |

I start with $0$ and end positive in both outcomes. Arbitrage.

Case 2: $1 + r \le d$. The stock does at least as well as the bond even in its worst case. So I borrow in the bond and buy the stock. Take $r = 0.25$, $d = 1.3$: borrow 1, buy 1 share. Same layout:

| | bond | stock | sum |
|---|---|---|---|
| $t = 0$ | $-1 \times 1 = -1$ | $1 \times 1 = 1$ | $0$ |
| $t = 1$, up | $-1 \times 1.25 = -1.25$ | $1 \times 1.75 = 1.75$ | $0.5$ |
| $t = 1$, down | $-1 \times 1.25 = -1.25$ | $1 \times 1.3 = 1.3$ | $0.05$ |

Again an arbitrage.

Case 3: $d < 1 + r < u$. Start from nothing with $\Delta$ shares and $b = -\Delta S_0$ in the bond. Then $V_1 = \Delta(S_1 - (1+r)S_0)$, which is $\Delta(u - (1+r))S_0$ in the up outcome and $\Delta(d - (1+r))S_0$ in the down outcome. The two brackets have opposite signs, so whatever $\Delta$ I pick, I win in one outcome and lose in the other. No arbitrage. With $r = 0.25$, $d = 0.5$, $\Delta = 1$: up gives $1.75 - 1.25 = 0.5$, down gives $0.5 - 1.25 = -0.75$.

Second part: why is this the same as an EMM? A number lies strictly between two others exactly when it is a weighted average of them with a weight strictly between $0$ and $1$. Solve for that weight:

$$p^* = \frac{S_0 - \frac{S_1(d)}{1+r}}{\frac{S_1(u)}{1+r} - \frac{S_1(d)}{1+r}} = \frac{1 + r - d}{u - d}$$

If $S_0$ is inside the interval, $p^* \in (0, 1)$, so it is a real probability that gives both outcomes positive weight, and

$$S_0 = p^* \frac{S_1(u)}{1+r} + (1 - p^*) \frac{S_1(d)}{1+r} = E^*\left(\frac{S_1}{1+r}\right)$$

That is the EMM: under $p^*$, the discounted stock price is a fair game, and today's price equals the expected discounted price tomorrow. If $S_0$ is outside the interval, the same formula gives $p^* > 1$ or $p^* < 0$, which is not a probability, so no EMM exists.

Numbers. With $r = 0.25$, $d = 0.5$, the interval is $(0.4, 1.4)$ and $p^* = \frac{1 - 0.4}{1.4 - 0.4} = 0.6$. In Case 1 ($r = 0.8$), $p^* = \frac{1.8 - 0.5}{1.75 - 0.5} = 1.04 > 1$: not a probability, and indeed we found an arbitrage.

So "$S_0$ is inside the interval", "$d < 1 + r < u$", "there is an EMM" and "no arbitrage" are four ways of saying the same thing. Thm 2 is this same fact for many stocks and outcomes, with the interval replaced by the triangle $D_0$.
