# p.86–87: General discrete model, self-financing strategies and no-arbitrage

## The securities (p.86)

Now we go from one stock to many. Let's write the prices at time $$n$$ as a vector:

$$S_n = (S_n^0, S_n^1, \dots, S_n^d)$$

This is the development of $$d$$ equity securities. Here $$S_n^i$$ is the price of the $$i$$th stock at time $$n$$.

The $$0$$th one is special. It is the bond:

$$S_n^0 = (1+r)^n$$

Numbers. Take $$d = 1$$, $$r = 0.05$$, and one stock with $$S_0^1 = 100$$, $$S_1^1 = 130$$. Then

$$S_0 = (1, 100), \quad S_1 = (1.05, 130)$$

Let's lay all the prices out as a table. Each row is a time $$n$$. Each column is a security $$i$$, so there are $$d + 1$$ columns: the bond ($$i = 0$$) and the $$d$$ stocks.

| | $$i = 0$$ (bond) | $$i = 1$$ | $$\dots$$ | $$i = d$$ |
|---|---|---|---|---|
| $$n = 0$$ | $$S_0^0$$ | $$S_0^1$$ | $$\dots$$ | $$S_0^d$$ |
| $$n = 1$$ | $$S_1^0$$ | $$S_1^1$$ | $$\dots$$ | $$S_1^d$$ |
| $$\vdots$$ | $$\vdots$$ | $$\vdots$$ | | $$\vdots$$ |

Row $$n$$ of this table is the vector $$S_n$$. Column $$i$$ is the price history of security $$i$$.

Our numbers, with $$d = 1$$ (so 2 columns), and one more time step where the stock goes to $$150$$ (so 3 rows):

| | $$i = 0$$ (bond) | $$i = 1$$ (stock) |
|---|---|---|
| $$n = 0$$ | $$1$$ | $$100$$ |
| $$n = 1$$ | $$1.05$$ | $$130$$ |
| $$n = 2$$ | $$1.1025$$ | $$150$$ |

## Portfolio and trading strategy (p.86)

A portfolio describes the proportions of the different securities in it.

A trading strategy

$$\Phi = (\Phi_n) = (\Phi_n^0, \dots, \Phi_n^d)$$

describes the development of the portfolio over time. Here $$\Phi_n^i$$ is the number of shares of security number $$i$$ at time $$n$$.

Numbers. Take the duplicating portfolio from p.66: $$0.4$$ shares and a bond amount of $$-30.48$$. Since $$S_0^0 = 1$$, that's $$-30.48$$ units of bond. So

$$\Phi_1 = (-30.48, \ 0.4)$$

The strategy is a table of the same shape as the prices. Each row is a time $$n$$. Each column is a security $$i$$ ($$d + 1$$ columns). The entry is how many shares I hold.

| | $$i = 0$$ (bond) | $$i = 1$$ | $$\dots$$ | $$i = d$$ |
|---|---|---|---|---|
| $$n = 1$$ | $$\Phi_1^0$$ | $$\Phi_1^1$$ | $$\dots$$ | $$\Phi_1^d$$ |
| $$n = 2$$ | $$\Phi_2^0$$ | $$\Phi_2^1$$ | $$\dots$$ | $$\Phi_2^d$$ |
| $$\vdots$$ | $$\vdots$$ | $$\vdots$$ | | $$\vdots$$ |

Row $$n$$ is the vector $$\Phi_n$$. Our numbers (2 columns; $$\Phi_2$$ comes from the self-financing step below):

| | $$i = 0$$ (bond) | $$i = 1$$ (stock) |
|---|---|---|
| $$n = 1$$ | $$-30.48$$ | $$0.4$$ |
| $$n = 2$$ | $$-18.10$$ | $$0.3$$ |

## Value of the portfolio (p.86)

The value of the portfolio at time $$n$$ is: for each security, shares times price, then add up. That's a dot product:

$$V_n(\Phi) = \Phi_n \cdot S_n$$

$$V_n(\Phi) = \sum_{i=0}^{d} \Phi_n^i S_n^i$$

In the tables: take row $$n$$ of the strategy table and row $$n$$ of the price table. Multiply them column by column. Add across.

Numbers. Value $$\Phi_1$$ at the time-1 prices $$S_1 = (1.05, 130)$$. Here each row is a security ($$d + 1 = 2$$ rows). The columns are shares held, price, and their product:

| security | $$\Phi_1^i$$ | $$S_1^i$$ | $$\Phi_1^i S_1^i$$ |
|---|---|---|---|
| $$i = 0$$ (bond) | $$-30.48$$ | $$1.05$$ | $$-32$$ |
| $$i = 1$$ (stock) | $$0.4$$ | $$130$$ | $$52$$ |
| sum | | | $$20$$ |

$$\Phi_1 \cdot S_1 = (-30.48)(1.05) + (0.4)(130) = -32 + 52 = 20$$

That's the call payoff from p.67, as it should be.

## Self-financing (p.86)

$$\Phi$$ is called self-financing if

$$\Phi_n \cdot S_n = \Phi_{n+1} \cdot S_n$$

Let's read this. At time $$n$$ the prices are $$S_n$$. On the left, I value my old holding $$\Phi_n$$ at these prices. On the right, I value my new holding $$\Phi_{n+1}$$, the one I switch to now, at the same prices. They must be equal.

So changes to the portfolio result only from regroupings. No additional capital is required for the change. No withdrawal of value takes place.

Numbers. At time $$1$$, prices $$S_1 = (1.05, 130)$$, I hold $$\Phi_1 = (-30.48, 0.4)$$, worth $$20$$. Now I regroup. I sell $$0.1$$ share, which brings in $$0.1 \times 130 = 13$$. I put that $$13$$ into the bond, which buys $$13 / 1.05 = 12.38$$ units. So

$$\Phi_2 = (-30.48 + 12.38, \ 0.4 - 0.1) = (-18.10, \ 0.3)$$

Check self-financing. Rows are securities (2 rows). The columns are old holding, new holding, today's price, and each holding valued at today's price:

| security | $$\Phi_1^i$$ (old) | $$\Phi_2^i$$ (new) | $$S_1^i$$ | $$\Phi_1^i S_1^i$$ | $$\Phi_2^i S_1^i$$ |
|---|---|---|---|---|---|
| $$i = 0$$ (bond) | $$-30.48$$ | $$-18.10$$ | $$1.05$$ | $$-32$$ | $$-19$$ |
| $$i = 1$$ (stock) | $$0.4$$ | $$0.3$$ | $$130$$ | $$52$$ | $$39$$ |
| sum | | | | $$20$$ | $$20$$ |

The two sums in the last row are the two sides of the self-financing equation:

$$\Phi_2 \cdot S_1 = (-18.10)(1.05) + (0.3)(130) = -19 + 39 = 20$$

Same $$20$$. Nothing added, nothing taken out.

## Increase in value (p.87)

The increase in value from $$n$$ to $$n+1$$ is

$$\Delta V_n(\Phi) = V_{n+1}(\Phi) - V_n(\Phi)$$

Now substitute $$V = \Phi \cdot S$$ at each time:

$$\Delta V_n(\Phi) = \Phi_{n+1} \cdot S_{n+1} - \Phi_n \cdot S_n$$

Now, if $$\Phi$$ is self-financing, I replace $$\Phi_n \cdot S_n$$ by $$\Phi_{n+1} \cdot S_n$$:

$$\Delta V_n(\Phi) = \Phi_{n+1} \cdot S_{n+1} - \Phi_{n+1} \cdot S_n$$

Now take $$\Phi_{n+1}$$ out as a common factor, and write $$\Delta S_n = S_{n+1} - S_n$$:

$$\Delta V_n(\Phi) = \Phi_{n+1} \cdot \Delta S_n$$

So for a self-financing strategy, the value changes only because prices move. It equals my holding times the price change.

Numbers. Continue the example. Say at time $$2$$ the stock is $$150$$, so $$S_2 = (1.05^2, 150) = (1.1025, 150)$$. Then

$$\Delta S_1 = S_2 - S_1 = (0.0525, \ 20)$$

Now apply the formula with $$\Phi_2 = (-18.10, 0.3)$$. Rows are securities (2 rows). The columns are the holding, the price before, the price after, the change, and holding times change:

| security | $$\Phi_2^i$$ | $$S_1^i$$ | $$S_2^i$$ | $$\Delta S_1^i$$ | $$\Phi_2^i \Delta S_1^i$$ |
|---|---|---|---|---|---|
| $$i = 0$$ (bond) | $$-18.10$$ | $$1.05$$ | $$1.1025$$ | $$0.0525$$ | $$-0.95$$ |
| $$i = 1$$ (stock) | $$0.3$$ | $$130$$ | $$150$$ | $$20$$ | $$6$$ |
| sum | | | | | $$5.05$$ |

$$\Delta V_1 = (-18.10)(0.0525) + (0.3)(20) = -0.95 + 6 = 5.05$$

Check it directly. $$V_2 = (-18.10)(1.1025) + (0.3)(150) = -19.95 + 45 = 25.05$$. And $$V_1 = 20$$. So $$V_2 - V_1 = 5.05$$. Same.

## No-arbitrage principle (p.87)

The no-arbitrage principle says there is no arbitrage strategy $$\Phi$$. That is, there is no strategy $$\Phi$$ such that

$$V_0(\Phi) = 0, \quad V_n(\Phi) \ge 0 \quad \text{and} \quad P(V_n(\Phi) > 0) > 0$$

Let's read the three parts. I start with nothing. I can never end up below zero. And there is some chance I end up above zero. That's free money with no risk.

Or, equivalently,

$$V_0(\Phi) \le 0, \quad V_n(\Phi) \ge 0 \quad \text{and} \quad P(V_n(\Phi) > 0) > 0$$

Why is this the same? If $$V_0(\Phi) < 0$$, I am paid $$-V_0$$ to start. I put that money in the bond. Now my starting value is $$0$$, and my final value is even bigger. So I'm back in the first form.

Numbers. Take Example 1 from p.60, where $$r = 0$$ and $$C = 20$$. Buy 1 share, sell 3 options: cost $$40$$. Borrow that $$40$$ in the bond, so $$V_0 = 40 - 40 = 0$$. At time $$1$$ the holding is worth $$50$$ and I repay $$40$$, so $$V_1 = 10$$ in both cases. Then $$V_1 \ge 0$$ and $$P(V_1 > 0) = 1 > 0$$. That's an arbitrage strategy. The principle says the price $$C = 20$$ can't happen.
