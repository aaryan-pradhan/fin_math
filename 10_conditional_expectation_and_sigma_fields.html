10 — Conditional Expectation & σ-Fields

Rigorously connecting independence, sub-σ-fields, the Law of Iterated Expectations, and operational rules.

Step 1: Independence of Random Variables & σ-Fields

Independent σ-Fields: Two sub-σ-fields 𝒢, ℋ ⊆ ℱ are independent if for all A ∈ 𝒢 and all B ∈ ℋ:

  P(A ∩ B) = P(A) P(B)

Independent Random Variables: ξ and η are independent ⟺ their generated σ-fields σ(ξ) and σ(η) are independent, where:

  σ(ξ) = { ξ⁻¹(B) ⊆ Ω : B ∈ ℬ(ℝ) }

Step 2: What is E(X | 𝒢)?

E(X | 𝒢) is a RANDOM VARIABLE, not a single number.

• E(X | Y = y) is a single real number (the estimate when Y(ω) = y).
• E(X | Y) = E(X | σ(Y)) is a random variable that assigns E(X | Y = y) whenever Y(ω) = y.
• E(X | 𝒢) is the general random variable for any sub-σ-field 𝒢 ⊆ ℱ.

Formal Definition: Y = E(X | 𝒢) is the unique (a.s.) random variable satisfying:

  1. Y is 𝒢-measurable: σ(Y) ⊆ 𝒢. Y cannot see finer details than 𝒢 allows and is forced to be constant on every information block G ∈ 𝒢.

  2. Integral Matching (For all G ∈ 𝒢): ∫G Y dP = ∫G X dP. Since Y is constant (cG) on block G, this reduces to cG · P(G) = ∫G X dP ⟹ cG = ∫G X dP / P(G). Condition 2 forces Y to equal the exact average of X over each block G.

  3. Unique (a.s.): Any two random variables Y₁, Y₂ satisfying (1) & (2) must be equal everywhere except on a set of probability zero (P(Y₁ ≠ Y₂) = 0).

Step 3: Law of Iterated Expectations (Tower Property)

Theorem:   E( E(X | Y) ) = E(X)   and generally   E( E(X | 𝒢) ) = E(X)

Proof via Joint Densities:
  E( E(X | Y) ) = ∫−∞∞ [ ∫−∞∞ x fX|Y=y(x) dx ] fY(y) dy
                  = ∬ℝ² x fX|Y=y(x) fY(y) dx dy
                  = ∬ℝ² x f(x, y) dx dy
                  = ∫−∞∞ x [ ∫−∞∞ f(x, y) dy ] dx = ∫−∞∞ x fX(x) dx = E(X)

Tail Probability Application: Setting X = 𝟏{X > t} gives P(X > t) = E( P(X > t | Y) ).

Step 4: Operational Rules

1. Linearity: For constants a, b ∈ ℝ:
  E(aX + bY | 𝒢) = a E(X | 𝒢) + b E(Y | 𝒢)

2. Taking Out What Is Known: If Z is 𝒢-measurable:
  E(Z · X | 𝒢) = Z · E(X | 𝒢)

3. Independence Rule: If X is independent of 𝒢:
  E(X | 𝒢) = E(X)
