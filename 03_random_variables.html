03 — Random Variables & Measurability

Un-rushed, line-by-line breakdown built from ground-truth Socratic session.

Step 1: Definition of a Measurable Function

Given a measurable space (Ω, ℱ), a function X : Ω → ℝ is said to be ℱ-measurable if:

  [X ∈ B] ∈ ℱ    ∀ B ∈ ℬ(ℝ)

where:
  [X ∈ B] = {ω ∈ Ω : X(ω) ∈ B} = X⁻¹(B)
  ℬ(ℝ) is the Borel σ-field on ℝ (generated by open/closed intervals).

Step 2: Definition of a Random Variable

If (Ω, ℱ, P) is a probability space, then such an ℱ-measurable function X : Ω → ℝ is called a random variable (r.v.).

Why measurability matters: We assign probabilities to events in ℱ. Requiring X⁻¹(B) ∈ ℱ guarantees that P(X ∈ B) = P({ω : X(ω) ∈ B}) is always well-defined.

Step 3: Concrete Coin-Toss Example

Let Ω = {H, T},   ℱ = { ∅, {H}, {T}, {H, T} }.
Define X = number of heads:   X(H) = 1,   X(T) = 0.

Checking pre-images of generating intervals (-∞, x]:

Range of xPre-image X⁻¹((-∞, x])Belongs to ℱ?
x < 0∅✅ Yes (∅ ∈ ℱ)
0 ≤ x < 1{T}✅ Yes ({T} ∈ ℱ)
x ≥ 1{H, T}✅ Yes ({H, T} ∈ ℱ)

Since all pre-images lie in ℱ, X is an ℱ-measurable random variable.

Step 4: Dependence on Information (The Trivial σ-field Counterexample)

Measurability is a joint property of both X and ℱ.

Suppose we restrict our information to the trivial σ-field: ℱtrivial = { ∅, {H, T} }.

For 0 ≤ x < 1, X⁻¹((-∞, x]) = {T}.
Since {T} ∉ ℱtrivial, X is NOT measurable with respect to ℱtrivial.

Step 5: The σ-field Generated by X, denoted σ(X)

The σ-field generated by a random variable X, denoted σ(X), is the smallest σ-field on Ω that makes X measurable:

  σ(X) = { X⁻¹(B) : B ∈ ℬ(ℝ) }

Physical Meaning: σ(X) contains exactly all events in Ω whose occurrence can be decided purely by observing the output value of X(ω).

For our coin toss X:
  • X⁻¹((-2, -1)) = ∅
  • X⁻¹((0.5, 1.5)) = {H}
  • X⁻¹((-0.5, 0.5)) = {T}
  • X⁻¹((-1, 10)) = {H, T}
Thus, σ(X) = { ∅, {H}, {T}, {H, T} }.
