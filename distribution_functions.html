Distribution Measure & Cumulative Distribution Function

Un-rushed breakdown of push-forward probability measures and distribution functions (d.f.).

Step 1: The Push-Forward Measure $P_\xi$

Every random variable $\xi : \Omega \to \mathbb{R}$ on $(\Omega, \mathcal{F}, P)$ induces a probability measure $P_\xi$ on $(\mathbb{R}, \mathcal{B}(\mathbb{R}))$, defined for all Borel sets $B \in \mathcal{B}(\mathbb{R})$ by: $$P_\xi(B) = P(\xi \in B) = P(\{\omega \in \Omega : \xi(\omega) \in B\})$$
Interpretation: $P_\xi$ is the "distribution" of $\xi$. It transports probability measure $P$ from abstract sample space $\Omega$ to sets on the real line $\mathbb{R}$.

Step 2: Cumulative Distribution Function $F_\xi(x)$

The function $F_\xi : \mathbb{R} \to [0, 1]$ defined by: $$F_\xi(x) = P(\xi \leq x) = P_\xi((-\infty, x])$$ is called the distribution function (d.f.) of $\xi$.

Step 3: Properties of Distribution Functions

Every distribution function $F_\xi$ satisfies three core properties:
  1. Non-Decreasing: If $x_1 < x_2$, then $F_\xi(x_1) \leq F_\xi(x_2)$.
    Proof: $(-\infty, x_1] \subseteq (-\infty, x_2] \implies \{\xi \leq x_1\} \subseteq \{\xi \leq x_2\} \implies P(\xi \leq x_1) \leq P(\xi \leq x_2)$.
  2. Right-Continuous: $\lim_{h \downarrow 0} F_\xi(x + h) = F_\xi(x)$.
    Proof: For sequence $x_n \downarrow x$, events $A_n = \{\xi \leq x_n\}$ form nested decreasing sequence $A_1 \supseteq A_2 \supseteq \cdots$ with $\bigcap_{n=1}^{\infty} A_n = \{\xi \leq x\}$. By continuity of measure from above, $\lim P(A_n) = P(\{\xi \leq x\})$.
  3. Limits at $\pm\infty$: $$\lim_{x \to -\infty} F_\xi(x) = 0 \qquad \text{and} \qquad \lim_{x \to +\infty} F_\xi(x) = 1$$
