02 — Almost Surely & Borel-Cantelli Lemma

Un-rushed, line-by-line breakdown.

Step 1: The Setup

Given a probability space (Ω, ℱ, P) and a sequence of events A1, A2, A3, … ∈ ℱ.

For each integer n ≥ 1, define:
  Bn = ∪i=n∞ Ai = An ∪ An+1 ∪ An+2 ∪ …

Step 2: Understanding Bn for a single outcome ω

For a fixed outcome ω ∈ Ω:
  • ω ∈ Bn iff ω belongs to at least one set in {An, An+1, An+2, …}
  • ω ∉ Bn iff ω belongs to NONE of the sets in {An, An+1, An+2, …}
As n grows, Bn drops early Ai sets. Thus B1 ⊇ B2 ⊇ B3 ⊇ … (written Bn ↓).

Step 3: The Intersection Set E

Define E = ∩n=1∞ Bn = B1 ∩ B2 ∩ B3 ∩ …

An outcome ω ∈ E iff ω ∈ Bn for EVERY n ≥ 1.

Step 4: Characterizing E (The Limsup Event)

  • If ω belongs to finitely many Ai (say the last one is Ak):
    Then for any n > k, ω ∉ Bn. Therefore, ω ∉ E.

  • If ω belongs to infinitely many Ai:
    For every n, there is always some i ≥ n where ω ∈ Ai. Therefore, ω ∈ E.
Conclusion: E = {ω ∈ Ω : ω belongs to infinitely many Ai}. Denoted lim sup An.

Step 5: Continuity of Measure from Above (*1)

Since Bn ↓, probability measure continuity implies:
  P(E) = P(∩n=1∞ Bn) = limn→∞ P(Bn)

Step 6: Union Bound (Subadditivity)

By definition of Bn:
  P(Bn) = P(∪i=n∞ Ai) ≤ Σi=n∞ P(Ai)

Step 7: The Complete Proof Chain

Given that Σi=1∞ P(Ai) < ∞ (convergent series), the tail sum limit is zero:
  limn→∞ Σi=n∞ P(Ai) = 0

Chain of inequalities:
  0 ≤ P(E) = limn→∞ P(Bn) ≤ limn→∞ Σi=n∞ P(Ai) = 0

Therefore: P(E) = 0.

Step 8: Final Physical Meaning

P(E) = 0 means the set of outcomes ω that hit infinitely many Ai events has probability 0.

P(Ec) = 1 means almost surely, the actual outcome ω that occurs in real life belongs to Ec.

In plain words: Almost surely, event Ai will only occur for finitely many indices i, and after some finite cutoff step N, Ai will NEVER occur again.
