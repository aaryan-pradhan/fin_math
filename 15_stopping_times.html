15 — Stopping Times

Definition, equivalent characterisation, and the first-entry time example — all on a filtered probability space (Ω, ℱ, 𝔽, P).

Step 1: Definition

A random variable τ : Ω → {0, 1, 2, …} ∪ {∞} on a filtered probability space (Ω, ℱ, 𝔽, P) is called a stopping time (ST) if:

  {τ ≤ t} ∈ ℱt   for each t = 0, 1, 2, …    — condition ①

Operational meaning: At time t, using only information available up to t, you can determine whether stopping has already occurred. No future peeking. This captures decisions like "stop gambling" or "sell a block of shares at the stock exchange" — if τ = k, you act at time k based only on what you already know by then.

Step 2: Equivalent Characterisation — ① ⟺ ②

Condition ② :  {τ = t} ∈ ℱt for each t.

① ⟹ ②: Write

  {τ = t} = {τ ≤ t} ∩ {τ ≤ t−1}c

{τ ≤ t} ∈ ℱt by ①. {τ ≤ t−1} ∈ ℱt−1 ⊆ ℱt by ①, so its complement is also ∈ ℱt (σ-algebras are closed under complements). Their intersection ∈ ℱt (closed under finite intersections). ∴ {τ = t} ∈ ℱt.

② ⟹ ①: Write

  {τ ≤ t} = ⋃s=0t {τ = s}

Each {τ = s} ∈ ℱs ⊆ ℱt (filtration is nested). Finite union of ℱt-sets ∈ ℱt (σ-algebras are closed under countable unions). ∴ {τ ≤ t} ∈ ℱt.   ■

Step 3: Example — First Entry Time is a ST

Setup: Let (Xn) be a sequence of r.v.'s adapted to (ℱn), and let B ⊆ ℝ be a Borel set.

Claim: τ = min{n : Xn ∈ B} is a stopping time.

Proof: Use condition ②. For each n:

  {τ = n} = {X1 ∉ B} ∩ … ∩ {Xn−1 ∉ B} ∩ {Xn ∈ B}

Each piece lands in ℱn:
 • {Xn ∈ B} ∈ ℱn : Xn is ℱn-measurable (adapted), so preimages of Borel sets land in ℱn.
 • {Xk ∉ B} = {Xk ∈ Bc} ∈ ℱk ⊆ ℱn for k < n (same measurability + filtration nesting).

Finite intersection of ℱn-sets ∈ ℱn. ∴ {τ = n} ∈ ℱn for each n ⟹ τ is a ST.   ■
Pitfall — "last exit time" is NOT a ST: τ = max{n : Xn ∈ B} requires knowing the future (whether Xn+1, Xn+2, … ever re-enter B). At time n you cannot determine this — so {τ = n} ∉ ℱn in general.
