Generated σ-Fields & Doob–Dynkin Lemma

Un-rushed, line-by-line breakdown built from ground-truth Socratic session.

Step 1: σ-field Generated by a Single Random Variable $\sigma(\xi)$

Given a random variable $\xi : \Omega \to \mathbb{R}$, the σ-field generated by $\xi$, denoted $\sigma(\xi)$, consists of all pre-images of Borel sets $B \in \mathcal{B}(\mathbb{R})$: $$\sigma(\xi) = \big\{\{\omega \in \Omega : \xi(\omega) \in B\} : B \in \mathcal{B}(\mathbb{R})\big\} = \{\xi^{-1}(B) : B \in \mathcal{B}(\mathbb{R})\}$$
Key Fact: The collection of pre-images is automatically a valid σ-field on $\Omega$ because inverse images preserve all set operations (complements, countable unions, and intersections).
Let $\Omega = \{\omega_1, \omega_2, \omega_3\}$ with $\xi(\omega_1) = 2$, $\xi(\omega_2) = 2$, $\xi(\omega_3) = 5$.
The Borel sets $B \subset \mathbb{R}$ isolate the atoms $\{\omega_1, \omega_2\}$ and $\{\omega_3\}$. Evaluating all pre-images gives: $$\sigma(\xi) = \{\varnothing, \{\omega_1, \omega_2\}, \{\omega_3\}, \Omega\}$$

Step 2: σ-field Generated by a Family of Random Variables

Given a collection of random variables $\{\xi_i, i \in I\}$, the generated σ-field $\sigma(\xi_i, i \in I)$ is defined as the smallest σ-field containing all events of the form $\{\xi_i \in B\}$ for all $i \in I$ and $B \in \mathcal{B}(\mathbb{R})$: $$\sigma(\xi_i, i \in I) = \sigma\Big(\bigcup_{i \in I} \sigma(\xi_i)\Big)$$
$\omega$-Level Separation Principle: Two outcomes $\omega_a, \omega_b$ can be separated into distinct events in $\sigma(\xi_i, i \in I)$ if and only if there exists at least one index $j \in I$ such that $\xi_j(\omega_a) \neq \xi_j(\omega_b)$.
Adding $\eta(\omega_1) = 0$, $\eta(\omega_2) = 5$, $\eta(\omega_3) = 8$ allows us to isolate the singleton $\{\omega_2\}$ via $\eta^{-1}((4.5, 5.5)) = \{\omega_2\} \in \sigma(\xi, \eta)$.

Step 3: Borel Functions and Composition Measurability

A function $f : \mathbb{R} \to \mathbb{R}$ is a Borel function if for every Borel set $B \in \mathcal{B}(\mathbb{R})$, its pre-image $f^{-1}(B) \in \mathcal{B}(\mathbb{R})$.
Theorem: If $f$ is a Borel function and $\xi$ is a random variable, then the composite function $f(\xi) = f \circ \xi$ is $\sigma(\xi)$-measurable.

Proof: Fix any $B \in \mathcal{B}(\mathbb{R})$. Then: $$\{\omega \in \Omega : f(\xi(\omega)) \in B\} = \{\omega \in \Omega : \xi(\omega) \in f^{-1}(B)\} = \xi^{-1}(f^{-1}(B))$$ Since $f$ is Borel, $A = f^{-1}(B)$ is a Borel set in $\mathbb{R}$. By definition of $\sigma(\xi)$, $\xi^{-1}(A) \in \sigma(\xi)$. ∎

Step 4: Doob–Dynkin Lemma

Lemma (Doob–Dynkin): Let $\xi : \Omega \to \mathbb{R}$ be a random variable. A random variable $\eta : \Omega \to \mathbb{R}$ is $\sigma(\xi)$-measurable if and only if there exists a Borel function $f : \mathbb{R} \to \mathbb{R}$ such that: $$\eta = f(\xi) \qquad (\text{i.e., } \forall \omega \in \Omega,\ \eta(\omega) = f(\xi(\omega)))$$
Physical Interpretation: A random variable $\eta$ is $\sigma(\xi)$-measurable if and only if knowing the value of $\xi(\omega)$ uniquely determines the value of $\eta(\omega)$. No extra randomness or information about $\omega$ is involved.
If $\xi(\omega_1) = 2$, $\xi(\omega_2) = 2$, $\xi(\omega_3) = 5$ and $\eta(\omega_1) = 9$, $\eta(\omega_2) = 9$, $\eta(\omega_3) = 25$:
Since $\eta(\omega_1) = \eta(\omega_2)$ when $\xi(\omega_1) = \xi(\omega_2)$, $\eta$ is $\sigma(\xi)$-measurable.
We construct $f$ by matching outputs on the range of $\xi$: $$f(2) = 9,\quad f(5) = 25 \;\Rightarrow\; f(x) = \tfrac{16}{3}x - \tfrac{5}{3}$$ (or step function $f(x) = 9 \cdot \mathbb{1}_{\{2\}}(x) + 25 \cdot \mathbb{1}_{\{5\}}(x)$).
