Joint Distribution of $W(t)$ and $M(t)$

Brownian Motion · Running Maximum · Reflection Principle

1. Setup

$W(t)$ — Standard Brownian motion at time $t$. A random variable with $W(0) = 0$ and $W(t) \sim \mathcal{N}(0, t)$.
$M(t)$ — Running maximum up to time $t$: $$M(t) = \max_{0 \leq s \leq t} W(s)$$
Key constraints (always true):
  • $M(t) \geq W(t)$ — the max is always at least the current value.
  • $M(t) \geq 0$ — because $W(0) = 0$, so the max is at least $0$.

Goal: Compute $P(W(t) \in I,\ M(t) \in J)$ for arbitrary intervals $I$ and $J$.

2. Disjoint Case

Case A: $I$ above $J$

If $W(t) \in I$ with $I$ above $J$, then $W(t) > M(t)$ — impossible.

$$P(W(t) \in I,\ M(t) \in J) = 0$$

Case B: $I$ below $J$ — Inclusion-Exclusion

Let $I = (a, b]$, $J = (c, d]$ with $a < b \leq c < d$ and $c > 0$. Using rectangle inclusion-exclusion:

$$P(a < W(t) \leq b,\ c < M(t) \leq d)$$ $$= P(W(t)\!\leq\! b, M(t)\!\geq\! c) - P(W(t)\!\leq\! b, M(t)\!\geq\! d) - P(W(t)\!\leq\! a, M(t)\!\geq\! c) + P(W(t)\!\leq\! a, M(t)\!\geq\! d)$$

Each term is evaluated using the Reflection Principle (see §3):

EventSubstitutionResult
$P(W \leq b,\ M \geq c)$$a=c,\ y=c-b$$1 - \Phi\!\left(\frac{2c-b}{\sqrt{t}}\right)$
$P(W \leq b,\ M \geq d)$$a=d,\ y=d-b$$1 - \Phi\!\left(\frac{2d-b}{\sqrt{t}}\right)$
$P(W \leq a,\ M \geq c)$$a=c,\ y=c-a$$1 - \Phi\!\left(\frac{2c-a}{\sqrt{t}}\right)$
$P(W \leq a,\ M \geq d)$$a=d,\ y=d-a$$1 - \Phi\!\left(\frac{2d-a}{\sqrt{t}}\right)$
$$P(a < W(t) \leq b,\ c < M(t) \leq d) = -\Phi\!\left(\tfrac{2c-b}{\sqrt{t}}\right) + \Phi\!\left(\tfrac{2d-b}{\sqrt{t}}\right) + \Phi\!\left(\tfrac{2c-a}{\sqrt{t}}\right) - \Phi\!\left(\tfrac{2d-a}{\sqrt{t}}\right)$$

3. The Reflection Principle

Step 1: Hitting Time

For $a > 0$, define the first hitting time: $$\tau_a = \inf\{s \geq 0 : W(s) = a\}$$ Key equivalence: $\{M(t) > a\} = \{\tau_a \leq t\}$, and $W(\tau_a) = a$ exactly.

Step 2: Strong Markov Property

After $\tau_a$, the future increments $W(\tau_a + s) - W(\tau_a)$ are independent of the past and form a fresh standard BM $\tilde{W}(s)$. $$W(t) = a + \tilde{W}(t - \tau_a) \quad \text{for } t > \tau_a$$

Step 3: Reflected Path $W^*(t)$

Define the reflected process: $$W^*(t) = \begin{cases} W(t) & t \leq \tau_a \\ 2a - W(t) & t > \tau_a \end{cases}$$ After $\tau_a$: flip every value across the mirror line $W = a$. Since $\tilde{W}$ is symmetric, $-\tilde{W} \overset{d}{=} \tilde{W}$, so $W^*(t) \overset{d}{=} W(t)$.

Step 4: The Bijection

On $\{\tau_a \leq t\}$, reflecting $W(t) \leq a - y$ gives $W^*(t) \geq a + y$:

$$\{W(t) \leq a - y\} \cap \{\tau_a \leq t\} \;\longleftrightarrow\; \{W^*(t) \geq a+y\} \cap \{\tau_a \leq t\}$$

Step 5: Full Proof

(1)$P(W(t) \leq a-y,\ M(t) > a) = P(W(t)\leq a-y,\ \tau_a \leq t)$
(2)$= P(W^*(t) \geq a+y,\ \tau_a \leq t)$    [bijection]
(3)$= P(W(t) \geq a+y,\ \tau_a \leq t)$    [$W^* \overset{d}{=} W$]
(4)$= P(W(t) \geq a+y)$    [continuity + $a>0$ forces $\tau_a \leq t$]
$$P(W(t) \leq a - y,\ M(t) > a) = 1 - \Phi\!\left(\frac{a + y}{\sqrt{t}}\right)$$
Why $a > 0$ is essential: $W(0) = 0 < a$ and $W(t) \geq a$. By continuity, the path must have crossed $a$ — so $\tau_a \leq t$ is automatic, and we can drop that condition. For $a \leq 0$, the path starts at or above $a$, so $W(t) \geq a + y$ does not imply the path ever went down to $a$.

Corollary: Distribution of $M(t)$

Setting $y = 0$ and adding the case $W(t) > a$:

$$P(M(t) > a) = 2\left(1 - \Phi\!\left(\frac{a}{\sqrt{t}}\right)\right), \quad a > 0$$

4. Arbitrary Intervals $I$ and $J$

Decomposition

Split $I$ into disjoint and overlapping parts with $J$:

$$P(W(t) \in I,\ M(t) \in J) = \underbrace{P(W(t) \in I \setminus J,\ M(t) \in J)}_{\text{disjoint — §2}} + \underbrace{P(W(t) \in I \cap J,\ M(t) \in J)}_{\text{overlapping — below}}$$

The Overlapping Case

Let $J' = I \cap J = (c, d]$ with $c \geq 0$. Since $M(t) \geq W(t)$:

$$P(M(t) \in J') = P(W(t) \in J',\ M(t) \in J') + P(W(t) \leq c,\ M(t) \in J')$$
$$P(W(t) \in J',\ M(t) \in J') = \underbrace{P(M(t) \in J')}_{\text{from corollary}} - \underbrace{P(W(t) \leq c,\ M(t) \in J')}_{\text{disjoint case — §2}}$$
Insight: The overlapping case reduces entirely to the tools we already have — the running-max distribution and the disjoint formula. No new machinery needed.

5. Architecture Summary

Arbitrary I, J │ ├── Split: I = (I\J) ∪ (I∩J) │ ├── W(t) ∈ I\J (disjoint from J) │ └── Inclusion-exclusion → 4 terms → Φ formula │ └── W(t) ∈ I∩J = J' (overlap) └── P(W∈J', M∈J') = P(M∈J') − P(W≤c, M∈J') │ │ │ disjoint case → Φ formula │ P(M(t) > a) = 2(1 − Φ(a/√t)) All paths lead to Φ.
