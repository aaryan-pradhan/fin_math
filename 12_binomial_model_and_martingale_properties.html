12 — Binomial Market Model & Martingale Properties

Rigorously building the discrete binomial tree, natural filtrations, sub/super-martingales, multi-step expectations, and the constant mean property.

Step 1: Binomial Market Model & Natural Filtration

Binomial Asset Price: S₀ > 0 fixed, with movement factors 0 < d < u.
At each time step t ∈ {1, 2, …, T}:

  Sₜ = vₜ Sₜ₋₁    where vₜ ∈ {u, d}

Sample Space Ω: Path vectors of length T:
  Ω = { v = (v₁, v₂, …, vₜ) : vⱼ ∈ {u, d} }

Natural Filtration 𝔽 = (ℱₜ)t ≥ 0: Generated by price history ℱₜ = σ(S₀, S₁, …, Sₜ).
• ℱ₀ = { ∅, Ω }
• ℱ₁ = σ(Aᵤ, A_d) = { ∅, Ω, Aᵤ, A_d } where Aᵤ = { v₁ = u }
• ℱₜ ⊂ ℱₜ₊₁ (nested information structure)

Non-Adapted Increment: Yₜ := Sₜ₊₁ - Sₜ is not ℱₜ-measurable because determining { Yₜ = c } requires future move vₜ₊₁ ∉ ℱₜ.

Step 2: Martingale, Submartingale & Supermartingale

Let (Xₜ)t ≥ 0 be an adapted, integrable process (E[|Xₜ|] < ∞).

1. Martingale (MG): E[ Xₜ₊₁ | ℱₜ ] = Xₜ   (P-a.s.)    (Fair game)

2. Submartingale (sub-MG): E[ Xₜ₊₁ | ℱₜ ] ≥ Xₜ   (P-a.s.)    (Expected value grows or stays equal)

3. Supermartingale (super-MG): E[ Xₜ₊₁ | ℱₜ ] ≤ Xₜ   (P-a.s.)    (Expected value shrinks or stays equal)

Binomial Stock Condition: E[ Sₜ₊₁ | ℱₜ ] = Sₜ · E[ vₜ₊₁ ].
If P(vₜ₊₁ = u) = p, then E[ vₜ₊₁ ] = p u + (1-p) d.
Sₜ is a martingale ⟺ p u + (1-p) d = 1.

Step 3: Multi-Step Expectation Theorem

Theorem: If (Xₜ) is a martingale, then for any s ≥ 1:

  E[ Xₜ₊ₛ | ℱₜ ] = Xₜ   (P-a.s.)

Proof via Tower Property:
Since ℱₜ ⊆ ℱₜ₊ₛ₋₁:
  E[ Xₜ₊ₛ | ℱₜ ] = E[ E[ Xₜ₊ₛ | ℱₜ₊ₛ₋₁ ] | ℱₜ ]
By martingale property, E[ Xₜ₊ₛ | ℱₜ₊ₛ₋₁ ] = Xₜ₊ₛ₋₁.
  = E[ Xₜ₊ₛ₋₁ | ℱₜ ] = … = E[ Xₜ₊₁ | ℱₜ ] = Xₜ.   ■

Step 4: Corollary — Constant Unconditional Mean

Theorem: For a martingale (Xₜ), E[ Xₜ ] = E[ X₀ ] for all t ≥ 0.

Proof:
1. Since Ω ∈ ℱₜ (as ∅ ∈ ℱₜ and Ω = ∅ᶜ), total expectation gives E[ E[ Z | ℱₜ ] ] = E[ Z ].
2. Taking E[ · ] on both sides of E[ Xₜ₊ₛ | ℱₜ ] = Xₜ yields E[ Xₜ₊ₛ ] = E[ Xₜ ].
3. Setting t = 0: E[ Xₛ ] = E[ X₀ ]   ∀ s ≥ 0.   ■

For Submartingales: E[ Yₜ₊ₛ | ℱₜ ] ≥ Yₜ ⟹ E[ Yₜ₊ₛ ] ≥ E[ Yₜ ] ≥ E[ Y₀ ].
