Optimal Stopping Theorem

My understanding, built from scratch.

1. Theorem Statement

Given: $(X_t)$ martingale, $\tau$ bounded ST ($\tau \leq c$ a.s. for some constant $c$).
Conclusion: $E[X_\tau] = E[X_0]$.

In plain terms: No stopping strategy can beat a fair game. Expected value at exit = starting value, always.
⚠️ Bounded is essential. Unbounded $\tau$ (e.g. doubling strategy: "quit when I first win") can appear to beat $E[X_0]$ — but only by waiting potentially forever. The theorem doesn't apply.
Unbounded counterexample. Symmetric walk from 0, $\tau$ = first hit of $+1$. The walk hits $+1$ a.s., so $X_\tau = 1$ always and $E[X_\tau] = 1 \ne 0 = E[X_0]$. The catch: $E[\tau] = \infty$, and on the way the walk can sink arbitrarily low.

Doubling, capped at 10 rounds (bounded). Bet 1, 2, 4, … and quit at the first win.
  • A win at round $k$ nets $2^{k-1} - (1 + 2 + \cdots + 2^{k-2}) = +1$. Probability $1 - (\tfrac12)^{10} = \tfrac{1023}{1024}$.
  • Losing all 10 rounds costs $1 + 2 + \cdots + 512 = 1023$. Probability $\tfrac1{1024}$.
$E = \tfrac{1023}{1024}(1) - \tfrac{1}{1024}(1023) = 0$ ✅. A frequent small win is paid for by a rare huge loss.

2. Proof

Step 1: By the stopped process theorem, $Z_t = X_{t \wedge \tau}$ is a MG.

Step 2: Every MG has constant mean. By tower property + MG property iterated: $$E[Z_t] = E[Z_0] = E[X_0] \quad \forall\, t$$ Step 3: Set $t = c$. Since $\tau \leq c$ a.s.: $c \wedge \tau = \tau$ a.s., so $Z_c = X_\tau$ a.s.

Step 4: Combine: $$E[X_\tau] = E[Z_c] = E[X_0] \qquad \square$$

4. BM Application: Finding $E[\tau]$

$\tau = \min\{t : W(t) = 2 - 4t\}$ — first time BM hits moving line.

Step 1: $W(t)$ is MG, $W(0)=0$. Apply optimal stopping: $$E[W(\tau)] = 0$$ Step 2: At $\tau$ by definition: $W(\tau) = 2 - 4\tau$. Substitute: $$E[2 - 4\tau] = 0$$ Step 3: Linearity of expectation: $$2 - 4E[\tau] = 0 \implies \boxed{E[\tau] = \tfrac{1}{2}}$$ The trick: optimal stopping converts an unknown distribution of $\tau$ into one-line algebra.
Gambler's ruin with OST (CT-1 Q10). Walk from 0, stop at $+10$ or $-5$. ($\tau$ is not bounded, but $X_{t\wedge\tau}$ stays in $[-5, 10]$, so taking the limit is justified.)
  • MG $X_n$: $10p - 5(1-p) = 0$, so $p = \tfrac13$.
  • MG $X_n^2 - n$: $E[\tau] = E[X_\tau^2] = 100\cdot\tfrac13 + 25\cdot\tfrac23 = 50$.

Practice Questions

Q1. Symmetric walk from 0, stop at $+3$ or $-2$. Find $P(\text{hit } +3)$ and $E[\tau]$.
Answer$3p - 2(1-p) = 0$, so $p = \tfrac25$. $E[\tau] = 9\cdot\tfrac25 + 4\cdot\tfrac35 = \tfrac{18 + 12}{5} = 6$. Shortcut: $E[\tau] = AB = 3\cdot 2$.
Q2. $\tau = \min\{t : W(t) = 3 - 6t\}$. Find $E[\tau]$.
Answer$E[W(\tau)] = 0$, so $E[3 - 6\tau] = 0$, giving $E[\tau] = \tfrac12$.
Q3. Try the same method on $\tau = \min\{t : W(t) = 1 + 2t\}$. What goes wrong?
AnswerYou'd get $1 + 2E[\tau] = 0$, so $E[\tau] = -\tfrac12 < 0$, which is impossible. The line runs away upward, BM may never catch it, and $P(\tau = \infty) > 0$. OST needs $\tau$ bounded (or a limit argument that holds). Always check the hypotheses before doing the algebra.
Q4. Doubling strategy capped at 5 rounds. Distribution of the final wealth and its mean?
Answer$+1$ with probability $1 - \tfrac1{32} = \tfrac{31}{32}$. $-(1+2+4+8+16) = -31$ with probability $\tfrac1{32}$. Mean $= \tfrac{31}{32} - \tfrac{31}{32} = 0$.
Q5. Symmetric walk, $\tau$ = first exit from $(-2, 2)$, i.e. first time $|X_n| = 2$. Find $E[\tau]$.
Answer$X_\tau^2 = 4$ always. MG $X_n^2 - n$ gives $E[\tau] = E[X_\tau^2] = 4$. Sanity check: after 2 steps you're at $\pm2$ with probability $\tfrac12$, otherwise back at 0 and starting over. So $E[\tau] = 2 + \tfrac12E[\tau]$, giving $E[\tau] = 4$ ✅
Q6. $X_n$ is a super-MG (house edge), $X_0 = 100$, $\tau \le 50$. What can you say about $E[X_\tau]$?
Answer$E[X_\tau] \le 100$. The stopped process is a super-MG, so its mean can only fall.
