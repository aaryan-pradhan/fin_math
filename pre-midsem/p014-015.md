# Filtrations, Adapted Processes & Martingales

Rigorously building discrete-time information flow, adapted processes, function composition, conditional expectation partition proofs, and martingale properties.

## Step 1: Filtrations & Adapted Stochastic Processes

**Filtration $\mathbb{F}$:** An increasing sequence of sub-σ-fields on $(\Omega, \mathcal{F}, P)$:

$$\mathcal{F}_0 \subseteq \mathcal{F}_1 \subseteq \mathcal{F}_2 \subseteq \cdots \subseteq \mathcal{F}$$

Each $\mathcal{F}_t$ represents all events observable up to time $t$.

**Adapted Process:** A stochastic process $(X_t)_{t \geq 0}$ is *adapted* to $\mathbb{F}$ if $X_t$ is **$\mathcal{F}_t$-measurable** for every $t$:

$$\{\omega \in \Omega : X_t(\omega) \in B\} \in \mathcal{F}_t \quad \forall B \in \mathcal{B}(\mathbb{R})$$

**$\omega$-Level Example (Coin Flips):** $\Omega = \{HH, HT, TH, TT\}$. At $t = 1$, only toss 1 is observed:

$$\mathcal{F}_1 = \{\varnothing, \Omega, \{HH, HT\}, \{TH, TT\}\}$$

The single event $\{HT\} \notin \mathcal{F}_1$ because at $t=1$, outcome $HT$ cannot be distinguished from $HH$.

**Adapted vs not (same two tosses).** Test: $X_1$ must be constant on each atom of $\mathcal{F}_1$, i.e. on $\{HH,HT\}$ and on $\{TH,TT\}$.

| $\omega$ | $X_1$ = heads so far | $Y_1$ = heads in both tosses |
|---|---|---|
| $HH$ | 1 | 2 |
| $HT$ | 1 | 1 |
| $TH$ | 0 | 1 |
| $TT$ | 0 | 0 |

- $X_1$: 1 on $\{HH,HT\}$, 0 on $\{TH,TT\}$. $\mathcal{F}_1$-measurable ✅

- $Y_1$: 2 on $HH$ but 1 on $HT$, which lie in the same atom. Not $\mathcal{F}_1$-measurable ❌ (it needs toss 2).

## Step 2: Measurable Functions of Adapted Processes

**Theorem:** If $(X_t)_{t \geq 0}$ is adapted to $\mathbb{F}$ and $f: \mathbb{R} \to \mathbb{R}$ is a Borel-measurable function, then $Y_t = f(X_t)$ is also adapted to $\mathbb{F}$.

**Proof via Pre-images:** For any Borel set $B \in \mathcal{B}(\mathbb{R})$:

$$\{\omega \in \Omega : Y_t(\omega) \in B\} = \{\omega \in \Omega : X_t(\omega) \in f^{-1}(B)\}$$

- Since $f$ is Borel-measurable, $A = f^{-1}(B) \in \mathcal{B}(\mathbb{R})$.

- Since $X_t$ is $\mathcal{F}_t$-measurable, $\{\omega : X_t(\omega) \in A\} \in \mathcal{F}_t$.

- Therefore, $\{\omega : Y_t(\omega) \in B\} \in \mathcal{F}_t$, proving $Y_t$ is $\mathcal{F}_t$-measurable.

Random walk $X_1 = \pm1$ (toss 1 H or T). Then $f(x) = x^2$ gives $Y_1 = 1$ on every $\omega$, a constant, which is trivially adapted. And $f(x) = e^x$ gives $Y_1 = e$ on $\{H\ldots\}$ and $e^{-1}$ on $\{T\ldots\}$, still constant on each atom of $\mathcal{F}_1$ ✅. A function can merge values but can never split an atom.

## Step 3: Discrete-Time Martingale Definition

**Definition:** A stochastic process $(X_t)_{t \geq 0}$ on a filtered probability space $(\Omega, \mathcal{F}, \mathbb{F}, P)$ is a **martingale** relative to $\mathbb{F}$ if:

- **Adapted:** $(X_t)$ is adapted to $\mathbb{F}$.

- **Integrable:** $E[|X_t|] < \infty$ for all $t \geq 0$.

- **Fair Game (a.s.):** $E[X_{t+1} \mid \mathcal{F}_t] = X_t$ ($P$-a.s.)

**Symmetric random walk.** $S_0 = 0$, $S_{n+1} = S_n + \xi_{n+1}$, $\xi = \pm1$ with probability $\tfrac12$ each.

- If $S_3 = 2$: $E[S_4 \mid \mathcal{F}_3] = \tfrac12(3) + \tfrac12(1) = 2 = S_3$ ✅

- In general, $E[S_{n+1} \mid \mathcal{F}_n] = S_n + E[\xi] = S_n + 0$.

- Integrable: $|S_n| \le n$, so $E|S_n| \le n < \infty$ ✅

**Biased walk** with $P(+1) = 0.6$: $E[\xi] = 0.6 - 0.4 = 0.2$. So $E[S_{n+1} \mid \mathcal{F}_n] = S_n + 0.2 \ne S_n$, and $S_n$ is not a martingale. But $S_n - 0.2n$ is.

## Step 4: Rigorous Partition Proof for $E[X \mid \mathcal{G}]$

**Theorem:** If $\mathcal{G} = \sigma(A_1, A_2, \ldots, A_k)$ is generated by a partition of $\Omega$ into disjoint sets with $P(A_i) > 0$, then for any $\omega \in A_i$:

$$E[X \mid \mathcal{G}](\omega) = c_i = \frac{\int_{A_i} X\, dP}{P(A_i)} = \frac{E[X \cdot \mathbb{1}_{A_i}]}{P(A_i)}$$

**Proof:**

- **Measurability:** Since $Y = E[X \mid \mathcal{G}]$ is $\mathcal{G}$-measurable, $\sigma(Y) \subseteq \mathcal{G}$. $Y$ cannot break atoms $A_i$, so $Y(\omega) = \sum c_i \mathbb{1}_{A_i}(\omega)$.

- **Integral Matching:** For set $G = A_i \in \mathcal{G}$, the definition requires $\int_{A_i} Y\, dP = \int_{A_i} X\, dP$.

- Substituting $Y(\omega) = c_i$ on $A_i$ yields: $c_i \int_{A_i} dP = c_i P(A_i) = \int_{A_i} X\, dP$.

- Dividing by $P(A_i) > 0$ gives $c_i = E[X \cdot \mathbb{1}_{A_i}] / P(A_i)$. ■

Fair die, $X(\omega) = \omega$, $\mathcal{G}$ generated by low $L = \{1,2,3\}$ and high $H = \{4,5,6\}$. Each $c_i$ is the average of $X$ over its atom:

$$c_L = \frac{(1+2+3)\cdot\tfrac16}{\tfrac12} = 2,\qquad c_H = \frac{(4+5+6)\cdot\tfrac16}{\tfrac12} = 5$$

So $E[X \mid \mathcal{G}] = 2$ on $L$ and $5$ on $H$. Check the tower property: $E\big[E[X \mid \mathcal{G}]\big] = \tfrac12\cdot 2 + \tfrac12\cdot 5 = 3.5 = E[X]$ ✅

## Step 5: Concrete Coin-Flip Martingale Calculation

<!-- anim: walk path=udud step=1 label="S_n" say="A fair coin-flip walk: one step up or down each toss." -->

**Setup:** $\Omega = \{HH, HT, TH, TT\}$, equal prob $\tfrac14$. Partition of $\mathcal{F}_1$: $A_1 = \{HH, HT\}$, $A_2 = \{TH, TT\}$. Given $X_2$ values: $X_2(HH) = 3$, $X_2(HT) = 1$, $X_2(TH) = -1$, $X_2(TT) = -3$.

**1. Calculation for Atom $A_1 = \{HH, HT\}$:**

$$P(A_1) = \tfrac12, \quad \int_{A_1} X_2\, dP = 3\left(\tfrac14\right) + 1\left(\tfrac14\right) = 1$$

$$E[X_2 \mid \mathcal{F}_1](HH) = \frac{1}{1/2} = 2 \implies X_1(HH) = 2$$

**2. Calculation for Atom $A_2 = \{TH, TT\}$:**

$$P(A_2) = \tfrac12, \quad \int_{A_2} X_2\, dP = (-1)\left(\tfrac14\right) + (-3)\left(\tfrac14\right) = -1$$

$$E[X_2 \mid \mathcal{F}_1](TH) = \frac{-1}{1/2} = -2 \implies X_1(TH) = -2$$

Constant mean check: $E[X_2] = \tfrac14(3 + 1 - 1 - 3) = 0$ and $E[X_1] = \tfrac12(2) + \tfrac12(-2) = 0$. So $X_0 = 0$.

## Practice Questions

**Q1.** Two tosses. Is $Z = \mathbb{1}\{\text{toss 2 is H}\}$ $\mathcal{F}_1$-measurable?

Answer

No. $Z(HH) = 1$ and $Z(HT) = 0$, but $HH$ and $HT$ lie in the same atom $\{HH, HT\}$ of $\mathcal{F}_1$. It is $\mathcal{F}_2$-measurable.

**Q2.** Symmetric random walk, $S_3 = -1$. Find $E[S_5 \mid \mathcal{F}_3]$.

Answer

$-1$. Multi-step martingale property: $E[S_{t+s} \mid \mathcal{F}_t] = S_t$. Directly: $S_5 = S_3 + \xi_4 + \xi_5$, and the future steps have mean 0.

**Q3.** Is $S_n^2$ a martingale for the symmetric walk? If not, fix it.

Answer

$E[S_{n+1}^2 \mid \mathcal{F}_n] = E[(S_n + \xi)^2 \mid \mathcal{F}_n] = S_n^2 + 2S_nE[\xi] + E[\xi^2] = S_n^2 + 1$. It is not a martingale (it is a sub-MG). $S_n^2 - n$ is a martingale. Check with $S_2 = 2$: $E[S_3^2] = \tfrac12(9) + \tfrac12(1) = 5 = 4 + 1$.

**Q4.** Fair die, $X = \omega$, $\mathcal{G} = \sigma(\{1,2\}, \{3,4,5,6\})$. Compute $E[X \mid \mathcal{G}]$ and check $E[E[X \mid \mathcal{G}]] = 3.5$.

Answer

On $\{1,2\}$: $(1+2)/2 = 1.5$. On $\{3,4,5,6\}$: $(3+4+5+6)/4 = 4.5$. Check: $\tfrac13(1.5) + \tfrac23(4.5) = 0.5 + 3 = 3.5$ ✅

**Q5.** Walk with $P(+1) = 0.7$, $P(-1) = 0.3$. Find $c$ such that $S_n - cn$ is a martingale.

Answer

$E[\xi] = 0.7 - 0.3 = 0.4$. $E[S_{n+1} - c(n+1) \mid \mathcal{F}_n] = S_n + 0.4 - cn - c$. This equals $S_n - cn$ iff $c = 0.4$.

**Q6.** $\xi_k$ i.i.d., equal to $2$ or $0$ with probability $\tfrac12$ each. $M_n = \xi_1\xi_2\cdots\xi_n$. Martingale? Find the distribution of $M_3$ and $E[M_3]$.

Answer

$E[M_{n+1} \mid \mathcal{F}_n] = M_n E[\xi] = M_n \cdot 1$, so it is a martingale. $M_3 = 8$ with probability $\tfrac18$ (all 2s), else $0$. $E[M_3] = 8\cdot\tfrac18 = 1 = M_0$. The mean is constant even though $M_n \to 0$ a.s.
