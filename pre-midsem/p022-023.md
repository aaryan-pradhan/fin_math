# Stopped Process & Martingale Preservation

My understanding, built from scratch.

## 1. Motivating Question

If $(X_t)$ is a martingale, can a clever stopping time $\tau$ give $E[X_\tau] > E[X_0]$? **Answer: No.** The stopped process is also a martingale, so $E[X_\tau] = E[X_0]$ always.

## 2. The Stopped Process

Define $Z_t = X_{t \wedge \tau}$ where $a \wedge b = \min(a,b)$.

$$Z_t = \begin{cases} X_t & \tau > t \text{ (still running)} \\ X_\tau & \tau \leq t \text{ (frozen at stop)} \end{cases}$$

**Example:** $\tau(\omega)=2$, $T=4$:

| $t$ | $Z_t(\omega)$ |
|---|---|
| 0 | $X_0$ |
| 1 | $X_1$ |
| 2 | $X_2$ |
| 3 | $X_2$ (frozen) |
| 4 | $X_2$ (frozen) |

**With numbers.** Walk steps $+1, +1, -1, +1$, so $X = 0, 1, 2, 1, 2$. $\tau$ = first hit of 2 = 2.

| $t$ | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| $X_t$ | 0 | 1 | 2 | 1 | 2 |
| $Z_t = X_{t\wedge\tau}$ | 0 | 1 | 2 | 2 | 2 |

After $\tau$, $Z$ ignores what $X$ does: $X_3 = 1$, but $Z_3 = 2$.

## 3. Explicit Formula

$$Z_{t+1} = \sum_{k=0}^{t} X_k \mathbf{1}_{\{\tau=k\}} + X_{t+1}\mathbf{1}_{\{\tau > t\}}$$

**Term 1:** Picks up $X_\tau$ if already stopped at some $k \leq t$. **Term 2:** Continues with $X_{t+1}$ if not yet stopped.

**Trace for $\tau(\omega)=2$, computing $Z_3$:** Term 1: $X_0 \cdot 0 + X_1 \cdot 0 + X_2 \cdot 1 = X_2$ (since $\tau=2$) Term 2: $X_3 \cdot \mathbf{1}_{\tau > 2} = X_3 \cdot 0 = 0$ $\Rightarrow Z_3 = X_2$ ✓

## 4. Theorem: $(Z_t)$ is a Martingale

**Proof of $E(Z_{t+1} \mid \mathcal{F}_t) = Z_t$:**

$$E(Z_{t+1} \mid \mathcal{F}_t) = E\!\left(\sum_{k=0}^t X_k \mathbf{1}_{\tau=k} + X_{t+1}\mathbf{1}_{\tau>t} \;\middle|\; \mathcal{F}_t\right)$$

**Term 1 pulls out:** Each $X_k$ ($k \leq t$) and $\mathbf{1}_{\tau=k}$ are $\mathcal{F}_t$-measurable (adapted process + stopping time definition), so the sum is a constant w.r.t. $\mathcal{F}_t$.

**Term 2:** $\mathbf{1}_{\tau>t} \in \mathcal{F}_t$ (since $\{\tau>t\} = \{\tau \leq t\}^c \in \mathcal{F}_t$), so pull it out:

$$= \mathbf{1}_{\{\tau>t\}} \cdot E(X_{t+1} \mid \mathcal{F}_t) = \mathbf{1}_{\{\tau>t\}} \cdot X_t \quad \text{(MG property)}$$

**Combine:**

$$= \sum_{k=0}^t X_k \mathbf{1}_{\tau=k} + \mathbf{1}_{\{\tau>t\}} X_t = Z_t \checkmark$$

**Numeric check.** Two-step walk, $\tau$ = first time $X = 1$, capped at 2.

| $\omega$ | $X_1, X_2$ | $\tau$ | $Z_1$ | $Z_2$ |
|---|---|---|---|---|
| $HH$ | 1, 2 | 1 | 1 | 1 |
| $HT$ | 1, 0 | 1 | 1 | 1 |
| $TH$ | −1, 0 | 2 | −1 | 0 |
| $TT$ | −1, −2 | 2 | −1 | −2 |

- Atom $\{HH, HT\}$: $E[Z_2 \mid \mathcal{F}_1] = \tfrac12(1 + 1) = 1 = Z_1$ ✅ (frozen)

- Atom $\{TH, TT\}$: $E[Z_2 \mid \mathcal{F}_1] = \tfrac12(0 - 2) = -1 = Z_1$ ✅ (still running)

- $E[Z_2] = \tfrac14(1 + 1 + 0 - 2) = 0 = Z_0$ ✅

## 5. Stopping Time — Coin Flip Grounding

$\Omega = \{HHH, HHT, HTH, HTT, THH, THT, TTH, TTT\}$, $T=3$.

✅ **Valid ST:** $\tau =$ "first time flip is H" $\{\tau=1\} = \{H\_ \_\} \in \mathcal{F}_1$ — decided from flip 1 alone. ✓ $\{\tau=2\} = \{TH\_\} \in \mathcal{F}_2$ — decided from flips 1,2 alone. ✓

❌ **Invalid ST:** $\tau =$ "last time flip is H" $\{\tau=1\} = \{HTT\}$ — at $t=1$ seeing H, you can't know flips 2,3 are both T. $\{HTT\} \notin \mathcal{F}_1$. Requires future info. ✗

## 6. Key Consequence

If $(X_t)$ is a martingale: no stopping strategy beats $E[X_0]$.

$$E[X_\tau] = E[Z_\tau] = E[Z_0] = E[X_0]$$

You cannot exploit a fair game by choosing when to quit.

## Practice Questions

**Q1.** $X = 0, -1, 0, 1, 2, 1$ for $t = 0, \ldots, 5$. $\tau$ = first time $X = 1$. Write $Z_0, \ldots, Z_5$.

Answer

$\tau = 3$. $Z = 0, -1, 0, 1, 1, 1$.

**Q2.** Three-step walk, $\tau$ = first time $X = -1$, else 3. Enumerate all 8 paths and compute $E[X_\tau]$.

Answer

- Paths $T{\_}{\_}$ (4 of them): $\tau = 1$, $X_\tau = -1$. Total $-4$.

- $HHH$: 3. $HHT$: 1. $HTH$: $X = 1, 0, 1$, so 1. $HTT$: $X = 1, 0, -1$, so $\tau = 3$ and $X_\tau = -1$.

$E[X_\tau] = \tfrac18(-4 + 3 + 1 + 1 - 1) = 0$ ✅

**Q3.** Two-step walk. "Cheat" rule: $\tau = 1$ if toss 2 will be T, else $\tau = 2$. Compute $E[X_\tau]$. Why doesn't the theorem stop this?

Answer

$HH$: $\tau = 2$, $X = 2$. $HT$: $\tau = 1$, $X = 1$. $TH$: $\tau = 2$, $X = 0$. $TT$: $\tau = 1$, $X = -1$. $E[X_\tau] = \tfrac14(2 + 1 + 0 - 1) = 0.5 > 0$. This $\tau$ is not a stopping time: $\{\tau = 1\}$ depends on toss 2. The proof uses $\mathbf{1}_{\{\tau > t\}} \in \mathcal{F}_t$, which fails here.

**Q4.** In the formula for $Z_{t+1}$, with $\tau(\omega) = 5$, compute $Z_3$ term by term.

Answer

$Z_3 = \sum_{k=0}^{2} X_k\mathbf{1}_{\tau=k} + X_3\mathbf{1}_{\tau>2}$. All indicators $\mathbf{1}_{\tau=k}$ for $k \le 2$ are 0, and $\mathbf{1}_{\tau>2} = 1$. So $Z_3 = X_3$: not yet stopped.
