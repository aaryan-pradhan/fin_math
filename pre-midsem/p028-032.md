# Brownian Motion with Drift & Exit Probabilities

Continuous Gambler's Ruin, Rigorous Floor Limits, and First Passage Times.

## 1. Definition of Brownian Motion with Drift

<!-- anim: drift_barriers mu=0.5 a=-1 b=1.5 say="Brownian motion with drift between two barriers: which one is hit first?" -->

A stochastic process $\{X(t), t \ge 0\}$ is **Brownian Motion with drift $\mu$** if:

$$X(t) = \mu t + W(t)$$

where $W(t)$ is standard Brownian motion. Thus $X(t) \sim \mathcal{N}(\mu t, t)$ with stationary, independent increments.

## 2. Squeeze Theorem Proof for Random Walk Limit

Set time step $\Delta t$, spatial step $\Delta x = \sqrt{\Delta t}$, and move right ($+\Delta x$) with prob $p = \frac{1}{2}(1 + \mu\sqrt{\Delta t})$. Number of steps by time $t$ is $N(t) = \lfloor t / \Delta t \rfloor$. Using $\frac{t}{\Delta t} - 1 < \lfloor t / \Delta t \rfloor \le \frac{t}{\Delta t}$:

$$\mu t - \mu \Delta t < \mathbb{E}[X(t)] \le \mu t \implies \lim_{\Delta t \to 0} \mathbb{E}[X(t)] = \mu t \quad \text{(Squeeze Theorem)}$$

$$\text{Var}(X(t)) = \Delta t (1 - \mu^2 \Delta t) \left\lfloor \frac{t}{\Delta t} \right\rfloor \implies \lim_{\Delta t \to 0} \text{Var}(X(t)) = t$$

## 3. Continuous to Discrete Coordinate Mapping

Map continuous domain $[-B, A]$ to discrete grid $\{0, 1, \dots, N\}$ via:

$$g(x) = \left\lfloor \frac{x + B}{\Delta x} \right\rfloor$$

- Lower Barrier ($x = -B$) $\mapsto 0$

- Starting Point ($x$) $\mapsto i = \left\lfloor \frac{x + B}{\Delta x} \right\rfloor$

- Upper Barrier ($x = A$) $\mapsto N = \left\lfloor \frac{A + B}{\Delta x} \right\rfloor$

## 4. Floor Function Limit for Exit Probabilities

Let $r = \frac{q}{p} = \frac{1 - \mu \Delta x}{1 + \mu \Delta x}$. Since $\lim_{\Delta x \to 0} r^{1/\Delta x} = e^{-2\mu}$:

$$r^{\frac{B}{\Delta x}} \le r^{\lfloor B/\Delta x \rfloor} < r^{-1} \cdot \left(r^{\frac{1}{\Delta x}}\right)^B \implies \lim_{\Delta x \to 0} r^{\lfloor B/\Delta x \rfloor} = e^{-2\mu B}$$

Substituting into discrete Gambler's Ruin $P(x) = \frac{1 - r^i}{1 - r^N}$ yields:

$$P(x) = \mathbb{P}(X(t) \text{ hits } A \text{ before } -B \mid X(0) = x) = \frac{1 - e^{-2\mu(x+B)}}{1 - e^{-2\mu(A+B)}}$$

## 5. Special Cases

- **Negative Drift ($\mu < 0$):** Letting $B \to \infty$, the probability of ever reaching $+A$ starting from $0$ is:

$$\mathbb{P}(\text{Max } \ge A) = e^{2\mu A}$$

The maximum $M = \sup_{t \ge 0} X(t)$ is Exponentially distributed with rate $-2\mu > 0$.

- **Zero Drift ($\mu = 0$):** Taking $\mu \to 0$ via L'Hôpital's rule:

$$P(x) = \frac{x+B}{A+B}$$

## 6. Application: Optimal Stock Option Exercise Threshold

Suppose current stock price $X(0) = 0$ follows BM with negative drift $\mu = -d < 0$. We hold an option to buy one unit at fixed strike price $A$. If we set a rule to exercise as soon as stock price reaches target $x > A$:

$$\text{Gain upon exercise} = x - A, \qquad \mathbb{P}(\text{ever hits } x) = e^{2\mu x} = e^{-2dx}$$

Expected gain function:

$$f(x) = (x - A) e^{-2dx}$$

Setting derivative $f'(x) = e^{-2dx} [1 - 2d(x - A)] = 0$ gives the optimal target:

$$x^* = A + \frac{1}{2d}$$

Maximum expected gain: $f(x^*) = \frac{1}{2d} e^{-2dA - 1}$.
