# Random Variables & Measurability

Un-rushed, line-by-line breakdown built from ground-truth Socratic session.

## Step 1: Definition of a Measurable Function

Given a measurable space $(\Omega, \mathcal{F})$, a function $X : \Omega \to \mathbb{R}$ is said to be **$\mathcal{F}$-measurable** if:

$$[X \in B] \in \mathcal{F} \quad \forall B \in \mathcal{B}(\mathbb{R})$$

where:

- $[X \in B] = \{\omega \in \Omega : X(\omega) \in B\} = X^{-1}(B)$

- $\mathcal{B}(\mathbb{R})$ is the Borel σ-field on $\mathbb{R}$ (generated by open/closed intervals).

Die, $\Omega = \{1,\dots,6\}$. $X(\omega) = 1$ if $\omega$ is even, $0$ if odd. Pre-images of some Borel sets $B$:

| $B$ | $X^{-1}(B)$ |
|---|---|
| $\{1\}$ | $\{2,4,6\}$ |
| $(-5, 0.5)$ | $\{1,3,5\}$ |
| $[0, 1]$ | $\Omega$ |
| $\{7\}$ | $\varnothing$ |

$X$ takes only the values 0 and 1, so every pre-image is one of these 4 sets.

## Step 2: Definition of a Random Variable

If $(\Omega, \mathcal{F}, P)$ is a probability space, then such an $\mathcal{F}$-measurable function $X : \Omega \to \mathbb{R}$ is called a **random variable (r.v.)**.

**Why measurability matters:** We assign probabilities to events in $\mathcal{F}$. Requiring $X^{-1}(B) \in \mathcal{F}$ guarantees that $P(X \in B) = P(\{\omega : X(\omega) \in B\})$ is always well-defined.

Fair die, $X$ = "is even" as above. Each probability is computed by pulling back to $\Omega$:

$$P(X = 1) = P(\{2,4,6\}) = \tfrac36 = \tfrac12$$

Two fair tosses, $X$ = number of heads: $X(HH) = 2$, $X(HT) = X(TH) = 1$, $X(TT) = 0$.

$$P(X = 1) = P(\{HT, TH\}) = \tfrac24 = \tfrac12,\qquad P(X \ge 1) = P(\{HH, HT, TH\}) = \tfrac34$$

## Step 3: Concrete Coin-Toss Example

Let $\Omega = \{H, T\}$, $\mathcal{F} = \{\varnothing, \{H\}, \{T\}, \{H, T\}\}$. Define $X$ = number of heads: $X(H) = 1$, $X(T) = 0$.

Checking pre-images of generating intervals $(-\infty, x]$:

| Range of $x$ | Pre-image $X^{-1}((-\infty, x])$ | Belongs to $\mathcal{F}$? |
|---|---|---|
| $x < 0$ | $\varnothing$ | ✅ Yes ($\varnothing \in \mathcal{F}$) |
| $0 \leq x < 1$ | $\{T\}$ | ✅ Yes ($\{T\} \in \mathcal{F}$) |
| $x \geq 1$ | $\{H, T\}$ | ✅ Yes ($\{H, T\} \in \mathcal{F}$) |

Since all pre-images lie in $\mathcal{F}$, **$X$ is an $\mathcal{F}$-measurable random variable**.

## Step 4: Dependence on Information (The Trivial σ-field Counterexample)

Measurability is a joint property of both $X$ and $\mathcal{F}$.

Suppose we restrict our information to the trivial σ-field: $\mathcal{F}_{\text{trivial}} = \{\varnothing, \{H, T\}\}$.

For $0 \leq x < 1$, $X^{-1}((-\infty, x]) = \{T\}$. Since $\{T\} \notin \mathcal{F}_{\text{trivial}}$, $X$ is **NOT measurable** with respect to $\mathcal{F}_{\text{trivial}}$.

Die, where you are only told "low (1–3) or high (4–6)": $\mathcal{G} = \{\varnothing, \{1,2,3\}, \{4,5,6\}, \Omega\}$.

- $Y = 1$ if $\omega \ge 4$, else $0$. $Y^{-1}(\{1\}) = \{4,5,6\} \in \mathcal{G}$. **Measurable**.

- $X = 1$ if even, else $0$. $X^{-1}(\{1\}) = \{2,4,6\} \notin \mathcal{G}$. **Not measurable**. Being told "high" doesn't tell you "even": the outcome could be 4 or 5.

## Step 5: The σ-field Generated by $X$, denoted $\sigma(X)$

The **σ-field generated by a random variable $X$**, denoted $\sigma(X)$, is the smallest σ-field on $\Omega$ that makes $X$ measurable:

$$\sigma(X) = \{X^{-1}(B) : B \in \mathcal{B}(\mathbb{R})\}$$

**Physical Meaning:** $\sigma(X)$ contains exactly all events in $\Omega$ whose occurrence can be decided purely by observing the output value of $X(\omega)$.

For our coin toss $X$:

- $X^{-1}((-2, -1)) = \varnothing$

- $X^{-1}((0.5, 1.5)) = \{H\}$

- $X^{-1}((-0.5, 0.5)) = \{T\}$

- $X^{-1}((-1, 10)) = \{H, T\}$

Thus, $\sigma(X) = \{\varnothing, \{H\}, \{T\}, \{H, T\}\}$.

Die, three choices of $X$:

| $X$ | $\sigma(X)$ | Size |
|---|---|---|
| $X = 7$ (constant) | $\{\varnothing, \Omega\}$ | 2 |
| $X$ = "is even" | $\{\varnothing, \{2,4,6\}, \{1,3,5\}, \Omega\}$ | 4 |
| $X(\omega) = \omega$ | all subsets | $2^6 = 64$ |

Rule: if $X$ takes $k$ distinct values, $\sigma(X)$ has $2^k$ events. The more $X$ reveals, the bigger $\sigma(X)$.
