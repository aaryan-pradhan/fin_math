# Binomial Market Model & Martingale Properties

Rigorously building the discrete binomial tree, natural filtrations, sub/super-martingales, multi-step expectations, and the constant mean property.

## Step 1: Binomial Market Model & Natural Filtration

<!-- anim: binomial_tree T=2 S0=4 u=2 d=0.5 say="The binomial market: the price moves up by $u$ or down by $d$ each period." -->

**Binomial Asset Price:** $S_0 > 0$ fixed, with movement factors $0 < d < u$. At each time step $t \in \{1, 2, \ldots, T\}$:

$$S_t = v_t S_{t-1} \quad \text{where } v_t \in \{u, d\}$$

**Sample Space $\Omega$:** Path vectors of length $T$:

$$\Omega = \{v = (v_1, v_2, \ldots, v_T) : v_j \in \{u, d\}\}$$

**Natural Filtration $\mathbb{F} = (\mathcal{F}_t)_{t \geq 0}$:** Generated by price history $\mathcal{F}_t = \sigma(S_0, S_1, \ldots, S_t)$.

- $\mathcal{F}_0 = \{\varnothing, \Omega\}$

- $\mathcal{F}_1 = \sigma(A_u, A_d) = \{\varnothing, \Omega, A_u, A_d\}$ where $A_u = \{v_1 = u\}$

- $\mathcal{F}_t \subset \mathcal{F}_{t+1}$ (nested information structure)

**Running example:** $S_0 = 100$, $u = 1.2$, $d = 0.8$, $T = 2$.

| path $v$ | $S_1$ | $S_2$ |
|---|---|---|
| $(u,u)$ | 120 | 144 |
| $(u,d)$ | 120 | 96 |
| $(d,u)$ | 80 | 96 |
| $(d,d)$ | 80 | 64 |

Atoms of $\mathcal{F}_1$: $A_u = \{uu, ud\}$ ($S_1 = 120$) and $A_d = \{du, dd\}$ ($S_1 = 80$). $S_2 = 96$ on both $ud$ and $du$, so $S_2$ alone can't tell them apart. $\mathcal{F}_2 = \sigma(S_0, S_1, S_2)$ can, because $S_1$ differs (120 vs 80).

**Non-Adapted Increment:** $Y_t := S_{t+1} - S_t$ is *not* $\mathcal{F}_t$-measurable because determining $\{Y_t = c\}$ requires future move $v_{t+1} \notin \mathcal{F}_t$.

Running example: on the atom $A_u$, $Y_1 = S_2 - S_1$ equals $144 - 120 = 24$ on $uu$ but $96 - 120 = -24$ on $ud$. It is not constant on an atom of $\mathcal{F}_1$, so it is not $\mathcal{F}_1$-measurable.

## Step 2: Martingale, Submartingale & Supermartingale

Let $(X_t)_{t \geq 0}$ be an adapted, integrable process ($E[|X_t|] < \infty$).

- **Martingale (MG):** $E[X_{t+1} \mid \mathcal{F}_t] = X_t$ ($P$-a.s.) — fair game

- **Submartingale (sub-MG):** $E[X_{t+1} \mid \mathcal{F}_t] \geq X_t$ ($P$-a.s.) — expected value grows or stays equal

- **Supermartingale (super-MG):** $E[X_{t+1} \mid \mathcal{F}_t] \leq X_t$ ($P$-a.s.) — expected value shrinks or stays equal

**Binomial Stock Condition:** $E[S_{t+1} \mid \mathcal{F}_t] = S_t \cdot E[v_{t+1}]$. If $P(v_{t+1} = u) = p$, then $E[v_{t+1}] = pu + (1-p)d$. $S_t$ is a martingale $\iff pu + (1-p)d = 1$.

Running example: solve $1.2p + 0.8(1-p) = 1$, i.e. $0.4p = 0.2$, so $p = \tfrac12$. In general $p = \frac{1-d}{u-d}$.

| $p$ | $E[v] = 1.2p + 0.8(1-p)$ | type |
|---|---|---|
| 0.5 | 1.00 | MG |
| 0.6 | 1.04 | sub-MG |
| 0.4 | 0.96 | super-MG |

Check at $p = 0.5$ on $A_u$: $E[S_2 \mid S_1 = 120] = \tfrac12(144) + \tfrac12(96) = 120 = S_1$ ✅

## Step 3: Multi-Step Expectation Theorem

**Theorem:** If $(X_t)$ is a martingale, then for any $s \geq 1$:

$$E[X_{t+s} \mid \mathcal{F}_t] = X_t \quad (P\text{-a.s.})$$

**Proof via Tower Property:** Since $\mathcal{F}_t \subseteq \mathcal{F}_{t+s-1}$:

$$E[X_{t+s} \mid \mathcal{F}_t] = E\big[E[X_{t+s} \mid \mathcal{F}_{t+s-1}] \mid \mathcal{F}_t\big]$$

By martingale property, $E[X_{t+s} \mid \mathcal{F}_{t+s-1}] = X_{t+s-1}$, so

$$= E[X_{t+s-1} \mid \mathcal{F}_t] = \cdots = E[X_{t+1} \mid \mathcal{F}_t] = X_t. \quad ■$$

Running example, $p = \tfrac12$, two steps from $t = 0$:

$$E[S_2 \mid \mathcal{F}_0] = \tfrac14(144) + \tfrac12(96) + \tfrac14(64) = 36 + 48 + 16 = 100 = S_0\ ✅$$

Tower version: $E[S_2 \mid \mathcal{F}_1] = S_1 \in \{120, 80\}$, then $E[S_1] = \tfrac12(120) + \tfrac12(80) = 100$.

## Step 4: Corollary — Constant Unconditional Mean

**Theorem:** For a martingale $(X_t)$, $E[X_t] = E[X_0]$ for all $t \geq 0$.

**Proof:**

- Since $\Omega \in \mathcal{F}_t$ (as $\varnothing \in \mathcal{F}_t$ and $\Omega = \varnothing^c$), total expectation gives $E[E[Z \mid \mathcal{F}_t]] = E[Z]$.

- Taking $E[\cdot]$ on both sides of $E[X_{t+s} \mid \mathcal{F}_t] = X_t$ yields $E[X_{t+s}] = E[X_t]$.

- Setting $t = 0$: $E[X_s] = E[X_0]$ $\forall s \geq 0$. ■

**For Submartingales:** $E[Y_{t+s} \mid \mathcal{F}_t] \geq Y_t \implies E[Y_{t+s}] \geq E[Y_t] \geq E[Y_0]$.

Sub-MG case $p = 0.6$: $E[S_t] = 100(1.04)^t$. Check $t = 2$ by the table: $0.36(144) + 0.48(96) + 0.16(64) = 51.84 + 46.08 + 10.24 = 108.16 = 100(1.04)^2$ ✅. The mean grows: $100 \to 104 \to 108.16$.

## Practice Questions

**Q1.** $u = 2$, $d = 0.5$. For which $p$ is $S_t$ a martingale?

Answer

$p = \frac{1-d}{u-d} = \frac{0.5}{1.5} = \tfrac13$. Check: $\tfrac13(2) + \tfrac23(0.5) = \tfrac23 + \tfrac13 = 1$ ✅

**Q2.** $S_0 = 50$, $u = 1.1$, $d = 0.9$. Find $E[S_3]$ for (a) $p = 0.5$, (b) $p = 0.7$.

Answer

(a) $E[v] = 0.55 + 0.45 = 1$, a MG, so $E[S_3] = 50$. (b) $E[v] = 0.77 + 0.27 = 1.04$, so $E[S_3] = 50(1.04)^3 = 56.2432$.

**Q3.** Running example with $p = \tfrac12$ (so $S_t$ is a MG). Is $S_t^2$ a MG?

Answer

$E[S_{t+1}^2 \mid \mathcal{F}_t] = S_t^2E[v^2] = S_t^2\cdot\tfrac12(1.44 + 0.64) = 1.04\,S_t^2 > S_t^2$. It is a sub-MG, not a MG. Numbers: $S_0^2 = 10000$, $E[S_1^2] = \tfrac12(14400 + 6400) = 10400$.

**Q4.** $p = 0.6$ (so $m = E[v] = 1.04$). Show $X_t = S_t/m^t$ is a MG and compute $X_1$ on both atoms.

Answer

$E[X_{t+1} \mid \mathcal{F}_t] = \frac{S_tE[v]}{m^{t+1}} = \frac{S_t}{m^t} = X_t$. $X_1 = 120/1.04 \approx 115.38$ on $A_u$ and $80/1.04 \approx 76.92$ on $A_d$. $E[X_1] = 0.6(115.38) + 0.4(76.92) = 100 = X_0$ ✅

**Q5.** Running tree. Which are $\mathcal{F}_1$-measurable: (a) $S_1^2$, (b) $S_2 - S_1$, (c) $\max(S_0, S_1)$, (d) $\mathbb{1}\{S_2 > 100\}$?

Answer

(a) Yes (a function of $S_1$). (b) No ($\pm24$ within $A_u$). (c) Yes: 120 on $A_u$, 100 on $A_d$. (d) No: on $A_u$ it is 1 at $uu$ (144) but 0 at $ud$ (96).
