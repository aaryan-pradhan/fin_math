# Distribution Measure & Cumulative Distribution Function

Un-rushed breakdown of push-forward probability measures and distribution functions (d.f.).

## Step 1: The Push-Forward Measure $P_\xi$

Every random variable $\xi : \Omega \to \mathbb{R}$ on $(\Omega, \mathcal{F}, P)$ induces a probability measure $P_\xi$ on $(\mathbb{R}, \mathcal{B}(\mathbb{R}))$, defined for all Borel sets $B \in \mathcal{B}(\mathbb{R})$ by:

$$P_\xi(B) = P(\xi \in B) = P(\{\omega \in \Omega : \xi(\omega) \in B\})$$

**Interpretation:** $P_\xi$ is the "distribution" of $\xi$. It transports probability measure $P$ from abstract sample space $\Omega$ to sets on the real line $\mathbb{R}$.

Two fair tosses, $\xi$ = number of heads. Push each outcome's $\tfrac14$ onto its value:

| value $x$ | 0 | 1 | 2 |
|---|---|---|---|
| outcomes | $TT$ | $HT, TH$ | $HH$ |
| $P_\xi(\{x\})$ | $\tfrac14$ | $\tfrac12$ | $\tfrac14$ |

Any Borel set: $P_\xi([0.5, 10]) = P_\xi(\{1\}) + P_\xi(\{2\}) = \tfrac34$. $P_\xi((-\infty, 0)) = 0$.

Different $\Omega$, same distribution. Uniform point $\omega \in [0,1]$, and

$$\eta(\omega) = \begin{cases} 0 & \omega < 0.25 \\ 1 & 0.25 \le \omega < 0.75 \\ 2 & \omega \ge 0.75 \end{cases}$$

$P_\eta(\{0\}) = 0.25$, $P_\eta(\{1\}) = 0.5$, $P_\eta(\{2\}) = 0.25$. This is the same as $P_\xi$ above, even though $\Omega$ is completely different. $P_\xi$ only records values and their probabilities, not which $\Omega$ produced them.

## Step 2: Cumulative Distribution Function $F_\xi(x)$

<!-- anim: plot fns="1-np.exp(-x)" x=(0,4) y=(0,1) labels="F_\xi(x)" xlabel="x" ylabel="F" say="A distribution function rises from $0$ to $1$ and never decreases." -->

The function $F_\xi : \mathbb{R} \to [0, 1]$ defined by:

$$F_\xi(x) = P(\xi \leq x) = P_\xi((-\infty, x])$$

is called the **distribution function (d.f.)** of $\xi$.

Number of heads in two tosses: add up the mass at values $\le x$.

$$F_\xi(x) = \begin{cases} 0 & x < 0 \\ \tfrac14 & 0 \le x < 1 \\ \tfrac34 & 1 \le x < 2 \\ 1 & x \ge 2 \end{cases}$$

$F_\xi(-3) = 0$, $F_\xi(0.5) = \tfrac14$, $F_\xi(1) = \tfrac34$, $F_\xi(1.99) = \tfrac34$, $F_\xi(100) = 1$.

Uniform on $[0,1]$: $F(x) = 0$ for $x < 0$, $F(x) = x$ for $0 \le x \le 1$, $F(x) = 1$ for $x > 1$. $F(0.3) = P(U \le 0.3) = 0.3$. No jumps.

Interval probabilities from $F$: $P(a < \xi \le b) = F(b) - F(a)$. Heads: $P(0 < \xi \le 2) = 1 - \tfrac14 = \tfrac34$. Uniform: $P(0.2 < U \le 0.7) = 0.7 - 0.2 = 0.5$.

## Step 3: Properties of Distribution Functions

Every distribution function $F_\xi$ satisfies three core properties:

- **Non-Decreasing:** If $x_1 < x_2$, then $F_\xi(x_1) \leq F_\xi(x_2)$. *Proof:* $(-\infty, x_1] \subseteq (-\infty, x_2] \implies \{\xi \leq x_1\} \subseteq \{\xi \leq x_2\} \implies P(\xi \leq x_1) \leq P(\xi \leq x_2)$.

- **Right-Continuous:** $\lim_{h \downarrow 0} F_\xi(x + h) = F_\xi(x)$. *Proof:* For sequence $x_n \downarrow x$, events $A_n = \{\xi \leq x_n\}$ form nested decreasing sequence $A_1 \supseteq A_2 \supseteq \cdots$ with $\bigcap_{n=1}^{\infty} A_n = \{\xi \leq x\}$. By continuity of measure from above, $\lim P(A_n) = P(\{\xi \leq x\})$.

- **Limits at $\pm\infty$:**

$$\lim_{x \to -\infty} F_\xi(x) = 0 \qquad \text{and} \qquad \lim_{x \to +\infty} F_\xi(x) = 1$$

Checking all three on the heads $F_\xi$:

- Non-decreasing: $0 \to \tfrac14 \to \tfrac34 \to 1$. It never goes down.

- Right-continuous at the jump $x = 1$: from the right, $F(1.1) = F(1.01) = F(1.001) = \tfrac34 = F(1)$ ✅. From the left, $F(0.99) = \tfrac14 \ne F(1)$. Left limits can differ from $F(x)$.

- $F(-1000) = 0$, $F(1000) = 1$.

Jump size = point mass: $F(1) - F(1^-) = \tfrac34 - \tfrac14 = \tfrac12 = P(\xi = 1)$.

$\le$ vs $<$ matters when there is a jump: $P(\xi \le 1) = \tfrac34$ but $P(\xi < 1) = F(1^-) = \tfrac14$.
