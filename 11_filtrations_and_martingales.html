11 — Filtrations, Adapted Processes & Martingales

Rigorously building discrete-time information flow, adapted processes, function composition, conditional expectation partition proofs, and martingale properties.

Step 1: Filtrations & Adapted Stochastic Processes

Filtration 𝔽: An increasing sequence of sub-σ-fields on (Ω, ℱ, P):

  ℱ₀ ⊆ ℱ₁ ⊆ ℱ₂ ⊆ … ⊆ ℱ

Each ℱₜ represents all events observable up to time t.

Adapted Process: A stochastic process (Xₜ)t ≥ 0 is adapted to 𝔽 if Xₜ is ℱₜ-measurable for every t:

  { ω ∈ Ω : Xₜ(ω) ∈ B } ∈ ℱₜ    ∀ B ∈ ℬ(ℝ)

ω-Level Example (Coin Flips): Ω = {HH, HT, TH, TT}. At t = 1, only toss 1 is observed:
  ℱ₁ = { ∅, Ω, {HH, HT}, {TH, TT} }
The single event {HT} ∉ ℱ₁ because at t=1, outcome HT cannot be distinguished from HH.

Step 2: Measurable Functions of Adapted Processes

Theorem: If (Xₜ)t ≥ 0 is adapted to 𝔽 and f: ℝ → ℝ is a Borel-measurable function, then Yₜ = f(Xₜ) is also adapted to 𝔽.

Proof via Pre-images: For any Borel set B ∈ ℬ(ℝ):

  { ω ∈ Ω : Yₜ(ω) ∈ B } = { ω ∈ Ω : Xₜ(ω) ∈ f⁻¹(B) }

1. Since f is Borel-measurable, A = f⁻¹(B) ∈ ℬ(ℝ).
2. Since Xₜ is ℱₜ-measurable, { ω : Xₜ(ω) ∈ A } ∈ ℱₜ.
3. Therefore, { ω : Yₜ(ω) ∈ B } ∈ ℱₜ, proving Yₜ is ℱₜ-measurable.

Step 3: Discrete-Time Martingale Definition

Definition: A stochastic process (Xₜ)t ≥ 0 on a filtered probability space (Ω, ℱ, 𝔽, P) is a martingale relative to 𝔽 if:

  1. Adapted: (Xₜ) is adapted to 𝔽.
  2. Integrable: E[|Xₜ|] < ∞ for all t ≥ 0.
  3. Fair Game (a.s.): E[ Xt+1 | ℱₜ ] = Xₜ   (P-a.s.)

Step 4: Rigorous Partition Proof for E[ X | 𝒢 ]

Theorem: If 𝒢 = σ(A₁, A₂, …, Aₖ) is generated by a partition of Ω into disjoint sets with P(Aᵢ) > 0, then for any ω ∈ Aᵢ:

  E[ X | 𝒢 ](ω) = cᵢ = ∫Aᵢ X dP / P(Aᵢ) = E[ X · 𝟙Aᵢ ] / P(Aᵢ)

Proof:
1. Measurability: Since Y = E[X | 𝒢] is 𝒢-measurable, σ(Y) ⊆ 𝒢. Y cannot break atoms Aᵢ, so Y(ω) = ∑ cᵢ 𝟙Aᵢ(ω).
2. Integral Matching: For set G = Aᵢ ∈ 𝒢, the definition requires ∫Aᵢ Y dP = ∫Aᵢ X dP.
3. Substituting Y(ω) = cᵢ on Aᵢ yields: cᵢ ∫Aᵢ dP = cᵢ P(Aᵢ) = ∫Aᵢ X dP.
4. Dividing by P(Aᵢ) > 0 gives cᵢ = E[ X · 𝟙Aᵢ ] / P(Aᵢ).   ■

Step 5: Concrete Coin-Flip Martingale Calculation

Setup: Ω = {HH, HT, TH, TT}, equal prob ¼. Partition of ℱ₁: A₁ = {HH, HT}, A₂ = {TH, TT}.
Given X₂ values: X₂(HH) = 3, X₂(HT) = 1, X₂(TH) = -1, X₂(TT) = -3.

1. Calculation for Atom A₁ = {HH, HT}:
  P(A₁) = ½,   ∫A₁ X₂ dP = 3(¼) + 1(¼) = 1.
  E[ X₂ | ℱ₁ ](HH) = 1 / (½) = 2 ⟹ X₁(HH) = 2.

2. Calculation for Atom A₂ = {TH, TT}:
  P(A₂) = ½,   ∫A₂ X₂ dP = (-1)(¼) + (-3)(¼) = -1.
  E[ X₂ | ℱ₁ ](TH) = -1 / (½) = -2 ⟹ X₁(TH) = -2.
