Filtrations, Adapted Processes & Martingales

Rigorously building discrete-time information flow, adapted processes, function composition, conditional expectation partition proofs, and martingale properties.

Step 1: Filtrations & Adapted Stochastic Processes

Filtration $\mathbb{F}$: An increasing sequence of sub-σ-fields on $(\Omega, \mathcal{F}, P)$: $$\mathcal{F}_0 \subseteq \mathcal{F}_1 \subseteq \mathcal{F}_2 \subseteq \cdots \subseteq \mathcal{F}$$ Each $\mathcal{F}_t$ represents all events observable up to time $t$.

Adapted Process: A stochastic process $(X_t)_{t \geq 0}$ is adapted to $\mathbb{F}$ if $X_t$ is $\mathcal{F}_t$-measurable for every $t$: $$\{\omega \in \Omega : X_t(\omega) \in B\} \in \mathcal{F}_t \quad \forall B \in \mathcal{B}(\mathbb{R})$$
$\omega$-Level Example (Coin Flips): $\Omega = \{HH, HT, TH, TT\}$. At $t = 1$, only toss 1 is observed: $$\mathcal{F}_1 = \{\varnothing, \Omega, \{HH, HT\}, \{TH, TT\}\}$$ The single event $\{HT\} \notin \mathcal{F}_1$ because at $t=1$, outcome $HT$ cannot be distinguished from $HH$.

Step 2: Measurable Functions of Adapted Processes

Theorem: If $(X_t)_{t \geq 0}$ is adapted to $\mathbb{F}$ and $f: \mathbb{R} \to \mathbb{R}$ is a Borel-measurable function, then $Y_t = f(X_t)$ is also adapted to $\mathbb{F}$.

Proof via Pre-images: For any Borel set $B \in \mathcal{B}(\mathbb{R})$: $$\{\omega \in \Omega : Y_t(\omega) \in B\} = \{\omega \in \Omega : X_t(\omega) \in f^{-1}(B)\}$$
  1. Since $f$ is Borel-measurable, $A = f^{-1}(B) \in \mathcal{B}(\mathbb{R})$.
  2. Since $X_t$ is $\mathcal{F}_t$-measurable, $\{\omega : X_t(\omega) \in A\} \in \mathcal{F}_t$.
  3. Therefore, $\{\omega : Y_t(\omega) \in B\} \in \mathcal{F}_t$, proving $Y_t$ is $\mathcal{F}_t$-measurable.

Step 3: Discrete-Time Martingale Definition

Definition: A stochastic process $(X_t)_{t \geq 0}$ on a filtered probability space $(\Omega, \mathcal{F}, \mathbb{F}, P)$ is a martingale relative to $\mathbb{F}$ if:
  1. Adapted: $(X_t)$ is adapted to $\mathbb{F}$.
  2. Integrable: $E[|X_t|] < \infty$ for all $t \geq 0$.
  3. Fair Game (a.s.): $E[X_{t+1} \mid \mathcal{F}_t] = X_t$ ($P$-a.s.)

Step 4: Rigorous Partition Proof for $E[X \mid \mathcal{G}]$

Theorem: If $\mathcal{G} = \sigma(A_1, A_2, \ldots, A_k)$ is generated by a partition of $\Omega$ into disjoint sets with $P(A_i) > 0$, then for any $\omega \in A_i$: $$E[X \mid \mathcal{G}](\omega) = c_i = \frac{\int_{A_i} X\, dP}{P(A_i)} = \frac{E[X \cdot \mathbb{1}_{A_i}]}{P(A_i)}$$ Proof:
  1. Measurability: Since $Y = E[X \mid \mathcal{G}]$ is $\mathcal{G}$-measurable, $\sigma(Y) \subseteq \mathcal{G}$. $Y$ cannot break atoms $A_i$, so $Y(\omega) = \sum c_i \mathbb{1}_{A_i}(\omega)$.
  2. Integral Matching: For set $G = A_i \in \mathcal{G}$, the definition requires $\int_{A_i} Y\, dP = \int_{A_i} X\, dP$.
  3. Substituting $Y(\omega) = c_i$ on $A_i$ yields: $c_i \int_{A_i} dP = c_i P(A_i) = \int_{A_i} X\, dP$.
  4. Dividing by $P(A_i) > 0$ gives $c_i = E[X \cdot \mathbb{1}_{A_i}] / P(A_i)$. ■

Step 5: Concrete Coin-Flip Martingale Calculation

Setup: $\Omega = \{HH, HT, TH, TT\}$, equal prob $\tfrac14$. Partition of $\mathcal{F}_1$: $A_1 = \{HH, HT\}$, $A_2 = \{TH, TT\}$.
Given $X_2$ values: $X_2(HH) = 3$, $X_2(HT) = 1$, $X_2(TH) = -1$, $X_2(TT) = -3$.

1. Calculation for Atom $A_1 = \{HH, HT\}$: $$P(A_1) = \tfrac12, \quad \int_{A_1} X_2\, dP = 3\left(\tfrac14\right) + 1\left(\tfrac14\right) = 1$$ $$E[X_2 \mid \mathcal{F}_1](HH) = \frac{1}{1/2} = 2 \implies X_1(HH) = 2$$ 2. Calculation for Atom $A_2 = \{TH, TT\}$: $$P(A_2) = \tfrac12, \quad \int_{A_2} X_2\, dP = (-1)\left(\tfrac14\right) + (-3)\left(\tfrac14\right) = -1$$ $$E[X_2 \mid \mathcal{F}_1](TH) = \frac{-1}{1/2} = -2 \implies X_1(TH) = -2$$
