04 — Generated σ-Fields & Doob–Dynkin Lemma

Un-rushed, line-by-line breakdown built from ground-truth Socratic session.

Step 1: σ-field Generated by a Single Random Variable σ(ξ)

Given a random variable ξ : Ω → ℝ, the σ-field generated by ξ, denoted σ(ξ), consists of all pre-images of Borel sets B ∈ ℬ(ℝ):

  σ(ξ) = { {ω ∈ Ω : ξ(ω) ∈ B} : B ∈ ℬ(ℝ) } = { ξ⁻¹(B) : B ∈ ℬ(ℝ) }

Key Fact: The collection of pre-images is automatically a valid σ-field on Ω because inverse images preserve all set operations (complements, countable unions, and intersections).

Concrete Example:
Let Ω = {ω₁, ω₂, ω₃} with ξ(ω₁) = 2, ξ(ω₂) = 2, ξ(ω₃) = 5.
The Borel sets B ⊂ ℝ isolate the atoms {ω₁, ω₂} and {ω₃}.
Evaluating all pre-images gives:
  σ(ξ) = { ∅, {ω₁, ω₂}, {ω₃}, Ω }

Step 2: σ-field Generated by a Family of Random Variables

Given a collection of random variables {ξᵢ, i ∈ I}, the generated σ-field σ(ξᵢ, i ∈ I) is defined as the smallest σ-field containing all events of the form {ξᵢ ∈ B} for all i ∈ I and B ∈ ℬ(ℝ):

  σ(ξᵢ, i ∈ I) = σ( ⋃i ∈ I σ(ξᵢ) )

ω-Level Separation Principle: Two outcomes ωa, ωb can be separated into distinct events in σ(ξᵢ, i ∈ I) if and only if there exists at least one index j ∈ I such that ξj(ωa) ≠ ξj(ωb).

Example: Adding η(ω₁) = 0, η(ω₂) = 5, η(ω₃) = 8 allows us to isolate the singleton {ω₂} via η⁻¹((4.5, 5.5)) = {ω₂} ∈ σ(ξ, η).

Step 3: Borel Functions and Composition Measurability

A function f : ℝ → ℝ is a Borel function if for every Borel set B ∈ ℬ(ℝ), its pre-image f⁻¹(B) ∈ ℬ(ℝ).

Theorem: If f is a Borel function and ξ is a random variable, then the composite function f(ξ) = f ∘ ξ is σ(ξ)-measurable.

Proof: Fix any B ∈ ℬ(ℝ). Then:
  {ω ∈ Ω : f(ξ(ω)) ∈ B} = {ω ∈ Ω : ξ(ω) ∈ f⁻¹(B)} = ξ⁻¹(f⁻¹(B))
Since f is Borel, A = f⁻¹(B) is a Borel set in ℝ. By definition of σ(ξ), ξ⁻¹(A) ∈ σ(ξ). ∎

Step 4: Doob–Dynkin Lemma

Lemma (Doob–Dynkin):
Let ξ : Ω → ℝ be a random variable. A random variable η : Ω → ℝ is σ(ξ)-measurable if and only if there exists a Borel function f : ℝ → ℝ such that:

  η = f(ξ)    (i.e., ∀ ω ∈ Ω, η(ω) = f(ξ(ω)))

Physical Interpretation: A random variable η is σ(ξ)-measurable if and only if knowing the value of ξ(ω) uniquely determines the value of η(ω). No extra randomness or information about ω is involved.

Concrete Construction Example:
If ξ(ω₁) = 2, ξ(ω₂) = 2, ξ(ω₃) = 5 and η(ω₁) = 9, η(ω₂) = 9, η(ω₃) = 25:
Since η(ω₁) = η(ω₂) when ξ(ω₁) = ξ(ω₂), η is σ(ξ)-measurable.
We construct f by matching outputs on the range of ξ:
  f(2) = 9,   f(5) = 25   ⇒   f(x) = (16/3)x - (5/3)   (or step function f(x) = 9 · 𝕀{2}(x) + 25 · 𝕀{5}(x)).
