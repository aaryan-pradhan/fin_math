21 — Dynamic Programming & The Bellman Equation

My understanding, built from scratch.

1. The Objective & The Value Function

Global Goal: Maximize expected reward over $T$ steps: $\max E\left[ \sum_{t=1}^T R(X_t, a_t) \right]$
Finding the whole sequence at once is too hard. We break it down using the Value Function.
$V_n(i)$ = The maximum expected reward you can get starting in state $i$ with exactly $n$ steps left to play.
$$V_n(i) = \max_{a} E \left[ \sum_{t=1}^n R(X_t, a_t) \;\middle|\; X_1 = i \right]$$

2. The Dynamic Programming Split

Split the global maximum into two pieces: Right now + The rest of the game. $$V_n(i) = \max_a \left\{ \underbrace{R(i, a)}_{\text{Right now}} + \underbrace{E_a\left[ \sum_{t=2}^n R(X_t, a_t) \;\middle|\; X_1 = i \right]}_{\text{The rest of the game}} \right\}$$

3. The Expectation over the Next State

If taking action $a$ instantly teleported us to state $j$, the "rest of the game" would just be $V_{n-1}(j)$.
But in an MDP, we only reach state $j$ with probability $P_{ij}(a)$.
So, the expected value of the rest of the game is the weighted average over all possible next states: $$E_a[\text{rest of game}] = \sum_j P_{ij}(a) V_{n-1}(j)$$

4. The Bellman Equation

Substituting the expectation back in gives the fundamental equation of DP:

$$V_n(i) = \max_a \left\{ R(i, a) + \sum_j P_{ij}(a) V_{n-1}(j) \right\}$$
To find the best move: For every action $a$, add the immediate reward to the expected optimal future reward. Pick the action with the biggest total.

5. Backward Induction (Value Iteration)

To calculate $V_{10}$, you must first know $V_9$ for all states. To know $V_9$, you need $V_8$, and so on.
Algorithm:
  1. Start at the end: $V_0(i) = 0$ for all states (0 steps left = game over).
  2. Use Bellman eq to find $V_1(i)$ from $V_0(i)$.
  3. Use Bellman eq to find $V_2(i)$ from $V_1(i)$.
  4. Repeat up to $V_n(i)$.
This recursive step-by-step process is called Backward Induction.
