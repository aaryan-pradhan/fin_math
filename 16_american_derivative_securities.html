16 — American Derivative Securities (ADS)

My understanding, built from scratch.

1. What is an ADS?

An American Derivative Security is a contract giving the owner the right — but not the obligation — to receive a payoff at any time $t \in \{0, 1, \ldots, T\}$ up to expiry $T$.

Formally: an adapted process $(X_t)_{t=0,\ldots,T}$ with $X_t \geq 0$, defined on a filtered probability space $(\Omega, \mathcal{F}, \mathbb{F}, P)$.

2. Adaptedness — No Future Info

$X_t$ is $\mathcal{F}_t$-measurable for each $t$.

$\omega$-level: Fix one path $\omega$. At time $t$, you've only seen history up to $t$. To compute $X_t(\omega)$ you need only $\mathcal{F}_t$ — not $\mathcal{F}_{t+1}$ or beyond.
⚠️ If $X_0$ depended on $\mathcal{F}_3$: you'd need future prices at time 0. Financially impossible — this is look-ahead bias.

3. Stopping Time — Deciding When to Exercise

A stopping time $\tau: \Omega \to \{0, 1, \ldots, T\}$ satisfies: $$\{\tau = t\} \in \mathcal{F}_t \quad \forall\, t$$ The decision "stop at time $t$" uses only information available at time $t$.

4. Numerical Example ($T = 3$)

$t$$X_t(\omega)$Info used
05$\mathcal{F}_0$
112$\mathcal{F}_1$
28$\mathcal{F}_2$
315$\mathcal{F}_3$
❌ Invalid: $\tau = \arg\max_{t \leq T} X_t = 3$.
At $t=1$, choosing not to exercise requires knowing $X_3 = 15 > X_1 = 12$. That's future info. Not a stopping time.
✅ Valid: "Exercise first time $X_t \geq 10$."
$t=0$: $5 < 10$, wait. $t=1$: $12 \geq 10$, stop. $\tau(\omega) = 1$, payoff $= 12$.
Each decision uses only current info.
Threshold never hit: Rule "$X_t \geq 20$" → threshold never reached → $\tau(\omega) = T = 3$ (expiry), payoff $= X_3 = 15$.

5. Why $X_t \geq 0$?

The holder has a right, not an obligation. If exercising gives a negative payoff, they simply don't exercise — payoff is 0.
Example: Call payoff $= \max(S_t - K,\, 0) \geq 0$ always.
You are never forced into a loss.
