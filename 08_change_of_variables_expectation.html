08 — Change of Variables for Expectation

Transferring integration from abstract Ω to ℝ via the push-forward measure Pξ.

Theorem Statement

For any Borel function h : ℝ → ℝ such that h(ξ) is integrable on (Ω, ℱ, P):

  E(h(ξ)) = ∫Ω h(ξ(ω)) dP(ω) = ∫ℝ h(x) dPξ(x)

where Pξ(A) = P(ξ ∈ A) is the push-forward (distribution) measure on (ℝ, ℬ(ℝ)).

Step 1: Simple Functions (Base Case)

Let h(x) = Σi=1n hi 𝟏Ai(x) be a simple function over disjoint Borel sets Ai.

Evaluating at ξ(ω):
  h(ξ(ω)) = Σi=1n hi 𝟏Ai(ξ(ω)) = Σi=1n hi 𝟏{ξ ∈ Ai}(ω)

Taking expectation:
  E(h(ξ)) = Σi=1n hi P(ξ ∈ Ai) = Σi=1n hi Pξ(Ai) = ∫ℝ h(x) dPξ(x)

Step 2: Non-Negative Borel Functions (MCT)

For any h ≥ 0, construct a sequence of simple functions 0 ≤ h1 ≤ h2 ≤ … ↑ h pointwise.

By Step 1, E(hn(ξ)) = ∫ℝ hn(x) dPξ(x) for every n.

By the Monotone Convergence Theorem (MCT), we pass the limit inside both integral signs:
  limn→∞ E(hn(ξ)) = E(h(ξ))   and   limn→∞ ∫ℝ hn dPξ = ∫ℝ h dPξ

Hence, E(h(ξ)) = ∫ℝ h(x) dPξ(x) holds for all non-negative h.

Step 3: General Integrable Functions

Decompose h = h⁺ − h⁻ where h⁺ = max(h, 0) ≥ 0 and h⁻ = max(−h, 0) ≥ 0.

Since h(ξ) is integrable, both E(h⁺(ξ)) and E(h⁻(ξ)) are finite. Applying Step 2 to both parts:
  E(h(ξ)) = E(h⁺(ξ)) − E(h⁻(ξ)) = ∫ℝ h⁺ dPξ − ∫ℝ h⁻ dPξ = ∫ℝ h(x) dPξ(x)

Step 4: Concrete Applications

1. Continuous Case: If ξ has density fξ, then dPξ(x) = fξ(x) dx:
  E(h(ξ)) = ∫−∞∞ h(x) fξ(x) dx

2. Discrete Case: If ξ takes discrete values {x1, x2, …}:
  E(h(ξ)) = Σi h(xi) P(ξ = xi)
