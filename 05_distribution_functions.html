05 — Distribution Measure & Cumulative Distribution Function

Un-rushed breakdown of push-forward probability measures and distribution functions (d.f.).

Step 1: The Push-Forward Measure Pξ

Every random variable ξ : Ω → ℝ on (Ω, ℱ, P) induces a probability measure Pξ on (ℝ, ℬ(ℝ)), defined for all Borel sets B ∈ ℬ(ℝ) by:

  Pξ(B) = P(ξ ∈ B) = P({ω ∈ Ω : ξ(ω) ∈ B})

Interpretation: Pξ is the "distribution" of ξ. It transports probability measure P from abstract sample space Ω to sets on the real line ℝ.

Step 2: Cumulative Distribution Function Fξ(x)

The function Fξ : ℝ → [0, 1] defined by:

  Fξ(x) = P(ξ ≤ x) = Pξ((-∞, x])

is called the distribution function (d.f.) of ξ.

Step 3: Properties of Distribution Functions

Every distribution function Fξ satisfies three core properties:

  1. Non-Decreasing: If x₁ < x₂, then Fξ(x₁) ≤ Fξ(x₂).
    Proof: (-∞, x₁] ⊆ (-∞, x₂] ⟹ {ξ ≤ x₁} ⊆ {ξ ≤ x₂} ⟹ P(ξ ≤ x₁) ≤ P(ξ ≤ x₂).

  2. Right-Continuous: limh ↓ 0 Fξ(x + h) = Fξ(x).
    Proof: For sequence xn ↓ x, events An = {ξ ≤ xn} form nested decreasing sequence A₁ ⊇ A₂ ⊇ ... with ⋂n=1∞ An = {ξ ≤ x}. By continuity of measure from above, lim P(An) = P({ξ ≤ x}).

  3. Limits at ±∞:
      limx → -∞ Fξ(x) = 0     and     limx → +∞ Fξ(x) = 1
