07 — Expectation & Integration

The Lebesgue integral construction: from integrable r.v.s through indicators to simple functions.

Step 1: Integrable Random Variables

A random variable ξ : Ω → ℝ is integrable if:

  ∫Ω |ξ| dP < ∞

When this holds, the expectation exists and is defined as:

  E(ξ) = ∫Ω ξ dP

The family of all integrable r.v.s on (Ω, ℱ, P) is denoted L¹ or L¹(Ω, ℱ, P).

Step 2: Why Absolute Value?

Pitfall: Every r.v. decomposes as ξ = ξ⁺ − ξ⁻ where ξ⁺ = max(ξ, 0) and ξ⁻ = max(−ξ, 0). Both ∫ξ⁺ dP and ∫ξ⁻ dP exist in [0, ∞].

If both are +∞, then E(ξ) = ∞ − ∞ — undefined.

Requiring ∫|ξ| dP < ∞ forces both ∫ξ⁺ dP < ∞ and ∫ξ⁻ dP < ∞ (since |ξ| = ξ⁺ + ξ⁻), guaranteeing the subtraction is a finite real number.

Step 3: Indicator Random Variables

For any event A ∈ ℱ, the indicator function is:

  𝟏A(ω) = 1 if ω ∈ A,   0 if ω ∈ Ω \ A

Its expectation:

  E(𝟏A) = ∫Ω 𝟏A dP = ∫A 1 dP + ∫Ω\A 0 dP = P(A)

The integrand is 0 outside A, so only the measure of A survives. This works for any Ω (discrete or uncountable) — no ω-by-ω summation needed.

Step 4: Simple Functions

A simple function η : Ω → ℝ is a finite linear combination of indicators over pairwise disjoint events:

  η = Σi=1n ηi 𝟏Ai

where η1, …, ηn ∈ ℝ and A1, …, An are pairwise disjoint events.

Why disjoint? Each ω lands in at most one Ai, so η(ω) = ηi — one clean value, no ambiguity. (Disjointness is not needed for linearity of the integral — that always holds. It's needed for the representation to be unambiguous.)

Do the Ai need to cover Ω? No. If ω ∉ ∪Ai, every indicator is 0, so η(ω) = 0.

Step 5: Expectation of Simple Functions

By linearity of the integral:

  E(η) = ∫Ω η dP = Σi=1n ηi ∫Ω 𝟏Ai dP = Σi=1n ηi P(Ai)

This is the weighted sum of probabilities. The construction ladder:

  indicators → simple functions → (approximate arbitrary r.v.s by simple functions → general Lebesgue integral)
