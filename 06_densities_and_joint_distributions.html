06 — Probability Densities & Joint Distributions

Line-by-line breakdown of continuous, discrete, and joint distributions.

Step 1: Absolutely Continuous Distributions & Density

A random variable ξ : Ω → ℝ has an absolutely continuous distribution if there exists a Borel function fξ : ℝ → [0, ∞) (density) such that for any B ∈ ℬ(ℝ):

  P(ξ ∈ B) = ∫B fξ(x) dx

Single-Point Pitfall: For any single point x₀ ∈ ℝ, P(ξ = x₀) = ∫{x₀} fξ(x) dx = 0.

Step 2: Discrete Distributions

A random variable ξ has a discrete distribution with distinct values {x₁, x₂, ...} if for any B ∈ ℬ(ℝ):

  P(ξ ∈ B) = ∑xᵢ ∈ B P(ξ = xᵢ)

Here, probability mass is concentrated at isolated points xᵢ with P(ξ = xᵢ) > 0.

Step 3: Joint Distributions in ℝⁿ

For random vector (ξ₁, ..., ξₙ) : Ω → ℝⁿ, the joint distribution measure Pξ₁,...,ξₙ on (ℝⁿ, ℬ(ℝⁿ)) satisfies:

  Pξ₁,...,ξₙ(B) = P( (ξ₁, ..., ξₙ) ∈ B )    ∀ B ∈ ℬ(ℝⁿ)

If a joint density fξ₁,...,ξₙ exists:

  P( (ξ₁, ..., ξₙ) ∈ B ) = ∫...∫B fξ₁,...,ξₙ(x₁, ..., xₙ) dx₁...dxₙ

Step 4: Event Pre-Image Mapping

Event { ξ₁ ≤ 3, ξ₂ > 5 } corresponds to the joint Borel set:
  B = (-∞, 3] × (5, ∞) ⊂ ℝ²
