Expectation & Integration

The Lebesgue integral construction: from integrable r.v.s through indicators to simple functions.

Step 1: Integrable Random Variables

A random variable $\xi : \Omega \to \mathbb{R}$ is integrable if: $$\int_\Omega |\xi|\, dP < \infty$$ When this holds, the expectation exists and is defined as: $$E(\xi) = \int_\Omega \xi\, dP$$ The family of all integrable r.v.s on $(\Omega, \mathcal{F}, P)$ is denoted $L^1$ or $L^1(\Omega, \mathcal{F}, P)$.
  • Fair die, $\xi(\omega) = \omega$: $E|\xi| = \tfrac16(1 + \cdots + 6) = 3.5 < \infty$, so it's integrable and $E\xi = 3.5$.
  • Any bounded r.v. ($|\xi| \le M$) is integrable: $E|\xi| \le M$.
  • St Petersburg: $P(\xi = 2^k) = 2^{-k}$ for $k = 1, 2, \ldots$ Then $E|\xi| = \sum 2^k\cdot 2^{-k} = 1 + 1 + \cdots = \infty$. Not integrable.

Step 2: Why Absolute Value?

Pitfall: Every r.v. decomposes as $\xi = \xi^+ - \xi^-$ where $\xi^+ = \max(\xi, 0)$ and $\xi^- = \max(-\xi, 0)$. Both $\int \xi^+\, dP$ and $\int \xi^-\, dP$ exist in $[0, \infty]$.

If both are $+\infty$, then $E(\xi) = \infty - \infty$ — undefined.

Requiring $\int |\xi|\, dP < \infty$ forces both $\int \xi^+\, dP < \infty$ and $\int \xi^-\, dP < \infty$ (since $|\xi| = \xi^+ + \xi^-$), guaranteeing the subtraction is a finite real number.
Finite case. Die, $\xi = \omega - 3.5$:

$E\xi^+ = \tfrac{4.5}{6} = 0.75$ and $E\xi^- = 0.75$, so $E\xi = 0.75 - 0.75 = 0$.

$\infty - \infty$ case. $P(\xi = 2^k) = P(\xi = -2^k) = 2^{-k-1}$. Then $E\xi^+ = \sum 2^k 2^{-k-1} = \sum \tfrac12 = \infty$, and likewise $E\xi^- = \infty$. The distribution is symmetric, yet $E\xi$ is undefined, not 0.

Step 3: Indicator Random Variables

For any event $A \in \mathcal{F}$, the indicator function is: $$\mathbb{1}_A(\omega) = \begin{cases} 1 & \omega \in A \\ 0 & \omega \in \Omega \setminus A \end{cases}$$
Its expectation: $$E(\mathbb{1}_A) = \int_\Omega \mathbb{1}_A\, dP = \int_A 1\, dP + \int_{\Omega \setminus A} 0\, dP = P(A)$$ The integrand is 0 outside $A$, so only the measure of $A$ survives. This works for any $\Omega$ (discrete or uncountable) — no $\omega$-by-$\omega$ summation needed.
  • Die, $A = \{5, 6\}$: $\mathbb{1}_A = 0,0,0,0,1,1$, so $E\mathbb{1}_A = \tfrac26 = \tfrac13 = P(A)$.
  • Uniform $U$ on $[0,1]$, $A = \{0.2 \le U \le 0.5\}$: $E\mathbb{1}_A = 0.3$. There's nothing to sum $\omega$ by $\omega$ (uncountably many), and none is needed.

Step 4: Simple Functions

A simple function $\eta : \Omega \to \mathbb{R}$ is a finite linear combination of indicators over pairwise disjoint events: $$\eta = \sum_{i=1}^{n} \eta_i \mathbb{1}_{A_i}$$ where $\eta_1, \ldots, \eta_n \in \mathbb{R}$ and $A_1, \ldots, A_n$ are pairwise disjoint events.
Why disjoint? Each $\omega$ lands in at most one $A_i$, so $\eta(\omega) = \eta_i$ — one clean value, no ambiguity. (Disjointness is not needed for linearity of the integral — that always holds. It's needed for the representation to be unambiguous.)

Do the $A_i$ need to cover $\Omega$? No. If $\omega \notin \bigcup A_i$, every indicator is 0, so $\eta(\omega) = 0$.
Die, $\eta = 10\cdot\mathbb{1}_{\{1,2\}} + 5\cdot\mathbb{1}_{\{3\}}$:
$\omega$123456
$\eta$10105000
$\{4,5,6\}$ is not covered, so $\eta = 0$ there.
Non-disjoint: $\mathbb{1}_{\{1,2\}} + \mathbb{1}_{\{2,3\}}$ equals 2 at $\omega = 2$. It's still a fine function, but its disjoint form is $1\cdot\mathbb{1}_{\{1,3\}} + 2\cdot\mathbb{1}_{\{2\}}$.

Step 5: Expectation of Simple Functions

By linearity of the integral: $$E(\eta) = \int_\Omega \eta\, dP = \sum_{i=1}^{n} \eta_i \int_\Omega \mathbb{1}_{A_i}\, dP = \sum_{i=1}^{n} \eta_i P(A_i)$$ This is the weighted sum of probabilities. The construction ladder:
indicators → simple functions → (approximate arbitrary r.v.s by simple functions → general Lebesgue integral)
Die $\eta$ above: $E\eta = 10\cdot\tfrac26 + 5\cdot\tfrac16 = \tfrac{25}6 \approx 4.17$. Check $\omega$ by $\omega$: $\tfrac16(10 + 10 + 5 + 0 + 0 + 0) = \tfrac{25}6$ ✅
Approximating $U$ (uniform on $[0,1]$) from below. $\eta_n = \lfloor 2^nU \rfloor / 2^n$ rounds $U$ down to a multiple of $2^{-n}$.
  • $n = 1$: values $0, \tfrac12$, each with probability $\tfrac12$. $E\eta_1 = 0.25$.
  • $n = 2$: values $0, \tfrac14, \tfrac12, \tfrac34$, each $\tfrac14$. $E\eta_2 = 0.375$.
  • In general $E\eta_n = \tfrac12(1 - 2^{-n}) \uparrow \tfrac12 = EU$.

Practice Questions

Q1. Fair die. Compute $E(\xi^2)$ as a simple-function expectation.
Answer$\xi^2 = \sum_{k=1}^6 k^2\mathbb{1}_{\{k\}}$, so $E = \tfrac16(1 + 4 + 9 + 16 + 25 + 36) = \tfrac{91}6 \approx 15.17$.
Q2. $P(\xi = k) = \tfrac{c}{k^2}$, $k = 1, 2, \ldots$, with $c = 6/\pi^2$. Is $\xi$ integrable?
Answer$E|\xi| = \sum k\cdot\tfrac{c}{k^2} = c\sum\tfrac1k = \infty$ (harmonic series). Not integrable, even though $P$ is a valid distribution.
Q3. $U$ uniform on $[0,1]$, $\eta = 2\cdot\mathbb{1}\{U < 0.3\} - 1\cdot\mathbb{1}\{U \ge 0.7\}$. Find $E\eta$.
Answer$2(0.3) + (-1)(0.3) = 0.3$.
Q4. Die, $A = \{1,2,3\}$, $B = \{3,4\}$. Find $E(\mathbb{1}_A + \mathbb{1}_B)$ two ways.
AnswerLinearity (no disjointness needed): $\tfrac12 + \tfrac13 = \tfrac56$. Pointwise values $1, 1, 2, 1, 0, 0$: $\tfrac56$ ✅
Q5. For the dyadic approximation $\eta_3$ of $U$, compute $E\eta_3$.
AnswerValues $\tfrac k8$, $k = 0..7$, each with probability $\tfrac18$: $E = \tfrac1{64}(0 + 1 + \cdots + 7) = \tfrac{28}{64} = 0.4375 = \tfrac12(1 - \tfrac18)$ ✅
Q6. $X \sim \text{Exp}(1)$, $\xi = X - 1$. Compute $E\xi^+$ and $E\xi^-$, and check $E\xi = 0$.
Answer$E\xi^+ = \int_1^\infty (x-1)e^{-x}\,dx = e^{-1}$. $E\xi^- = \int_0^1 (1-x)e^{-x}\,dx = (1 - e^{-1}) - (1 - 2e^{-1}) = e^{-1}$. So $E\xi = e^{-1} - e^{-1} = 0 = EX - 1$ ✅
