Q1: Distribution of $\int_0^1 t\,dW_t$

Formula: §I1.5, §I1.4

$$E\left[\int_0^1 t\,dW_t\right] = 0$$ Itô isometry (deterministic integrand): $$Var = E\left[\left(\int_0^1 t\,dW_t\right)^2\right] = \int_0^1 t^2\,dt = \frac13$$ So $\int_0^1 t\,dW_t \sim N(0, 1/3)$.

Q2: $E(W_2^2W_3^2)$

Formula: §6.4, §6.3

Independent increments: $Z = W_3 - W_2$, $W_3 = W_2 + Z$.
  • $W_2\sim N(0,2)$, so $E(W_2^2) = 2$.
  • $Z\sim N(0,1)$, so $E(Z^2) = 1$, $E(Z) = 0$.
  • $W_2$ and $Z$ are independent.
$$E(W_2^2W_3^2) = E\left[W_2^2(W_2^2 + 2W_2Z + Z^2)\right] = E(W_2^4) + 2E(W_2^3Z) + E(W_2^2Z^2)$$
  1. $E(W_2^4) = 3(Var\,W_2)^2 = 3\cdot 2^2 = 12$ (fourth moment $3\sigma^4$).
  2. $2E(W_2^3Z) = 2E(W_2^3)E(Z) = 0$.
  3. $E(W_2^2Z^2) = E(W_2^2)E(Z^2) = 2\cdot 1 = 2$.
$$E(W_2^2W_3^2) = 12 + 0 + 2 = 14$$

Q3: Is $X(t) = e^{-t}W(e^{2t})$ Gaussian?

Formula: §5.3, §5.5

Gaussian process: for every finite $t_1,\dots,t_n$, $(X(t_1),\dots,X(t_n))$ is multivariate Gaussian.
  1. $W$ is a Gaussian process.
  2. Time change $t\mapsto e^{2t}$ is deterministic: $(W(e^{2t_1}),\dots,W(e^{2t_n}))$ is still jointly Gaussian.
  3. Multiplying by deterministic $e^{-t_i}$ is a linear map; linear maps preserve joint Gaussianity.
Yes.

Q4: $4W_1 + 6W_3$

Formula: §6.2, §1.6

Linear combination of jointly Gaussian variables, so normal.
  • Mean: $4E[W_1] + 6E[W_3] = 0$.
  • Variance: $16\,Var(W_1) + 36\,Var(W_3) + 48\,Cov(W_1,W_3)$, with $Var(W_t) = t$, $Cov(W_s,W_t) = \min(s,t)$: $$\sigma^2 = 16(1) + 36(3) + 48(1) = 172$$
$4W_1 + 6W_3 \sim N(0, 172)$.

Q5: Is $Y_t = e^{t/2}\sin W_t$ a martingale?

Formula: §7.4, §I4.3

Show $E[Y_t\mid\mathcal{F}_s] = Y_s$ for $0\le s\le t$.
1. Independent increments. $W_t = (W_t - W_s) + W_s$, $\sin(A+B) = \sin A\cos B + \cos A\sin B$: $$Y_t = e^{t/2}\left[\sin(W_t - W_s)\cos W_s + \cos(W_t - W_s)\sin W_s\right]$$ 2. Condition. $W_s$ is $\mathcal{F}_s$-measurable (pull out); $W_t - W_s$ is independent of $\mathcal{F}_s$ (drop conditioning): $$E[Y_t\mid\mathcal{F}_s] = e^{t/2}\left[\cos W_s\,E[\sin(W_t - W_s)] + \sin W_s\,E[\cos(W_t - W_s)]\right]$$ 3. Evaluate with $W_t - W_s\sim N(0, t-s)$:
  • $E[\sin(W_t - W_s)] = 0$ (odd function, symmetric distribution).
  • $E[\cos(W_t - W_s)] = e^{-\frac12(t-s)}$ (characteristic function $E[e^{iuX}] = e^{-\frac12u^2\sigma^2}$ at $u=1$).
4. Simplify. $$E[Y_t\mid\mathcal{F}_s] = e^{t/2}e^{-t/2 + s/2}\sin W_s = e^{s/2}\sin W_s = Y_s$$ Yes.
Same computation for $e^{ct}\sin W_t$ or $e^{ct}\cos W_t$ gives $e^{(c - 1/2)(t-s)}Y_s$: martingale iff $c = \tfrac12$. Hence Set 2/3 (with $e^t$): No.

Q6: GBM, $E[Y(10)]$

Formula: §11.2, §1.2

Method 1 (SDE). $dY = \mu Y\,dt + \sigma Y\,dW$, solution $Y(t) = Y(0)\exp\left((\mu - \tfrac12\sigma^2)t + \sigma W(t)\right)$: $$E[Y(t)] = Y(0)e^{\mu t},\qquad E[Y(10)] = 5e^{0.1}\approx 5.5259$$ Method 2 (exponent). $Y(t) = Y(0)e^{\mu t + \sigma W(t)}$: $$E[Y(t)] = Y(0)e^{(\mu + \frac12\sigma^2)t},\quad \mu + \tfrac12\sigma^2 = 0.01 + 0.045 = 0.055$$ $$E[Y(10)] = 5e^{0.55}\approx 8.6663$$ Formula used in class: Method 2. Answer $5e^{0.55}$ (both accepted).

Q9: $Cov(Y_1,Y_2)$, $Y_t = e^{W_t}$

Formula: §6.5

$Cov(Y_1,Y_2) = E[Y_1Y_2] - E[Y_1]E[Y_2]$.
1. $E[e^{W_t}] = e^{t/2}$: $E[Y_1]E[Y_2] = e^{1/2}e^{1} = e^{3/2}$.
2. $E[Y_1Y_2] = E[e^{W_1 + W_2}]$, with $W_1 + W_2$ normal, mean $0$, $$Var(W_1 + W_2) = 1 + 2 + 2\min(1,2) = 5 \quad\Rightarrow\quad E[e^{W_1 + W_2}] = e^{5/2}$$ 3. $$Cov(Y_1,Y_2) = e^{5/2} - e^{3/2} = e^{3/2}(e - 1)$$

Q10: Gambler's ruin (win 10 / lose 5)

Formula: §3.1, §3.2

Gambler's ruin. Shift: lower barrier $0$, start $z = 5$, upper barrier $a = 15$, $p = q = \tfrac12$.
  • (a) $P_z = \frac{z}{a} = \frac{5}{15} = \frac13$.
  • (b) $E_z = z(a - z) = 5\cdot 10 = 50$.
Martingales (alternative). $X_n = \sum_{i=1}^n Y_i$, $P(Y_i = \pm1) = \tfrac12$. Martingales: $X_n$ and $X_n^2 - n$. $\tau = \min\{n\ge 0: X_n = 10 \text{ or } X_n = -5\}$, a.s. finite, process bounded up to $\tau$, so OST applies.
(a) $E[X_\tau] = 0$: $10p - 5(1-p) = 0 \Rightarrow p = \tfrac13$.
(b) $E[X_\tau^2 - \tau] = 0 \Rightarrow E[\tau] = E[X_\tau^2]$: $$E[\tau] = 100\cdot\tfrac13 + 25\cdot\tfrac23 = \tfrac{150}{3} = 50$$
General: win $A$ / lose $B$, fair game: $P(\text{win}) = \frac{B}{A+B}$, $E[\tau] = AB$.
