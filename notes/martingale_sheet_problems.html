Warm-up — Markov and Chebyshev inequalities

Formula: §E1.6

Markov. For $X\ge0$ and $x>0$: $\displaystyle P(X\ge x)\le\frac{E(X)}x$.
Chebyshev. If $\xi$ has mean $\mu$ and variance $\sigma^2$, then $\displaystyle P(|\xi-\mu|\ge\epsilon)\le\frac{\sigma^2}{\epsilon^2}$ for any $\epsilon>0$.
Proof. $$E(X)=\int_0^xuf(u)\,du+\int_x^\infty uf(u)\,du\ \ge\ \int_x^\infty uf(u)\,du\ \ge\ x\int_x^\infty f(u)\,du=xP(X\ge x).$$ For Chebyshev, apply Markov to $X=(\xi-\mu)^2$ with $x=\epsilon^2$: $$P\big((\xi-\mu)^2\ge\epsilon^2\big)\le\frac{E(\xi-\mu)^2}{\epsilon^2}\quad\Longrightarrow\quad P(|\xi-\mu|\ge\epsilon)\le\frac{\sigma^2}{\epsilon^2}.$$

Example 1 — Exponential

Problem. $X\sim\text{Exp}$ with mean $E(X)=1$ and $x=0.5$. Compare $P(X>x)$ with the Markov bound $E(X)/x$.
Formula: §E1.6
Solution. $P(X>\tfrac12)=e^{-1/2}\approx0.607$, while the bound is $E(X)/x=1/\tfrac12=2$. The bound holds but is useless here (it exceeds 1).

Example 2 — Bernoulli

Problem. $X\sim\text{Bernoulli}(p)$. Compare $P(X\ge1)$ with the Markov bound $E(X)/1$.
Formula: §E1.6
Solution. $P(X\ge1)=P(X=1)=p$ and $E(X)/1=p$. The bound is attained, so Markov's inequality is sharp.

Problem 2.5.1 — Two steps ahead

Problem. Use the law of total probability for conditional expectations, $E[E\{X\mid Y,Z\}\mid Z]=E[X\mid Z]$, to show $$E[X_{n+2}\mid X_0,\dots,X_n]=E\big[E\{X_{n+2}\mid X_0,\dots,X_{n+1}\}\mid X_0,\dots,X_n\big].$$ Conclude that when $X_n$ is a martingale, $E[X_{n+2}\mid X_0,\dots,X_n]=X_n$.
Formula: §E4.4, §M2.3
Solution (not in notes). Apply the given identity with $X=X_{n+2}$, $Y=X_{n+1}$ and $Z=(X_0,\dots,X_n)$. Conditioning on $(Y,Z)$ is conditioning on $X_0,\dots,X_{n+1}$, which gives the displayed equation. If $X_n$ is a martingale, the inner expectation is $X_{n+1}$, so $$E[X_{n+2}\mid X_0,\dots,X_n]=E[X_{n+1}\mid X_0,\dots,X_n]=X_n .$$

Problem 2.5.2 — Product of doubled uniforms

Problem. Let $U_1,U_2,\dots$ be independent, each uniform on $(0,1]$. Show that $X_0=1$ and $X_n=2^nU_1\cdots U_n$, $n=1,2,\dots$, is a martingale.
Formula: §M2.1, §M2.5, §E4.5
Solution. $X_{n+1}=2X_nU_{n+1}$. Knowing $X_0,\dots,X_n$ is the same as knowing $U_1,\dots,U_n$, and $U_{n+1}$ is independent of them: $$E(X_{n+1}\mid X_0,\dots,X_n)=2X_nE(U_{n+1}\mid U_1,\dots,U_n)=2X_nE(U_{n+1})=2X_n\cdot\tfrac12=X_n,$$ with $E(U_{n+1})=\int_0^1u\,du=\tfrac12$. Also $E|X_n|=2^n2^{-n}=1<\infty$. So $\{X_n\}$ is a martingale.

Problem 2.5.3 — Exponential sums

Problem. Let $S_0=0$ and, for $n\ge1$, let $S_n=\epsilon_1+\dots+\epsilon_n$ be the sum of $n$ independent random variables, each exponential with mean $E[\epsilon]=1$. Show that $X_n=2^n\exp(-S_n)$, $n\ge0$, is a martingale.
Formula: §M2.1, §E4.5
Solution. $X_{n+1}=2X_ne^{-\epsilon_{n+1}}$, with $\epsilon_{n+1}$ independent of $\epsilon_1,\dots,\epsilon_n$: $$E(X_{n+1}\mid X_0,\dots,X_n)=2X_nE(e^{-\epsilon_{n+1}})=2X_n\int_0^\infty e^{-u}e^{-u}du=2X_n\cdot\tfrac12=X_n .$$
The handwritten note ends this line with "$=2X_n\cdot\frac12=1$". The value is $X_n$, not $1$.

Problem 2.5.4 — Bernoulli product

Problem. Let $\xi_1,\xi_2,\dots$ be independent Bernoulli random variables with parameter $p$, $0<p<1$. Show that $X_0=1$ and $X_n=p^{-n}\xi_1\cdots\xi_n$, $n=1,2,\dots$, is a nonnegative martingale. What is the limit of $X_n$ as $n\to\infty$?
Formula: §M2.1, §E4.5
Solution. $X_{n+1}=p^{-1}\xi_{n+1}X_n$. By independence of the $\xi_i$: $$E(X_{n+1}\mid X_0,\dots,X_n)=X_nE(p^{-1}\xi_{n+1}\mid\xi_1,\dots,\xi_n)=X_np^{-1}E(\xi_{n+1})=X_n .$$ Limit. $\prod_{i=1}^n\xi_i=1$ w.p. $p^n$ and $0$ w.p. $1-p^n$, so $X_n=p^{-n}$ w.p. $p^n$ and $0$ w.p. $1-p^n$. As $n\to\infty$, $P(X_n=0)=1-p^n\to1$, and once $X_n=0$ it stays $0$. So $$X_n\to0\quad\text{w.p. }1,$$ even though $EX_n=1$ for every $n$.

Problem 2.5.5 — Absorbed fair walk

Problem. A process evolves as follows. If $X_n=0$, then $X_{n+1}=0$. If $X_n>0$, then $$X_{n+1}=\begin{cases}X_n+1&\text{w.p. }\tfrac12,\\X_n-1&\text{w.p. }\tfrac12.\end{cases}$$ (a) Show that $X_n$ is a nonnegative martingale. (b) Suppose $X_0=i>0$. Use the maximal inequality to bound $\Pr\{X_n\ge N\text{ for some }n\ge0\mid X_0=i\}$.
Note. $X_n$ is the fortune of a player in a fair game who wagers \$1 per bet and must quit when all money is lost ($X_n=0$): the gambler's ruin problem.
Formula: §M2.1, §3.1
Solution. (a) If $x_n>0$: $$E(X_{n+1}\mid X_0=x_0,\dots,X_n=x_n)=(x_n+1)\tfrac12+(x_n-1)\tfrac12=x_n .$$ If $x_n=0$, then $X_{n+1}=0=x_n$. So $E(X_{n+1}\mid X_0,\dots,X_n)=X_n$. The walk starts at a nonnegative integer and is absorbed at $0$, so $X_n\ge0$.

(b) (not in notes) The maximal inequality for a nonnegative martingale says $\Pr\{\max_{n\ge0}X_n\ge N\}\le E[X_0]/N$. So $$\Pr\{X_n\ge N\text{ for some }n\ge0\mid X_0=i\}\le\frac iN .$$ This is exactly the gambler's-ruin probability of reaching $N$ before $0$ (for $i\le N$), so the bound is sharp.
