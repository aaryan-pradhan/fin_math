Expectation & Integration

The Lebesgue integral construction: from integrable r.v.s through indicators to simple functions.

Step 1: Integrable Random Variables

A random variable $\xi : \Omega \to \mathbb{R}$ is integrable if: $$\int_\Omega |\xi|\, dP < \infty$$ When this holds, the expectation exists and is defined as: $$E(\xi) = \int_\Omega \xi\, dP$$ The family of all integrable r.v.s on $(\Omega, \mathcal{F}, P)$ is denoted $L^1$ or $L^1(\Omega, \mathcal{F}, P)$.

Step 2: Why Absolute Value?

Pitfall: Every r.v. decomposes as $\xi = \xi^+ - \xi^-$ where $\xi^+ = \max(\xi, 0)$ and $\xi^- = \max(-\xi, 0)$. Both $\int \xi^+\, dP$ and $\int \xi^-\, dP$ exist in $[0, \infty]$.

If both are $+\infty$, then $E(\xi) = \infty - \infty$ — undefined.

Requiring $\int |\xi|\, dP < \infty$ forces both $\int \xi^+\, dP < \infty$ and $\int \xi^-\, dP < \infty$ (since $|\xi| = \xi^+ + \xi^-$), guaranteeing the subtraction is a finite real number.

Step 3: Indicator Random Variables

For any event $A \in \mathcal{F}$, the indicator function is: $$\mathbb{1}_A(\omega) = \begin{cases} 1 & \omega \in A \\ 0 & \omega \in \Omega \setminus A \end{cases}$$
Its expectation: $$E(\mathbb{1}_A) = \int_\Omega \mathbb{1}_A\, dP = \int_A 1\, dP + \int_{\Omega \setminus A} 0\, dP = P(A)$$ The integrand is 0 outside $A$, so only the measure of $A$ survives. This works for any $\Omega$ (discrete or uncountable) — no $\omega$-by-$\omega$ summation needed.

Step 4: Simple Functions

A simple function $\eta : \Omega \to \mathbb{R}$ is a finite linear combination of indicators over pairwise disjoint events: $$\eta = \sum_{i=1}^{n} \eta_i \mathbb{1}_{A_i}$$ where $\eta_1, \ldots, \eta_n \in \mathbb{R}$ and $A_1, \ldots, A_n$ are pairwise disjoint events.
Why disjoint? Each $\omega$ lands in at most one $A_i$, so $\eta(\omega) = \eta_i$ — one clean value, no ambiguity. (Disjointness is not needed for linearity of the integral — that always holds. It's needed for the representation to be unambiguous.)

Do the $A_i$ need to cover $\Omega$? No. If $\omega \notin \bigcup A_i$, every indicator is 0, so $\eta(\omega) = 0$.

Step 5: Expectation of Simple Functions

By linearity of the integral: $$E(\eta) = \int_\Omega \eta\, dP = \sum_{i=1}^{n} \eta_i \int_\Omega \mathbb{1}_{A_i}\, dP = \sum_{i=1}^{n} \eta_i P(A_i)$$ This is the weighted sum of probabilities. The construction ladder:
indicators → simple functions → (approximate arbitrary r.v.s by simple functions → general Lebesgue integral)
